BioPipe Studio · Windows x64 桌面交付包
版本：0.1.0 · 2026-10-12
原项目：https://github.com/lovegavin/BioPipe

启动
1. 将 ZIP 完整解压到一个文件夹。
2. 目标电脑需要 Python 3.11+ 环境及 Microsoft Edge WebView2 Runtime。
   已有环境满足依赖时，直接双击 BioPipe Studio.exe。
3. 首次缺少 Python 依赖时，在要使用的 Python 环境中执行一次：
   python -m pip install -r requirements-studio.txt
   之后仍直接双击 exe 启动，后端由桌面程序自动启动和关闭。

Python 环境选择
biopipe-desktop.json 中的 python 默认为 auto：优先查找解压目录内
的 .venv / venv，再检查环境变量、PATH 和 Python Launcher。
使用未加入 PATH 的 Conda/其他环境时，将 python 字段改成目标电脑
Python 解释器的实际路径，或设置 BIOPIPE_PYTHON 环境变量。
在 JSON 内填写 Windows 路径时，建议使用正斜杠。
backendRoot 为相对路径 "."，可随整个文件夹移动。

可选文件格式
CSV、文本等基础 reader 随基础环境可用。
H5AD、Parquet、PLINK、BGEN、VCF 等格式需要相应的额外 Python 库；
requirements-readers.txt 列出这些可选依赖，可按所需格式安装。
其中部分库的原生轮子与操作系统、Python 版本有关。

使用与保存
单击选择节点，双击查看参数；拖动端口连线，可以连接支线。
内存设置中可调整预算；运行前规划，运行中保留紧急溢写保护。
当前画布自动保存；文件菜单可导出/导入工作流 JSON，保留节点位置、
连线及参数，也可导出/导入执行 YAML。
导出工作流不会附带输入数据，移动工作流时需一并迁移或重新选择数据。

默认运行数据目录：%LOCALAPPDATA%\BioPipe Studio
  workspace\.studio\draft.json       自动保存的画布
  workspace\.studio\operators.json   启动时维护的算子/reader 契约清单
  workspace\.studio\jobs             运行记录、任务配置、日志与产物
  logs                                桌面启动与关闭日志
重新解压软件不影响该目录内的历史数据。

交付内容
BioPipe Studio.exe：桌面宿主，包含所需 .NET 运行库。
frontend：供桌面加载的编译后界面资源，需与 exe 一同保留。
src：Python 后端源码，含 reader、算子、info 契约、内存规划与缓存。
scripts：桌面后端入口和 pipeline 执行入口。
requirements-*.txt：目标电脑的 Python 依赖清单。
THIRD_PARTY_NOTICES：随包第三方组件的许可声明。
package-manifest.json：包内文件的 SHA-256 校验清单及来源版本。

此包可直接试用和检查后端修改。前端、桌面宿主的开发工程、测试、
构建工具、独立网页版启动入口、旧环境、缓存和个人运行数据已排除。
无需安装 Node.js、.NET SDK 或 CUDA；Python 环境由目标电脑提供。
