# ML validation and multiple testing

Route key: `ml_validation`.

## Inputs

| file | bytes | sha256 |
|---|---|---|
| `input/X.csv` | 122,657 | 30 standardized-by-operator features for 569 samples |
| `input/y.csv` | 4,566 | binary diagnosis (357 benign, 212 malignant) |
| `input/pvalues.csv` | 844 | Welch t-test p-value per feature (30 tests) |

The table is the public scikit-learn breast-cancer dataset (WDBC features,
569 samples), exported once and versioned with the route. The p-values are
derived from a Welch t-test between the two diagnosis groups.

## Steps

1. `ml_learning_curve` on features + labels (stratified 5-fold, five training
   fractions, C=0.01, standardized features, accuracy).
2. `export_results` to `ml_learning_curve.csv`.
3. `ml_grid_search` over C = 0.001, 0.01, 0.1, 1, 10.
4. `export_results` to `ml_grid_search.csv`.
5. `stats_fdr` with Benjamini-Hochberg at alpha = 0.05.
6. `export_results` to `stats_fdr.csv`.

## Results

Learning curve (n_train / train mean / test mean):

| n_train | train mean | test mean |
|---|---|---|
| 91 | 0.962638 | 0.926161 |
| 182 | 0.958242 | 0.968374 |
| 273 | 0.967766 | 0.966605 |
| 364 | 0.960989 | 0.959603 |
| 455 | 0.954286 | 0.949061 |

Grid search: best C = **1** with mean accuracy
**0.978916** (std 0.014245).

Multiple testing: **26 of 30** tests rejected at
alpha 0.05; adjusted p ranges 3.18e-95 .. 0.887.

## Oracles

| check | oracle | result |
|---|---|---|
| learning-curve sizes | `sklearn.model_selection.StratifiedKFold` | identical |
| train mean / test mean / test std | sklearn `LogisticRegression` (tol 1e-10) | max abs 1.1e-16 / 1.1e-16 / 8.6e-17 |
| grid mean / std scores | sklearn manual CV | max abs 1.1e-16 / 5.2e-17 |
| best C | sklearn | both 1 |
| BH adjusted p | `statsmodels.stats.multitest.multipletests` | max abs 1.1e-16; 26/30 rejected |

The folds themselves are generated by the operator with the same stratified
shuffle rule as scikit-learn (`random_state=0`), so the comparison is
element-wise rather than statistical.

## Limits

- The logistic solver is L-BFGS on the L2-penalized loss; coefficients are
  only identifiable up to collinearity, so this route judges predictions and
  scores, not coefficient signs.
- `train_sizes` are fractions of the largest possible training fold
  (`n - ceil(n / n_splits)`).
- `stats_fdr` implements BH, BY, Holm and Bonferroni; it does not perform
  permutation-based correction.
