# Operon 1.123.9

## Added

- Dependency checks are fully logged. Every round writes
  `logs/dependency-checks.log` (interpreter + entry ids), and the probe
  subprocess appends `<response>.log` with one line per entry: declared
  environment, resolved interpreter, exact import command, stderr tail and
  verdict. `scripts/diagnose_dependencies.py` reproduces the whole check
  offline and writes `dependency-diagnosis.json` + `.log` with the command and
  output for every entry.

## Changed

- `probe_environment` reports up to three stderr lines and the resolved
  interpreter path, so a failure names both the interpreter and the error.

Backend version: 1.123.9 (operators 709, Readers 101).
