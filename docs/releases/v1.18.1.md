# Operon backend 1.18.1

Patch release. No operators, Readers, providers or routes were added; the
library remains at **470 operators / 100 Readers / 7 providers / 24 routes**.

## Fix

`PlyReader` and `OffReader` previously called `path.read_bytes()` on the value
they received. The application passes `Path` objects, so workflows were
unaffected, but a direct `read("mesh.ply", ...)` call with a string raised
`AttributeError`. Both Readers now normalize the input with `Path(path)` first,
matching the other Readers in the package. A regression test covers string
paths for both Readers.

## Verification

- new regression test in `tests/test_extension17_readers.py`;
- `tests/test_extension17_readers.py tests/test_extension103.py` pass;
- registry check and documentation build are unchanged and clean.

## Compatibility

No protocol, SDK, parameter or serialized-workflow change. Workflows pinned to
1.18.0 continue to execute unchanged.
