# Operon 1.122.6

## Fixed

- The Boltz environment is created by cloning the validated shared environment
  (`micromamba create --clone <prefix>`). Boltz's metadata pins would otherwise
  abort a fresh `pip install` and, when forced with `--no-deps`, break the shared
  `pip check`. The clone keeps exactly the versions that already run Boltz, while
  the shared environment installs no model package at all.

## Verification

- `tests/test_remote_provision.py` still covers the bootstrap and isolated
  environment steps; the clone branch is exercised by the server install.

Backend version: 1.122.6 (operators 709, Readers 101).
