# Operon 1.63.0

Fourth real-inference batch: a new **AntiFold** operator, verified against the
official 540 MB checkpoint and a real VHH structure. The library grows to
**654 operators and 101 Readers**.

## Added

- `antifold_score` (`AntifoldScoreStep`, category Machine Learning, arity 0):
  runs the official AntiFold inverse-folding pipeline on one antibody chain and
  returns `[residue, statistic]` with `perplexity`, `log_prob`, `entropy` and an
  IMGT CDR flag. Parameters: `structure_path`, `chains`, `weights_path`,
  `device`, `batch_size`, `imgt_regions`, `residue_dim`, `output`. The
  `biotite` 2.0 rename (`filter_backbone` -> `filter_peptide_backbone`) is
  shimmed inside the operator, and the model is loaded through the official
  `load_IF1_checkpoint` so no package-path mutation is needed.

## Evidence

- Weights: `model.pt`, 566,838,063 bytes, sha1
  `952ff4c4d15e6ddb74e133805e5ecaa54bd27c9c`, assembled from three
  independently verified slices; `torch.load` yields 489 tensors and four
  server byte probes (offsets 0, 100 MB, 300 MB, 566.8 MB) match.
- Real run through `antifold_score` on `tests/fixtures/vhh_1mel.pdb` chain A:
  132 residues, `[residue, statistic]` shape (132, 4), mean perplexity **2.707**,
  35 CDR residues, 5.9 s on CPU (first residue `A:2` perplexity 1.619).
- `pytest tests/test_extension294.py`: 5 passed, 1 skipped without weights;
  **6 passed** with `OPERON_ANTIFOLD_WEIGHTS` pointing at the checkpoint.
- Registry 654/101/7/24 `errors []`; packaging gate passes.

## Boundaries

- CPU only; GPU is untested. Single chain per run by design (multi-chain files
  must be split or handled by a future operator).
- The weights live outside the repository and are user-supplied; the operator
  fails with an explicit download hint when the path is missing.
