# Operon Studio 2.6.0 - Library management and languages

This candidate uses the single **Operon_Setup.exe** installer with its own Python
environment. Final independent-PC interactive acceptance is pending; do not mark
the candidate as a validated public release before that acceptance is complete.

## Library management

- The existing library-management entry stays in place. Its window has separate
  **Manage library** and **Add operators** pages.
- The large library **+** opens **Add operators**. Ordinary operator/Reader
  packages and saved/imported workflow operators can be added in the same window.
- Adding workflow operators does not replace the active canvas or start a run.
  Existing hot refresh, package enable/disable/remove and dependency repair remain.

## Languages and shared configuration

- Studio supports Simplified Chinese, English and the system language through
  separate JSON message dictionaries. Changing languages keeps the editor and
  unfinished settings forms mounted.
- Language, theme, viewer defaults and configured application paths share the
  active profile's `workspace/.studio/config.json`. Updates merge their own fields
  atomically; earlier preferences are imported without deleting their originals.
- Workflow execution settings and frozen parameter JSON remain independent.

## SDK v3.5

- Operators and Readers can declare an optional adjacent language JSON file for
  titles, descriptions and parameter/choice labels. Existing v3 declarations keep
  their original language and continue to work unchanged.
- IDs, parameter keys/values, contracts, paths and execution identity are not
  translated. Translation-only updates do not require dependency reinstallation
  or change a saved workflow's frozen values.
- Updated English protocol/SDK guides, a public JSON schema and a bilingual
  runnable operator example are included. See [localization](../localization.md).

## Installation and scope

Each Setup installation/reinstallation uses a fresh application directory and
profile, exclusively with its bundled Python. Previous profiles are retained for
explicit import; the global runtime hint is not rewritten. The native installer,
shutdown behavior and application icon retain the validated 2.5.0 implementation.

The reference operator library remains **2026.11.5.2**, independently versioned.
Existing memory management, streaming, disk access, SSH, CLI, MCP and result
viewer behavior are preserved. Automatic layout was not changed in this release.
Optional tools, model weights and first-time WebView2 setup can still require
internet access. This candidate does not claim all optional operators were tested.
