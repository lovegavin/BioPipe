# Operon 1.113.0

One hard capability (705 operators, 101 Readers):
**`boltz_complex_confidence`** — Boltz-2 two-chain complex prediction with
per-residue and interface confidence.

## Operator

Takes a two-sequence Form, writes a single-document Boltz YAML (chains A and B,
`msa: empty`), runs the official `boltz predict` CLI on CPU or GPU, then parses
the prediction PDB and the confidence JSON. Output: per-residue `plddt` and
`is_interface` (cross-chain heavy-atom contact within `interface_cutoff`,
default 8 A). Info: `iptm`, `chains_ptm`, `chain_pair_iptm` (A vs B),
`complex_plddt`, `complex_iplddt`, `complex_pde`, `n_interface`,
`mean_interface_plddt`, `mean_plddt`, chains and sequences.

## Boundaries

- Empty MSA only (the ColabFold MSA server is unreachable here), so ipTM is a
  lower bound for a true homologue-supported prediction.
- Interface residues come from the predicted structure at the cutoff, not from
  contact maps or PAE thresholds.
- Boltz needs NumPy <= 2.1 (numba): the environment is pinned to numpy 2.1.3.
