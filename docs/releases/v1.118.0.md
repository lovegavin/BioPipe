# Operon 1.118.0

Adds one hard capability: **`esm3_sequence_generation`**, masked-prompt protein
sequence sampling with ESM-3 on CPU or CUDA.

## Operator

- Prompt is a plain string of standard amino acids plus `_` for positions to
  sample (validated: empty, unsupported characters, or no mask are rejected).
- `num_steps` (1-64), `temperature` (0.05-2.0), `seed`, `model`
  (`esm3_sm_open_v1`), `device`, `output`.
- Output is the shared `[sequence, position]` protein Form, so it composes with
  downstream operators (ProteinMPNN scores, embeddings, structure prediction).
  Info records `generated_sequence`, `prompt`, `n_masked`, `n_changed`, seed and
  temperature.

## Evidence

- Hand cases: prompt parsing and mask positions, Form round trip, stubbed model
  run (`MKTAY___` -> `MKTAYLLL`, 3 masked / 3 changed), validation errors.
- Real oracle (`OPERON_ESM3_REAL=1`): a seeded ESM-3 run reproduces the direct
  ESM-3 API output exactly (`MKTAYIAKQR________` -> 8 samples, prefix kept),
  `5 passed` in 148 s on CPU.
- Registry: **709 operators / 101 Readers / 7 packages / 24 routes, errors []**.

## Boundaries

The open ESM-3 checkpoint (`esm3_sm_open_v1`, 1.4B) is downloaded through the
Hugging Face mirror; larger checkpoints are not mirrored here. GPU is optional
and untested on this host. <Operon-directory> sync is intentionally frozen at the
user's request; this version is on GitHub only.
