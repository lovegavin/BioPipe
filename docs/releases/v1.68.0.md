# Operon 1.68.0

Ninth real-computation batch: computational **alanine scanning** of an interface,
built on the MM/GBSA machinery from 1.67.0. The library grows to
**657 operators and 101 Readers**.

## Added

- `interface_alanine_scan` (`InterfaceAlanineScanStep`, category Structure,
  arity 1, output `[mutation, statistic]`):
  - ranks target-side residues within `cutoff` of binder heavy atoms;
  - truncates each residue to N/CA/C/O/CB, renames it ALA, drops side-chain and
    hydrogen atoms, and lets PDBFixer rebuild the missing hydrogens;
  - evaluates MM/GBSA on the mutant and reports `wt_delta_kj`,
    `mutant_delta_kj`, `delta_delta_kj` for up to `max_residues` mutations.
  - Parameters: `atom_dim`, `field_dim`, `binder_chains`, `target_chains`,
    `cutoff`, `max_residues`, `ph`, `forcefield`, `implicit_model`,
    `mutation_dim`, `output`.

## Evidence

- Real run on 1MEL (binder `A,B`, target `L,M`, cutoff 4.5 A, five mutations) in
  28.2 s on CPU: wt delta **115.55 kJ/mol**; mutants 112.09, 61.00, 73.09,
  98.41, 54.71; delta-delta **-3.47, -54.55, -42.46, -17.14, -60.84** kJ/mol
  (L:35, M:35, L:46, M:46, L:47).
- `pytest tests/test_extension297.py`: 4 passed (14.7 s, includes the real scan of
  two mutations and the side-chain truncation unit test).

## Boundaries

- Single-point MM/GBSA again: no relaxation, entropy or explicit solvent, so the
  absolute delta-delta values are heuristic. Mutating both symmetry copies of the
  same lysozyme residue changes the complex energy for both interfaces at once.
- PDBFixer's hydrogen placement is not seeded, so absolute energies drift by a
  few kJ/mol between runs; comparisons are meaningful within one run because all
  mutants share a single wild-type baseline.
- Alanine only; no other substitutions, no back-mutation, no per-residue
  decomposition.
