# Operon 1.118.9

Example and documentation patch: the first-run exercise no longer ships a
ready-made route.

## Change

- `examples/smoke_real_data/` now contains only the two real inputs (1MEL
  structure, 132-aa VHH sequence) and a README describing them; the golden
  `task.yaml`, `parameters.json`, `route.json` and `ANALYSIS.md` moved to
  `tests/fixtures/smoke_route/` for regression use.
- Quickstart section 6 asks the agent to search operators, design the graph,
  validate, adjust on user instruction (one transaction per change) and submit
  with `request_id demo-001`; it records the 99/58/41 and 10-liability baseline
  as the sanity check.
- `tests/test_smoke_route.py` validates the reference route and asserts the
  example directory has inputs but no `route.json`.
