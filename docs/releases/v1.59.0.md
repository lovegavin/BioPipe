# Operon 1.59.0

First batch under the hard-capability policy: two model/binary wrappers that are
easy to get subtly wrong and valuable for binder work. Counts move to **653
operators and 101 Readers**.

## Added

- `boltz_predict` — Boltz-2 co-folding wrapper. Builds the official input YAML
  (protein + optional ligand SMILES, optional `properties.affinity`), runs
  `boltz predict` with `--out_dir/--model/--device/--use_msa_server/--affinity`,
  locates the predicted PDB and confidence JSON, and returns confidence
  (score, pTM, ipTM, pLDDT) plus Boltz-2 affinity values when requested.
- `foldseek_search` — Foldseek structural search wrapper. Runs
  `foldseek easy-search` with a fixed `--format-output`, parses the m8 table,
  sorts by alignment TM-score and reports evalue/bits/prob/TM-scores per hit.

## Boundaries

- Neither Boltz nor Foldseek is installed in this environment: real inference
  is resource-gated by the documented `boltz_path`/`foldseek_path` and weights.
  The wrappers reproduce the official invocations but have not been run against
  real weights here; the release note states this explicitly.
- AntiFold remains deferred: the OPIG weight download stalls locally.
