# Operon backend 1.13.0

Released 2026-11-01. Backend application version 1.13.0; the authoring protocol
stays at v3 and the SDK stays at 3.1.0. The factory library grows from 451 to
**455 operators**; the Reader count stays at 93.

## New operators

| Operator | Provider | Inputs | Output |
| --- | --- | --- | --- |
| `mood_median` | `operon-core` | values `[feature, sample]` + metadata `[sample, feature]` | `Z`, `p_value`, `n_x`, `n_y` per feature |
| `var_test` | `operon-core` | values `[feature, sample]` + metadata `[sample, feature]` | `F`, `df1`, `df2`, `p_value`, `ci_low`, `ci_high` per feature |
| `agostino_test` | `operon-core` | values `[sample, feature]` | `skewness`, `z`, `p_value`, `n` |
| `anscombe_test` | `operon-core` | values `[sample, feature]` | `kurtosis`, `z`, `p_value`, `n` |

`mood_median` implements Mood's two-sample test of scale on the pooled ranks,
including the tie correction from R `stats::mood.test`. `var_test` is the
normal-theory F test for two variances with an exact chi-square confidence
interval for the variance ratio. `agostino_test` and `anscombe_test` are the
D'Agostino and Anscombe-Glynn normal approximations of sample skewness and
kurtosis.

## Evidence

Checked against R 4.3.3:

| Operator | Oracle | Reference values |
| --- | --- | --- |
| `mood_median` | `stats::mood.test` | Z `-1.0544701613375884`, p `0.29166771478283576`; tie fixture Z `-0.29070839447937247`, p `0.77127435089028651` |
| `var_test` | `stats::var.test` | F `0.25`, df `5, 5`, p `0.15437725048441334`, CI `0.034982737557465352` – `1.7865954571832061` |
| `agostino_test` | `moments::agostino.test` | skewness `1.6122579953295555`, z `2.7223309730674288`, p `0.0064823184633833039` |
| `anscombe_test` | `moments::anscombe.test` | kurtosis `4.6492457866401962`, z `2.0728109528803347`, p `0.038189876705648086` |

The R oracle test also covers a second, mildly skewed fixture for both moment
tests. New operators are covered by `tests/test_extension98.py` (12 cases) and
`tests/test_r_oracles94.py` (1 runtime R comparison).

## Limits

- `mood_median` uses the normal approximation of the pooled-rank statistic and
  requires two groups with at least three pooled observations; tie correction
  follows R, but its variance approximation still assumes a large sample.
- `var_test` is a normal-theory test and is sensitive to non-normality; each
  group needs at least two observations and a positive sample variance.
- `agostino_test` and `anscombe_test` accept 8 to 46340 finite values and report
  one result for one `value_label` column per run.
- None of the operators applies multiple-testing correction; that remains a
  separate step in a workflow.
