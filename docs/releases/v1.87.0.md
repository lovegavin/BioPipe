# Operon 1.87.0

One hard capability: **`sequence_rna_duplex`** (676 operators, 101 Readers).
It wraps ViennaRNA `RNAduplex` to locate the optimal and near-optimal
hybridization sites between two RNA sequences and reports duplex energy and
spans.

## Operator

- Input: a `[sequence, position]` RNA Form with exactly two sequences.
- Parameters: `energy_range` (kcal/mol tolerance for suboptimal sites),
  `rnaduplex_path`, `timeout_seconds`, `duplex_dim`, `output`.
- Output `[duplex, statistic]`: `start_a`, `end_a`, `start_b`, `end_b`,
  `energy`; info `n_duplexes`, `best_energy`, `best_structure`, `sequences`,
  `energy_range`. Sequences are normalised to RNA (T to U) and validated
  against `ACGUN`.

## Boundaries

- Only intermolecular base pairs are considered (RNAduplex semantics); for
  intramolecular refolding use `RNAcofold` (`sequence_rna_ensemble` covers
  single-strand ensembles).
- Suboptimal sites depend on `energy_range`; the default reports the single
  optimal duplex.
