# Operon 1.117.8

Patch release that removes the last unsatisfiable dependency in the managed
install.

## Finding

`antifold==0.3.1` declares `numpy==1.26.*`, while `pydeseq2==0.5.4` (pinned by
the bulk RNA-seq operator) requires `numpy>=2.0`. No resolution exists, and the
installer's three pip stages all ended with
`ResolutionImpossible ... numpy`.

## Change

- `antifold` joins the optional extras (`CONDA_PROVIDED` / `OPTIONAL_MODULES`),
  so the default solve no longer sees its NumPy pin. The probe reports a
  missing AntiFold as an optional extra instead of failing.
- `docs/agent_environment_repair.md` documents a dedicated environment for
  AntiFold (`numpy==1.26.*`, `torch`, `antifold==0.3.1`) and the operator's
  `python_executable` parameter that points at it.
- Registry and operator code are unchanged; only the dependency plan and docs.

## Verification

- `pytest tests/test_remote_provision.py tests/test_remote_installation.py`:
  updated filter assertions pass.
- On the server, a dry-run without `antifold` is the remaining confirmation
  step before the full managed install is executed by hand.
