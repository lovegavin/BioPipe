# Operon 1.93.0

One hard capability: **`structure_md_dihedral_occupancy`** (682 operators,
101 Readers). It computes backbone phi/psi for every MD frame, classifies each
frame into coarse Ramachandran regions and reports per-residue region
occupancies and mean angles.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB), optional `chains` filter,
  `stride`, `residue_dim`, `output`.
- Output `[residue, statistic]`: `phi_mean`, `psi_mean`, `alpha_occupancy`,
  `beta_occupancy`, `dominant` (0 alpha, 1 beta, 2 left_alpha, 3 other);
  info `n_frames`, `n_residues`, `regions`, `stride`.
- Region boxes are the coarse rectangles defined by the existing
  `structure_phi_psi.ramachandran_region`; the dihedral and region functions are
  imported, not duplicated.

## Verification

- `tests/test_extension322.py`: 5 passed — backbone collection and angle
  finiteness, the hand occupancy case (alpha 2/3, beta 1/3, phi mean -80),
  the operator round trip, the mdtraj `compute_phi` cross-check (1e-3 degree
  agreement after residue mapping), and the error paths.
- Real-data check on 1MEL chain A (132 residues, two frames): mean alpha
  occupancy 0.121, beta 0.568 — consistent with the immunoglobulin beta-sandwich
  fold.
- Registry check: 682 operators / 101 Readers / 7 packages / 24 routes,
  `errors []`.
- Focused and packaging gates pass; Windows verification recorded separately.

## Boundaries

- Region classification uses rectangular boxes, not MolProbity contours, so
  "other" is broader than a validated Ramachandran outlier call.
- Frames must share the topology atom order; hydrogens are ignored.
