# Operon 1.119.3

Fix plus documentation.

## Fixed

Installer dependency receipts were discarded whenever the `site-packages`
directory mtime changed, which happens after almost any package write including
the editable install of Operon itself. A first connection therefore showed
`依赖 0/810` until the operator pressed refresh. `runtime_compatible()` now
compares the interpreter stamp, Python version, prefix, base prefix and
`OPERON_BASE_PATHS`, and ignores the library directory stamp; the installer
probes recorded in `operon-ready.json` are honoured on the first handshake.

## Documentation

- `docs/quickstart_full_flow.md` now opens with an English quick reference and
  keeps the full Chinese walkthrough, so one file serves both languages.
- The agent bootstrap prompt is English only: `docs/agent_bootstrap.md`.
  `docs/agent_bootstrap.zh.md` is removed and every reference points at the
  English file.

Backend version: 1.119.3 (operators 709, Readers 101).
