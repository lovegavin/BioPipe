# Operon backend 1.8.0

Backend-only release. Application version **1.8.0**; SDK **3.1.0**; protocol
**v3**. 435 operators, 93 Readers, seven provider packages and 24 route
templates.

## Added capabilities

| Capability | Provider | Input | Output |
| --- | --- | --- | --- |
| `pcnm` | `operon-core` | distance `[sample, sample_b]` | `[sample, axis]` |
| `cuzick` | `operon-core` | values `[feature, sample]` + metadata `[sample, group]` | `[feature, statistic]` |
| `fisher_alpha` | `operon-microbiome` | abundance `[sample, taxon]` | `[sample, statistic]` |
| `TpedReader` | `operon-readers` | `.tped` + `.tfam` | `[variant, sample]` |

`pcnm` builds principal coordinates of neighbourhood matrices (PCNM). By
default the truncation threshold is the longest edge of the minimum spanning
tree of the distance matrix; distances above it are replaced by
`4 * threshold`, the truncated distances are double-centred and decomposed, and
only positive eigenvalues are returned. Axes are unit-length eigenvectors; the
sign is canonicalised so the first element whose magnitude is within `1e-9` of
the largest magnitude is positive.

`cuzick` computes Cuzick's trend test across ordered groups. It ranks the full
sample, sums ranks per group, and combines group rank sums with ordered scores
(default `1..k`) into `T`, its expectation `L * (n + 1) / 2` and a variance that
uses the average-rank spread. The output reports `T`, the normal `z` statistic,
the p-value for `two-sided`, `greater` or `less`, the sample count and the group
count. Ties are handled through average ranks; unlike `PMCMRplus::cuzickTest`
there is no "ties are present, no correction" warning.

`fisher_alpha` solves `alpha * log(1 + N / alpha) = S` per sample, where `S` is
the number of observed taxa and `N` the total count, using an exact root. A
sample with no observed taxon returns `0`; a sample with only singletons
returns `inf`, since its alpha is unbounded.

`TpedReader` reads PLINK 1 `.tped` genotype rows and their `.tfam` sample list.
It emits `[variant, sample]` allele counts where the dosage is the number of
copies of allele code `1`; a missing allele code (`0`) makes the genotype
missing. `chrom` and `pos` are recorded in `axis_info`, and the representation
is `hard_call` with ploidy 2.

## Oracle evidence

| Check | Reference | Result |
| --- | --- | --- |
| PCNM axes | R `vegan::pcnm` | threshold and all positive eigenvalues match; unit axes match in absolute value to `1e-9` |
| Cuzick trend | R `PMCMRplus::cuzickTest` | `z = 3.53553390593274`, two-sided `p = 0.000406952017444959`; scores `c(3, 1, 2)` give `z = -1.76776695296637` |
| Fisher's alpha | R `vegan::fisher.alpha` | `1.22254799454805`, `0.751794973186656`, `0.525261477587570`; infinite for all-singleton rows |
| TPED decoding | `plink 1.9 --tfile ... --recode vcf` and `--make-bed` | missing, heterozygous and homozygous calls match `Plink1Reader` / `VcfReader` |

The Fisher's alpha comparison uses `abs = 2e-4` because `vegan` solves the same
equation with `uniroot` at its default tolerance (`~1.2e-4`); our exact root for
the second row is `0.7517669176875106`.

## Limits

- `pcnm` takes a distance matrix, not coordinates. The default threshold is the
  longest minimum-spanning-tree edge; only positive eigenvalues are returned,
  and `n_axes` may truncate the result. Axis signs are arbitrary up to the
  canonicalisation rule.
- `cuzick` requires at least two ordered groups and at least two finite values
  per group. Scores must be monotone representatives of the order; the p-value is
  a normal approximation, not an exact permutation test.
- `fisher_alpha` is computed per sample with no confidence interval. All-singleton
  samples return `inf`; empty samples are rejected.
- `TpedReader` decodes the two allele codes literally (`0` missing, `1`/`2`
  alleles). It requires the sibling `.tfam`, does not read compressed files and
  does not phase genotypes. The dosage therefore depends on the allele coding
  stored in the `.tped` file.
