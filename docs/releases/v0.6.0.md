# BioPipe Studio v0.6.0

Edit workflows on Windows and execute them on a Linux server over SSH. This
release also adds complete Hi-C routes starting from paired FASTQ, BAM/SAM or
pairs files, reusing existing QC, selection and plotting operators.

## Downloads

- **Windows-x64.zip**: recommended. Includes portable Python 3.11, SSH support,
  Windows CPU analysis/Reader dependencies and the Microsoft WebView2 bootstrapper.
  Extract the entire archive and double-click `BioPipe Studio.exe`.
- **Windows-x64-Lite.zip**: the same desktop UI and backend source, using an
  existing compatible Python environment.
- The Python wheel supports source/SDK installations. The PLINK 2 native source
  archive accompanies the bundled Windows wheel for reproducibility.

The Windows package does not include Linux executables. Prepare BWA, samtools,
pairtools, cooler and cooltools on the Linux server (or WSL) as described in
[Hi-C setup](../HIC.md). SSH does not install or replace the server environment.

## Changes

- 67 operators, 19 Readers, seven provider packages and eight reusable routes.
  Three new operators (`align_reads`, `build_contacts`, `analyze_contacts`) and
  four file Readers extend the existing library.
- A server target selector, SSH connection settings and a paged server file
  browser. Server jobs continue when the client disconnects; reconnect to inspect
  status, complete logs and output paths. Input and result data remain on the server.
- Host-key verification, in-memory credentials, private SSH transport and
  retry-safe submission. Interactive SSH gateways are supported alongside ordinary
  SSH servers. Damaged/truncated gateway frames are checked and retransmitted.
- Linux support labels in the operator library and canvas are derived from
  dependencies. No new operator authoring protocol is required.
- File-backed Hi-C artifacts retain bounded reads, streaming and spill support.
  Memory planning uses the run-start snapshot, including Linux container limits;
  emergency spilling remains the fallback for subsequent pressure.
- Independent route parameter JSON, code pins, previous routes, CLI/MCP and
  existing CPU workflows are retained.
