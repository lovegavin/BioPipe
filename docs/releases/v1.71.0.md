# Operon 1.71.0

Twelfth real-computation batch: **AntiFold antibody/nanobody inverse folding**.
The library grows to **660 operators and 101 Readers**.

## Added

- `antifold_design` (`AntifoldDesignStep`, category Machine Learning, arity 0,
  output `[design, statistic]`):
  - runs the official `python -m antifold.main` entry point with
    `--pdb_file`, chain flags (`nanobody_chain`, `heavy_chain`, `light_chain`,
    `antigen_chain`), `--regions`, `--num_seq_per_target`, `--sampling_temp`
    and `--seed`;
  - parses the FASTA (wild type plus sampled designs, with score,
    `global_score`, `seq_recovery`, mutations and temperature) and the
    per-residue log-probability CSV (preferred residue, perplexity, wild-type
    and preferred log-probabilities);
  - returns per-design `score`, `global_score`, `seq_recovery`, `n_mutations`,
    and info with the wild-type sequence/score, sampled sequences, region
    string and profile summary (`n_residues`, `n_preferred_changes`,
    `mean_perplexity`).
  - `runner_path` allows an explicit script entry (used by the contract tests
    and by alternative installs).

## Evidence

- antifold 0.3.1 + OPIG weights (566 838 063 bytes), 1MEL VHH (chain A) against
  hen lysozyme (chain L), CDR1-3: wild-type score **1.5146**.
- Five designs at T=0.2: recovery **0.857-0.865**, 12-13 substitutions each,
  **67-69%** inside Kabat CDRs (35% of the domain), 5 s per structure on CPU.
- Profile: 259 residues, 112 positions preferring a different residue, mean
  perplexity **3.71**.
- `pytest tests/test_extension300.py`: 5 passed, 1 skipped (real inference
  gated on `OPERON_ANTIFOLD_REAL=1`); with the gate: 6 passed in 5.75 s.

## Fixed

- `antibody_cdr_kabat` now sets the end-gap score through the
  `end_gap_score` property, so the shared Kabat aligner works on Biopython
  1.83+ (the removed `end_insertion_score`/`end_deletion_score` attributes are
  no longer touched). Existing antibody, paratope and developmentability tests
  pass again.

## Boundaries

- AntiFold is antibody-specific; general proteins should use `esm_if_design`
  or ProteinMPNN.
- The profile is a per-residue marginal, not a calibrated energy; recovery and
  score are model-internal and only comparable within AntiFold.
- Weights are user-downloaded (documented in `docs/large_resources.md`); the
  operator fails honestly when they are missing.
