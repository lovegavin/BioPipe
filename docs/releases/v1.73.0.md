# Operon 1.73.0

Fourteenth real-computation batch: **OpenFold (AlphaFold-2) structure
prediction**. The library grows to **662 operators and 101 Readers**.

## Added

- `openfold_predict` (`OpenfoldPredictStep`, category Machine Learning,
  arity 1, output `[atom, field]`):
  - writes a single-sequence FASTA and A3M alignment, a dummy template CIF
    directory when none is supplied, then runs the official
    `run_pretrained_openfold.py` with `--use_precomputed_alignments`,
    `--config_preset`, the checkpoint, and `--model_device`;
  - returns the predicted structure as an atom table (12 columns) with
    `plddt_mean/min/max` and the model/preset in info;
  - optional `alignment_dir`/`template_dir` for real MSAs and templates.

## Evidence

- OpenFold `finetuning_ptm_2.pt` (358 MB) from the public OpenFold S3 bucket.
- 14-residue peptide, `model_1_ptm`, CPU: **94 atoms in 36.8 s**, pLDDT mean
  **68.7**, range 52.4-80.2, which is the plausible low-confidence regime for a
  single-sequence peptide.
- `pytest tests/test_extension302.py`: 5 passed, 1 skipped; with the real gate
  (`OPERON_OPENFOLD_REAL=1`): 6 passed in 36.71 s.

## Environment notes

- CPU inference required three patches to the OpenFold checkout (CUDA kernel
  import guard plus softmax fallback, TensorRT import guard, and a template CIF
  directory); they are documented in `docs/large_resources.md`.
- The environment's torch is 2.3.1+cu121 (downgraded by the AntiFold install);
  OpenFold runs on it, but the GPU CUDA kernels would need a matching toolkit.

## Boundaries

- Single-sequence mode only; no jackhmmer/hhblits databases are installed, so
  the prediction is the weakest OpenFold mode. Real MSAs can be supplied with
  `alignment_dir`.
- No relaxation (side chains are not repacked) and no multimer prediction.
- Accuracy is not claimed without an experimental reference; pLDDT is reported
  as the model's own confidence.
