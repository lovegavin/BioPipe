# Operon 1.44.0

Released 2026-11-02.

## Capabilities

| Operator | Pillar | Description |
| --- | --- | --- |
| `proteinmpnn_masked_design` | protein design | Redesign a structure while fixing the residues named by an author-numbered mask. |
| `structure_ss_bridge_network` | structure | Contact network between phi/psi-assigned helix and strand segments. |
| `rdkit_functional_group_counts` | ligand | SMARTS functional-group counts for a molecule collection. |
| `sequence_gc_skew_profile` | sequence | Sliding-window GC content with GC and AT skew. |

Counts: 588 operators, 101 Readers, 7 packages, 24 route templates.

## Evidence

- `proteinmpnn_masked_design`: the mask is converted to ProteinMPNN's 1-based
  sequential chain indices and the complement is written as `fixed_positions_jsonl`
  for every chain; a stub runner captures the payload and verifies chain filtering,
  masking errors, designer failures and export counts.
- `structure_ss_bridge_network`: hand-computed two-segment lattice gives a 4.0 A
  minimum with all 16 pairs inside the contact cutoff; the 1MEL VHH fixture yields
  27 segments and 45 bridges, each distance re-derived independently in the test;
  parameter and contract error paths are covered.
- `rdkit_functional_group_counts`: hand-counted acetic acid, benzene, paracetamol,
  acetonitrile and chloroacetic acid against 17 SMARTS groups; RDKit's uniquified
  matching is asserted on benzene.
- `sequence_gc_skew_profile`: hand-computed windows for `GGGGCCCC`, `AAAT`, `ACGT`
  and a one-base-slide `GGCA` scan, including the zero-denominator skew convention;
  multi-sequence labels and short inputs are covered.
- Runner round trips for all four operators, including export JSON.

## Notes

- `proteinmpnn_masked_design` accepts author residue numbers (`A:97-110`), while
  ProteinMPNN itself indexes residues sequentially per chain; the conversion
  happens before the payload is written.
- `structure_ss_bridge_network` distinguishes the bridge cutoff from the contact
  cutoff: a pair can be within bridging distance yet have no atom-level contact.
- Functional groups overlap by design (for example a carboxyl group also counts as
  a hydroxyl); the panel is a triage profile, not a molecular formula.
- GC and AT skew use `0.0` when the denominator is empty, which keeps windows of
  pure A/T or pure G/C numerically defined.
