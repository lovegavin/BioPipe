# Operon 1.53.1

Patch release: two design notes (the minibinder/VHH design route and a
competitive landscape analysis) and the corrected fixtures for the pending
v1.54.0 test batch. No operator contract, registry entry or execution
semantics change; the library stays at **635 operators and 101 Readers**.

## Added

- `docs/design/minibinder_vhh_design_route.md` — the concrete design loop with
  the shipped operators: target preparation, interface and hotspot analysis,
  backbone sources (RFdiffusion, ColabFold/ESMFold, VHH scaffolds),
  ProteinMPNN/LigandMPNN/ESM-IF sequence design with hotspot masks, scoring,
  developability and liability triage, structure re-prediction, docking and
  pose clustering. It also records the current boundaries: no packaged
  route yet, no binder-class (neutral/agonist/antagonist) semantics and no
  pH-dependent scoring.
- `docs/design/competitive_landscape.md` — a comparison against GitHub and
  published-paper projects (RFdiffusion, BindCraft, ColabDesign, ProteinMPNN,
  LigandMPNN, IgFold, AntiFold, ESM/ESM-IF, Boltz, Chai, AlphaFold3) and
  workflow projects (Nextflow, Snakemake, Galaxy, CWL), with the moat
  assessment: the defensible layer is the contract-first operator library,
  registry hashes, generated documentation, oracle-backed tests, resource
  preflight and one service behind CLI/HTTP/MCP/Studio, not a proprietary
  model or dataset.
- `docs/README.md` gains a "Design notes" section linking both documents.

## Fixed

- `tests/test_extension272.py`–`275.py` fixtures corrected against the shipped
  behaviour: `disorder_rows` returns rows only, transmembrane topologies use
  single-sequence spans, liability positions follow the sequon convention, and
  the pairwise reaction test uses an epoxide ring-opening template because an
  amide-coupling template leaves reactant atoms unmapped and yields no
  products.

## Boundaries

- The documents are analyses; they do not add predictive capability. The
  roadmap items they name (packaged binder route, state-specific agonism,
  pH/protonation scoring, affinity estimation) are not implemented yet.
