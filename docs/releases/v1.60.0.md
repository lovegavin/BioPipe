# Operon 1.60.0

Real-inference evidence batch. `boltz_predict` now runs against locally cached
Boltz-1 weights, `foldseek_search` already ran against a real Foldseek binary,
and the blocked hard capabilities are documented with an explicit unblock list.
The library stays at **653 operators and 101 Readers**.

## Added

- `boltz_predict` parameters `msa_mode` (`server` or `empty`) and `cache_dir`.
  `msa_mode: empty` writes `msa: empty` into the YAML and omits
  `--use_msa_server`, which is the only way to run without an MSA server; the
  cache directory is forwarded as `--cache` so a pre-downloaded `ccd.pkl` and
  `boltz1_conf.ckpt` are reused instead of fetched again.
- `docs/design/hard_capability_status.md` gains a "Verified real runs" section
  and lists the concrete unblock steps for AntiFold, Boltz-2, OpenFold and the
  Pfam/HMMER path.

## Evidence

- Weights were downloaded through `hf-mirror.com` because `huggingface.co` is
  unroutable from this host: `ccd.pkl` (330 MB) and `boltz1_conf.ckpt`
  (3,595,352,714 bytes) now live in `~/.boltz`.
- `boltz_predict` end-to-end on `MKVLAAGIVGLLLA`: YAML written, the official
  `boltz` CLI invoked on CPU, `input_model_0.pdb` and
  `confidence_input_model_0.json` parsed into the `[atom, field]` Form, with
  `confidence_score 0.7321`, `ptm 0.1199`, `complex_plddt 0.8852`.
- `foldseek_search` real run stays as recorded in 1.59.3 (binary 10-941cd33,
  local database, 5 hits for 1MEL, self-hit alnTM 1.008).
- Registry: 653 operators / 101 Readers / 7 packages / 24 routes, `errors []`.
  Focused tests for `boltz_predict` and `foldseek_search` pass, plus the
  protocol and reference groups and the packaging gate.

## Boundaries

- Boltz-2 weights (`boltz2_conf.ckpt`, `boltz2_aff.ckpt`) and `mols.tar` were
  not downloaded; only Boltz-1 inference is verified. GPU inference is not
  exercised here.
- MSA generation still depends on an external server; without it only
  `msa: empty` single-sequence runs are possible.
- AntiFold, OpenFold/AlphaFold-2 parameters and Pfam-A.hmm remain unreachable;
  no substitute operator is added to pad the library.
