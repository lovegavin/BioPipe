# Operon 1.52.1

Patch release for the biased ProteinMPNN operator.

## Fix

`proteinmpnn_bias_matrix` forwarded its per-residue 21-amino-acid matrix through
`--bias_AA_per_residue`, a flag the official ProteinMPNN checkout does not
declare, so every real run failed with `protein_mpnn_run.py: error: unrecognized
arguments`. The operator now uses the documented `--bias_by_res_jsonl`
interface, whose payload (`{stem: {chain: [[21 floats] per residue]}}`) is exactly
what the operator already produced.

## Verification

- `tests/test_extension264.py` asserts the new flag name in the fake runner.
- The smoke script runs the operator against the real
  `<ProteinMPNN-checkout>` checkout and returns two designs.
- Registry: 625 operators, 101 Readers, seven packages, 24 routes, no errors.
