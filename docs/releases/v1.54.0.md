# Operon 1.54.0

Expansion batch adding five machine-learning and sequence-analysis operators,
reaching **635 operators and 101 Readers**. The operator sources were authored
alongside 1.53.1 and ship here with their documentation, fixtures and the
release notes; no contract of an earlier operator changes.

## Added

- `esm_embedding_mlp_probe` — scikit-learn MLP classifier over an ESM
  embedding matrix with stratified cross-validation, per-fold accuracy and a
  majority-class baseline.
- `structure_disorder_profile` — per-residue B-factor z-scores (per chain,
  clipped), numbering gaps and a disorder score for missing-loop detection.
- `sequence_transmembrane_topology` — Kyte-Doolittle TM segments with an
  inside/outside assignment from the N-terminal loop charge, segment table and
  topology string.
- `sequence_liability_scan` — deamidation, isomerisation, oxidation,
  N-glycosylation and N-terminal pyroglutamate motifs with severity codes and
  sequence context.
- `rdkit_reaction_pairwise_enumerate` — two-component reaction enumeration over
  a SMARTS template with product caps, deduplication, heavy-atom and molecular
  weight descriptors.

## Boundaries

- The MLP and ridge probes need scikit-learn at run time (documented install
  hint on import failure); RDKit is required for the reaction operator.
- Disorder is a B-factor proxy, not a trained disorder predictor; topology is
  a hydropathy heuristic, not a membrane-insertion model.
