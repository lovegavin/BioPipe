# BioPipe v4.0.0

**Application 4.0.0 · BioPipe Operator Library 4.0.0 · frontend 2.6.0 · protocol v3**

BioPipe 4.0.0 merges the 2.6.0 application and frontend with the verified 3.x
operator library. It is a merge and hardening release: protocol v3 is
unchanged, `export_results` keeps its contract, and no operator was added or
removed (717 operators / 101 Readers / 7 packages / 24 routes).

## What changed

- Application and library versions are unified at 4.0.0; the library requires
  application >= 4.0.0 (`library/release.json`).
- All 3.0.1 library fixes are included: interface core/rim mask, DSSP fixed
  columns, RNA fold/cofold/duplex parsing and defaults, protein molecular
  weight, LigandMPNN/PDBQT export registration, Vina determinism, ColabFold
  score retention, antiSMASH gene de-duplication, the Windows assembly
  launcher, GTF/GFF role mapping, BGEN four-plane decoding, limma's public
  SciPy gamma functions, and the `estimate_memory` classmethod contract.
- Import and plugin installation are portable; Windows path handling and
  desktop-server startup are hardened.

## Verification

- `registry check`: 717 operators / 101 Readers / 7 packages / 24 routes,
  errors 0.
- Backend `pytest -q -rs`: 2931 passed, 220 skipped, 0 failed. Skips are
  environment-gated (missing R, ViennaRNA, external binaries, Windows-only
  viewer tests) and are listed in the run log.
- Frontend 2.6.0 `npm run test`: 23 files, 142 tests passed; `npm run build`
  succeeds and produces `frontend/dist/index.html`.
- Desktop API smoke: bootstrap catalog 717/101; the demo graph executed through
  `POST /api/jobs` to `phase=complete` (3/3 steps).
- Windows compatibility: application 2.6.0 plus the Operator Library 3.0.1
  seed in a separate Windows tree loads 717/101/7/24 with errors 0.
- Operator coverage: 715/717 executed in the remote closure wave (156 real,
  137 synthetic, 293 recorded successes). The two remaining are
  resource/contract-gated models (OpenFold, RFdiffusion); the side-chain
  operator was executed through a filename-normalizing wrapper and its glob
  defect is recorded below.

## Known issues

See `docs/verification/biological-issues-4.0.0.md` for eight recorded
biological/logic discrepancies, including the side-chain glob, the ESM-IF
length assertion, aromatic-stacking label collisions, rotamer line-index
handling, PoseBusters PDB input, Vina 1.2 `--log`, and the two pI conventions.
They are intentionally unchanged in 4.0.0 so existing workflows keep their
semantics.
