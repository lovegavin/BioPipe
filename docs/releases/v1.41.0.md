# Operon 1.41.0

Expansion batch with five analytical capabilities spanning structure geometry,
ligand packing, cheminformatics fingerprints, embedding clustering and
nucleotide composition.

## Capabilities

| Operator | Output | Notes |
| --- | --- | --- |
| `structure_helix_helix_angle` | `[helix_pair, statistic]`: angle_deg, axis_distance, min_ca_distance, n_contacts, helix_i_residues, helix_j_residues | Helices are detected per chain from CA geometry (local step and i..i+3 spacing); axes come from an SVD of the CA trace. |
| `structure_ligand_clash` | `[ligand_atom, statistic]`: n_clashes, worst_overlap, min_distance | Van der Waals overlaps against protein heavy atoms with a Bondi radius table, an overlap tolerance and an optional radius scale. |
| `rdkit_murcko_fingerprint` | `[molecule, bit]` | Murcko scaffold per molecule followed by a hashed Morgan bit vector (radius and length configurable). |
| `esm_embedding_kmeans_silhouette` | `[k, statistic]`: silhouette, inertia | Deterministic k-means (seeded k-means++ style initialisation) over an embedding Form, one row per candidate cluster count. |
| `sequence_cpg_island` | `[island, statistic]`: start, end, length, gc_content, cpg_oe | Sliding-window CpG island scan with GC and observed/expected CpG thresholds, merged island intervals. |

## Oracle evidence

- Helix geometry: ideal helical CA traces with analytic angle, axis distance and
  minimum-CA-distance expectations; parallel and perpendicular pairs.
- Ligand clashes: hand-computed overlaps `(r_i + r_j) - d` compared against an
  independent NumPy loop over all pairs.
- Scaffold fingerprints: compared bit-for-bit with an RDKit
  `MurckoScaffold` + `GetMorganFingerprintAsBitVect` recomputation.
- k-means: silhouette compared with `sklearn.metrics.silhouette_score` and hand
  values on a two-cluster example; best-k asserted on separated clusters.
- CpG islands: sliding-window oracle re-implemented in the test plus a
  runner-level empty-result contract check.

## Limits and compatibility

- Helix detection is CA-only and assumes regular geometry; short or bent helices
  are reported only when they pass the spacing criteria.
- Ligand clashes use Bondi radii, not force-field radii; the tolerance and scale
  parameters make the criterion explicit.
- k-means is a local search seeded by a fixed RNG; the silhouette is only
  meaningful for `k < n`.
- The CpG criterion follows the Gardiner-Garden/Frommer thresholds and reports
  merged windows rather than a single island annotation.
- No existing operator or Reader ids, contracts or parameters changed.
