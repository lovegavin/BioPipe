# Operon 1.94.0

One hard capability: **`structure_ligand_redock_qc`** (683 operators,
101 Readers). It validates a docked ligand pose against a crystal ligand and
its protein using PoseBusters redock mode and reports symmetry-aware RMSD plus
the failed geometric checks.

## Operator

- Parameters: `complex_path` (protein PDB; waters may be included),
  `ligand_path` (crystal ligand, SDF/PDB), `pose_path` (docked pose, SDF/PDB),
  `full_report`, `metric_dim`, `output`.
- Output `[metric, statistic]`: `rmsd`, `kabsch_rmsd`, `centroid_distance`;
  info `n_checks`, `n_failed`, `failed_checks`, `rmsd_pass` (PoseBusters
  `rmsd_≤_2å`), `paths`.
- PoseBusters 0.6.5 config `redock`; the module is imported lazily and the
  operator fails with an install hint when it is missing.

## Verification

- `tests/test_extension323.py`: 3 passed — a synthetic protein/ligand pair with a
  pose shifted by 3.0 A (rmsd 3.0, `rmsd_pass` False, more than five checks),
  the operator round trip, and the missing-file error.
- Real-data check on 3PTB (trypsin + benzamidine BEN): shifted pose rmsd 3.0,
  kabsch_rmsd 0.0, `rmsd_pass` False; identical pose rmsd 0.0, `rmsd_pass`
  True. The identity run still reports five failed geometry checks because the
  protein-only condition omits waters and cofactor context, which is expected.
- Registry check: 683 operators / 101 Readers / 7 packages / 24 routes,
  `errors []`.
- Focused and packaging gates pass; Windows verification recorded separately.

## Boundaries

- `rmsd_≤_2å` is PoseBusters' fixed threshold (2 A); it is not a re-docking
  success guarantee without a reference ligand produced by the same protocol.
- The protein condition should include waters and cofactors when available,
  otherwise several geometry checks are trivially failed.
