# Operon 1.59.2

Completes the Windows fix for the v1.59 wrappers. v1.59.1 added the
`sys.executable` launch guard but the tests still created shebang scripts and
`foldseek_search` only resolved executables through `PATH`, so the Windows run
still failed. This release resolves a wrapper by path when it is a file and
uses plain `.py` fakes in the tests. Counts stay at **653 operators and 101
Readers**.

## Verification

- Registry: 653 operators / 101 Readers / 7 packages / 24 routes, `errors []`.
- `pytest tests/test_extension292.py`–`293.py`: 7 passed on Linux; re-run on
  Windows as part of the release verification.
- Focused gate with `test_protocol_v2.py` and `test_reference_docs.py`.
