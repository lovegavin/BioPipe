# Operon 1.29.0

Released 2026-11-02. Application version 1.29.0, authoring protocol v3, SDK 3.1.0.
The library now holds **521 operators, 101 Readers, seven packages and 24 routes**.

## New capabilities

| Operator | Input | What it reports |
| --- | --- | --- |
| `interface_distance_histogram` | PDB `[atom, field]` form | Binder–target heavy-atom pair distances binned by width, with pair counts, fractions and quantile statistics |
| `structure_packing_density` | PDB `[atom, field]` form | Per-residue heavy-atom neighbours inside a sphere, distinct neighbour residues and atoms per cubic angstrom |
| `sequence_hydrophobicity_profile` | sequence codes `[sequence, position]` | Sliding-window Kyte–Doolittle profile per position plus hydrophobic segments above a threshold |
| `rdkit_fragment_profile` | SMILES list | BRICS or RECAP fragment presence matrix, canonical fragment vocabulary and per-molecule fragment lists |
| `proteinmpnn_probability_profile` | structure path | Per-position amino-acid probabilities p(s_i \| backbone, rest of sequence) from the official ProteinMPNN conditional-probability mode |

## Design notes

- `interface_distance_histogram` counts every binder–target heavy-atom pair within the cutoff (not
  one pair per residue), reports five columns per bin and the 1/5/25/50/75/95/99 quantiles in info.
  Binder and target chains are selected with the same helper as the interface operators and an
  empty target list is derived from the remaining chains.
- `structure_packing_density` centres each residue on its CA atom when an `atom_name` column is
  present and falls back to the atom mean otherwise, so it works with both the compact and the
  full-atom PDB forms. Density is `neighbour atoms / (4/3 π r³)`; water and other excluded residue
  names are removed before counting.
- `sequence_hydrophobicity_profile` uses the Kyte–Doolittle scale, requires an odd window of at least
  three residues, leaves the first and last `(window - 1) / 2` positions as NaN and reports each
  hydrophobic segment as a 1-based inclusive range.
- `rdkit_fragment_profile` strips BRICS/RECAP attachment dummies, canonicalises every fragment, and
  builds a molecule-by-fragment presence matrix over the shared vocabulary; the per-molecule
  fragment lists stay available in `info.molecule_fragments`.
- `proteinmpnn_probability_profile` runs the official `protein_mpnn_run.py` with
  `--conditional_probs_only 1`, `--num_seq_per_target <n> --batch_size 1` (the official runner
  derives its batch count from those flags), averages `exp(log_p)` over batches, and keeps the
  positions selected by the runner mask. The matrix has one row per scored position and one column
  per standard amino acid; `info` carries the native sequence, the most likely residue per position,
  the per-position entropy and the design mask.
- CPU execution is forced with `CUDA_VISIBLE_DEVICES=""`; the seed is passed through, and upstream
  treats seed 0 as random, so the default is 1.

## Evidence

- 29 new tests (`tests/test_extension154.py`–`test_extension158.py`) plus one gated official
  ProteinMPNN run.
- `interface_distance_histogram`: hand-computed bins, cutoff filtering, brute-force histogram oracle,
  chain derivation and parameter failures.
- `structure_packing_density`: hand-computed neighbour counts, radius sensitivity, water exclusion,
  parameter failures.
- `sequence_hydrophobicity_profile`: hand-computed window means, segment detection, Biopython GRAVY
  agreement for the per-residue profile, parameter failures.
- `rdkit_fragment_profile`: RDKit `BRICSDecompose` oracle, RECAP validity, matrix consistency and
  error paths.
- `proteinmpnn_probability_profile`: deterministic fake runner covering parsing, masking, entropy and
  command construction, plus a gated real-checkpoint run on `tests/fixtures/backbone_1bc8_c60_75.pdb`
  (16 positions, native sequence `SRALRYYYVKNIIKKV`).

Focused suite: 154–158 plus the protocol and reference-document tests. Packaging group: builtin
pins, dependencies, library bundle, operator images, release build and agent harness.

## Limits

- The histogram is atom-pair based and reports absolute counts, so the number of pairs grows with
  the number of atoms per residue; compare structures at the same atom representation.
- Packing density uses Bondi-sized spheres through atom counts only; it does not compute Voronoi
  volumes.
- The hydrophobicity profile is Kyte–Doolittle only and requires a window that fits inside every
  sequence.
- BRICS/RECAP fragment vocabularies depend on the input set; the matrix columns change with the
  molecules supplied.
- `proteinmpnn_probability_profile` needs a local ProteinMPNN checkout and `v_48_*.pt` weights; the
  conditional probabilities come from the runner's single forward pass per batch on CPU unless
  `device="cuda"` is requested.

## Compatibility

Operator additions only. Existing operator ids, contracts and parameter schemas are unchanged;
saved workflows keep working and no re-pin is required.
