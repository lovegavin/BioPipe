Operon 1.48.1 is a patch release for the ColabFold wrapper.

## Fix

`colabfold_predict` executed the configured `colabfold_path` directly. On
Linux a Python script runner works through its shebang, but Windows cannot
`CreateProcess` a script, so a `.py` path failed with
`OSError: [WinError 193] %1 is not a valid Win32 application`. The wrapper now
launches a runner whose name ends in `.py` through `sys.executable` and keeps
the direct-executable path for the real `colabfold_batch` binary.

## Verification

* `tests/test_extension244.py` — 7 tests, including the fake `.py` runner that
  now starts under the current interpreter on both platforms.
* Focused group: 47 tests passed on Linux; the same modules run on the Windows
  <Operon-directory> checkout.
* Registry unchanged: 605 operators, 101 Readers, 7 packages, 24 routes,
  errors [].

## Boundaries

The fix only changes how a script entry point is started; it does not install
ColabFold or the sequence databases, and the smoke test still exercises the
documented "binary not found" path on hosts without ColabFold.
