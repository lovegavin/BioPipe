# Operon 1.108.0

One hard capability and a milestone (700 operators, 101 Readers):
**`sequence_rna_cofold_ensemble`** — two-strand RNA ensemble pairing statistics.

## Operator

Runs the ViennaRNA two-strand partition function (`A&B`), symmetrises the
pair-probability matrix, and splits every base's pairing probability into
unpaired, intra-strand and inter-strand components. It reports the MFE cofold
energy/structure, the total inter-strand probability, the interface bases and
per-base rows (`A:1..A:n`, `B:1..B:m`).

## Verification

- `tests/test_extension340.py`: 3 passed — a hand 2+2 matrix splits 0.6 inter /
  0.4 intra exactly, the per-base partition `unpaired + intra + inter = 1`
  holds to 1e-6 on a real 9+9 ensemble, the MFE structure contains no `&`
  separator, and the operator round trip plus strand-count error work.
- Real evidence: `GGGAAACCC` homodimer MFE **-7.10 kcal/mol**, total
  inter-strand probability **5.87** (six inter-strand pairs), 12 interface
  bases; tRNA-Phe (76 nt) plus an 8-nt fragment MFE -21.70 with 2.98
  inter-strand probability and 25 interface bases, showing that the operator
  separates internal folding from dimerisation.
- Registry: **700 operators** / 101 Readers / 7 packages / 24 routes,
  `errors []`.

## Boundaries

- These are thermodynamic pair probabilities at fixed temperature, not
  concentration-aware binding free energies (the CLI `RNAcofold --p` mode with
  concentrations is not exposed).
- No constraints, no SHAPE data, no pseudoknots; two strands only.
- The ViennaRNA bindings are optional and the operator gives an install hint
  when missing.
