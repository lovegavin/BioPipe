# Operon 1.91.0

One hard capability: **`structure_md_hbond_occupancy`** (680 operators,
101 Readers). It pairs each hydrogen with its nearest donor, evaluates every
donor-H...acceptor geometry per MD frame, and reports the fraction of frames in
which each residue pair stays hydrogen bonded.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB with hydrogens), optional
  `chains` filter, `cutoff` (H...acceptor, default 3.5 Å), `angle_cutoff`
  (D-H...A, default 120 degrees), `min_occupancy`, `stride`, `bond_dim`,
  `output`.
- Output `[hbond, statistic]`: `occupancy`, `mean_distance`, `mean_angle`;
  labels `A:17:OG-A:84:OD1`; info `n_frames`, `n_candidates`, `n_hbonds`,
  `cutoff`, `angle_cutoff`, `min_occupancy`, `stride`.
- Donors and acceptors are N/O/S; the hydrogen is assigned to the closest
  heavy atom within 1.35 Å in the first frame.

- Focused and packaging gates pass; Windows verification recorded separately.

## Boundaries

- The geometry criterion is the classic distance/angle definition; it does not
  compute energies or occupancies from an MD force field.
- Hydrogens must be present in the topology; X-ray structures need a repair
  step first (`structure_openmm_energy` performs the same PDBFixer repair).
