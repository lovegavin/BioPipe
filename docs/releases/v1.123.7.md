# Operon 1.123.7

## Fixed

- The automatic post-install readiness check reused cached dependency results,
  so a screen could still show `804/810` even when a live probe returned
  `810 entries; required 0; optional 0` (verified manually on the server with
  the exact installed environment). The automatic check now requests
  `verify_all=True`, which re-probes every operator in the remote interpreter.

Backend version: 1.123.7 (operators 709, Readers 101).
