# Operon 1.124.0

## Fixed

- Dependency checks failed for external tools (`foldseek`, `bwa`, `samtools`,
  `cooler`, `pairtools`, `cooltools`) whenever the checker process ran with a
  PATH that did not include the managed environment's `bin`. Tools now resolve
  through PATH **and** every managed `env-*/bin` directory, so the verdict no
  longer depends on how the server process was started.

## Added

- Every dependency round records per-entry status and reason
  (`logs/dependency-checks.log`, the probe sidecar log, and
  `scripts/diagnose_dependencies.py`, which prints one line per operator).

Backend version: 1.124.0 (operators 709, Readers 101).
