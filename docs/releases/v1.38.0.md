# Operon 1.38.0

Released 2026-11-02. Expansion batch: side-chain torsions, k-mer composition,
embedding loadings, reaction SMARTS and restriction-site scanning.

## Capabilities

| Operator | Category | Summary |
| --- | --- | --- |
| `structure_chi_angles` | Machine Learning | chi1/chi2/chi3 per residue from a full-atom PDB Form |
| `sequence_kmer_profile` | Machine Learning | k-mer entropy, distinct fraction and dominant k-mer per sequence |
| `esm_embedding_pca_loadings` | Machine Learning | per-feature PCA loadings and explained variance of an embedding matrix |
| `rdkit_reaction_smarts_apply` | Machine Learning | apply a reaction SMARTS to a SMILES collection and count products |
| `sequence_restriction_sites` | Omics | scan DNA sequences for common type II restriction sites |

## Design notes

- `structure_chi_angles` resolves side-chain atom names per residue type; chi1
  uses `N-CA-CB-XG`, chi2 `CA-CB-XG-XD` and chi3 `CB-XG-XD-XE`. Residues
  without the required atoms keep `NaN` so the table stays rectangular.
- `sequence_kmer_profile` accepts nucleotide or protein sequence Forms,
  measures Shannon entropy at k = 1, 2 and the requested k, and reports the
  distinct fraction and the dominant k-mer.
- `esm_embedding_pca_loadings` centres the matrix, runs an SVD and returns
  loadings (`feature x component`) normalised by the component standard
  deviation, plus the explained-variance ratios for projection reuse.
- `rdkit_reaction_smarts_apply` runs `RunReactants` per molecule, sanitises and
  de-duplicates products, and reports reaction matches, product count and mean
  product heavy-atom count.
- `sequence_restriction_sites` searches the forward strand for 14 palindromic
  type II recognition sites, reporting counts, distinct enzymes and the first
  position, with per-enzyme positions in `info`.

## Evidence

- `tests/test_extension196.py` – `tests/test_extension200.py` (25 tests):
  Biopython `calc_dihedral` oracle for chi1/chi2, hand k-mer entropy
  (`ACGTACGT` k=2 → 1.9502120649 bits), numpy SVD oracle for loadings, RDKit
  reaction product oracle (anisole deprotection → phenol) and hand restriction
  positions (`GAATTCGGATCC` → EcoRI 1, BamHI 7), plus runner-level contract
  checks through `src.task.runner.run`.
- Focused suite (`196`–`200` + `extension8` + `protocol_v2` +
  `reference_docs`) passes, as does the packaging group.
- Registry: 561 operators, 101 Readers, 7 packages, 24 routes, no errors.

## Limits

- `structure_chi_angles` needs complete side-chain atoms; a CA-only backbone
  produces an all-NaN table (documented, not an error).
- `sequence_kmer_profile` treats residues positionally, so gapped or padded
  sequences should be cleaned upstream.
- `esm_embedding_pca_loadings` is a projection helper, not a classifier; choose
  components from the reported variance ratios.
- `rdkit_reaction_smarts_apply` drops products that fail sanitisation and caps
  the product list with `max_products`.
- `sequence_restriction_sites` covers 14 common enzymes on the forward strand
  only; add enzymes or a reverse-strand pass in a downstream operator.

## Compatibility

Additive change: no existing operator IDs, contracts or parameter names were
modified, so previously pinned workflows keep their execution identity. The
registry counts move to 561 operators / 101 Readers.
