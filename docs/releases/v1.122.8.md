# Operon 1.122.8

## Fixed

- The managed installer no longer installs dependencies owned by a declared
  environment into the shared interpreter. `requirements()` filters descriptors
  with `resources.environment`, so Boltz's `pyyaml==6.0.2`/`requests==2.32.3`/
  `scipy==1.13.1` pins, AntiFold's `numpy==1.26` pin and ESM-3's `torch>=2.11`
  can never break the shared solve or the shared `pip check`. This is the root
  cause of the `pip check` abort reported after v1.121.4.

## Boundaries

- A host must still build each declared environment itself (Boltz's graph needs
  `fairscale` and a `modelcif` version the mirrored resolver accepts). If that
  build fails, the failure is isolated: the shared install still completes and
  only those operators report the missing environment instead of aborting the
  whole deployment.

Backend version: 1.122.8 (operators 709, Readers 101).
