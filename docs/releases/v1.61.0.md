# Operon 1.61.0

Second real-inference batch. Boltz-2 now runs protein plus ligand through the
operator on locally cached weights, the affinity head is exercised end to end,
and two YAML defects found during the real run are fixed. The library stays at
**653 operators and 101 Readers**.

## Fixed

- `write_yaml` now emits the required `version: 1` header. Without it Boltz
  produced no prediction at all, so the operator raised
  "no predicted structure".
- The affinity property now names the **ligand** chain (`binder: {ligand_chain}`)
  instead of the protein chain. With the protein chain, affinity input
  validation failed silently for the structure pass.
