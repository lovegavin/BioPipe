# Operon 1.121.1

## Fixed

- The isolated-environment installer now supports `no_deps` packages: AntiFold is
  installed with `--no-deps` after its runtime pins (NumPy 1.26.4, Torch 2.3.1,
  Biotite 0.38, Biopython 1.83, torch-geometric 2.4.0, pandas, scikit-learn,
  tqdm, matplotlib, meson-python) are resolved. `pygam` has no wheels and its
  Cython build fails on this toolchain; AntiFold's inference path does not import
  it, and the package metadata check is bypassed by the no-deps install.
- `operon/environments.json` records the working recipe and the weights URL;
  `docs/large_resources.md` documents `python -m operon.environments`, the
  `OPERON_ENV_ANTIFOLD` override and the `trained_models/model.pt` path.

## Verification

- Server: `external/antifold` imports `antifold` and `antifold.main`; the 541 MB
  `model.pt` is placed in `trained_models`; the dependency probe reports AntiFold
  through its own interpreter.

Backend version: 1.121.1 (operators 709, Readers 101).
