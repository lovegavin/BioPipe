# Operon 1.121.3

## Fixed

- `foldseek_align` and `foldseek_cluster` no longer declare a Python `foldseek`
  import. Foldseek is a command line tool; the descriptors now list it under
  `resources.external_tools`, so the dependency probe stops reporting a missing
  module while the tool snapshot still shows whether the binary exists.

## Declared

- `operon/environments.json` gains an `esm3` entry (Python 3.12, torch >= 2.11,
  ESM installed from GitHub). ESM-3 cannot share the managed 3.11/torch 2.6
  runtime; the environment is marked `wired: false` until in-process operators
  can run through a subprocess bridge. `docs/design/hard_capability_status.md`
  records the gap explicitly instead of hiding it behind a warning.

Backend version: 1.121.3 (operators 709, Readers 101).
