# Operon 1.95.0

One hard capability: **`structure_md_ligand_rmsd`** (684 operators,
101 Readers). It superposes every MD frame onto the first frame with receptor
CA atoms and reports the ligand displacement after superposition, which is the
standard way to measure ligand dissociation or drift in a trajectory.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB including the ligand), optional
  `receptor_chains`, `ligand_resname` (default LIG), `stride`, `frame_dim`,
  `output`.
- Output `[frame, statistic]`: `ligand_rmsd`; info `n_frames`,
  `n_receptor_atoms`, `n_ligand_atoms`, `mean_rmsd`, `max_rmsd`, `final_rmsd`,
  `stride`, `ligand_resname`.
- Kabsch superposition over receptor CA atoms only; the ligand is transformed
  with the same rotation/translation, so global rotation and translation are
  removed before the displacement is measured.

## Boundaries

- Atom correspondence is by topology order; symmetry-equivalent atom
  permutations are not considered (use `vina_pose_rmsd`/`symmetry_rmsd` for
  docked poses).
- The receptor must keep a rigid core; large domain motion is attributed to the
  ligand if the chosen CA set moves.
