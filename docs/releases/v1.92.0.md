# Operon 1.92.0

One hard capability: **`structure_md_sasa_occupancy`** (681 operators,
101 Readers). It computes per-residue solvent-accessible surface area for every
MD frame with the Shrake-Rupley algorithm and reports mean, minimum, maximum
and the fraction of frames in which the residue is exposed.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB), `probe_radius` (1.4 Å),
  `n_sphere_points` (92, matching the static SASA operator), `exposed_threshold`
  (1.0 Å²), `stride`, `residue_dim`, `output`.
- Output `[residue, statistic]`: `mean_sasa`, `min_sasa`, `max_sasa`,
  `exposed_fraction`; labels `A:ALA:104`; info `n_frames`, `n_residues`,
  `probe_radius`, `exposed_threshold`, `mean_sasa`.
- Radii come from the shared `interface_bsa.vdw_radii` table, so the dynamic and
  static SASA operators agree by construction.

## Boundaries

- Waters and other HETATM records are included when present in the topology.
- SASA is geometric accessibility, not thermodynamic solvation; no probe
  orientation averaging beyond the sphere points is applied.
