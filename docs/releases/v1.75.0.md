# Operon 1.75.0

Sixteenth real-computation batch: **TM-score structural similarity**.
The library grows to **664 operators and 101 Readers**.

## Added

- `structure_tm_score` (`StructureTmScoreStep`, category Structure, arity 1,
  output `[model, statistic]`):
  - extracts C-alpha coordinates keyed by resname:number (chain-agnostic, so
    independent crystal copies can be compared), matches residues, and runs an
    iterative Kabsch loop that reweights pairs closer than 4.5 A;
  - reports `tm_score`, `rmsd`, `aligned_fraction` and the length-dependent `d0`,
    with the matched residue count in info;
  - params: `reference_path`, `model_chains`, `reference_chains`, `cutoff`,
    `iterations`, output names.

## Evidence (authoritative oracle: tmtools / TM-align port)

- 1MEL VHH copies chain A vs chain B, 132 C-alpha pairs: our TM-score **0.9865**,
  tmtools **0.9865**, RMSD 0.51 A, aligned fraction 1.0, d0 4.26 A.
- Same reference with 1.0 A Gaussian noise on the model: ours **0.8652**,
  tmtools **0.8652** (delta 0.0000).
- Identity: **1.000000** for both.
- `pytest tests/test_extension304.py`: 6 passed, including the tmtools comparison.

## Boundaries

- Residue correspondence comes from residue names and numbers; sequence
  alignment is not performed, so insertion codes and renumbered structures must
  be harmonized by the user.
- Only C-alpha atoms are used; a full-atom TM-score is out of scope.
- This is a score, not an alignment output: the superposition matrix and aligned
  residue list are reported in info only at a summary level.
