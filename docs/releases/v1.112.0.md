# Operon 1.112.0

One hard capability (704 operators, 101 Readers):
**`esm3_sasa_prediction`** — per-residue solvent accessibility from the ESM-3
SASA track.

## Operator

The sequence Form is decoded, the ESM-3 open model generates the `sasa` track
with a configurable number of steps, and the track is coerced to one finite
float per residue (padded with NaN or truncated when the generation length
disagrees). The output table reports `predicted_sasa` and an `is_exposed` flag
(>= 25 A^2), with info mean/min/max, residue count and exposed fraction.

## Verification

- `tests/test_extension344.py`: 4 passed, 1 skipped (real ESM-3 run gated by
  `OPERON_ESM3_REAL=1`) — padding/truncation of the track, parsing through a
  fake model, operator round trip and validation errors.
- Real ESM-3 run on the 1MEL VHH domain (132 residues, 8 steps, CPU):
  predicted mean 51.3 A^2; against an independent Shrake–Rupley calculation on
  the crystal structure (92 sphere points, heavy atoms) the per-residue Pearson
  correlation is **0.689** with RMSE 38.4 A^2.
- Registry: 704 operators / 101 Readers / 7 packages / 24 routes, `errors []`.

## Boundaries

- Sequence-only conditioning and 8 generation steps; the SASA track is a
  learned prior, not a geometric calculation, so absolute values differ from
  Shrake–Rupley (predicted mean ~25% higher here).
- The exposed threshold (25 A^2) is a display convention, not a calibrated
  cutoff.
- The real test is skipped without the ESM package or weights.
