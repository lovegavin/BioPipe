# Operon 2.2.1

## Fixed

- The repository tracked a root file named `nul` (created accidentally by a
  Windows `2>nul` redirection). `nul` is a reserved device name on Windows, so
  `git checkout` failed with `error: invalid path 'nul'`. The file is removed,
  the name is ignored, and `tests/test_portable_paths.py` fails if any tracked
  path uses a Windows-reserved name, invalid character, or trailing dot/space.

Existing clones on Windows can recover with:

```
git fetch --all --tags
git reset --hard origin/main
```

Backend version: 2.2.1 (operators 716, Readers 101).
