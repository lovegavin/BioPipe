# Operon 1.56.0

Expansion batch adding four analysis operators, reaching **643 operators and
101 Readers**; no existing contract changes.

## Added

- `structure_dssp_segments` — runs `mkdssp` (DSSP 4.x, classic output format) and
  reports merged secondary-structure segments per chain with state fractions.
  This complements the in-house `structure_secondary_structure` operator with an
  authoritative DSSP assignment.
- `sequence_aggregation_propensity` — AGGRESCAN `a3v` hot-spot windows for
  developability triage.
- `esm_embedding_pca_reconstruction` — per-sample PCA reconstruction error for
  embedding novelty screening (a linear counterpart to the autoencoder).
- `sequence_net_charge` — net charge, mean charge and sliding-window charge
  extremes for pH and formulation reasoning.

## Boundaries

- DSSP requires the `mkdssp` binary; the other three are pure NumPy.
- Aggregation propensity is the a3v scale, not a trained predictor; net charge
  uses a fixed pH-7-style approximation and is not a titration curve.
