# Operon 1.43.0

Released 2026-11-02.

## Capabilities

| Operator | Pillar | Description |
| --- | --- | --- |
| `structure_cavity_scan` | structure | Grid-based buried cavity detection with probe radius, minimum volume and per-cavity centroid. |
| `structure_ligand_residue_map` | structure | Ligand-atom by residue contact matrix (contact counts or minimum distances). |
| `rdkit_scaffold_tree` | ligand | Hierarchical Bemis-Murcko scaffold levels shared across a molecule collection. |
| `sequence_repeat_finder` | sequence | Non-overlapping tandem repeats with 1-based start, period, copy count and length. |

Counts: 584 operators, 101 Readers, 7 packages, 24 route templates.

## Evidence

- `structure_cavity_scan`: hand-built hollow cube fixture yields one cavity with a
  centroid near the box centre; an open three-atom structure yields none; grid and
  flood-fill helpers are unit tested; parameter errors cover spacing, probe radius,
  minimum volume and hydrogen-only structures.
- `structure_ligand_residue_map`: hand-computed contacts for two ligand atoms against
  two residues in both `count` and `min_distance` modes; water exclusion and
  re-inclusion; cutoff, value, dimension and empty-ligand error paths.
- `rdkit_scaffold_tree`: benzene, toluene and aspirin collapse onto the same level-1
  scaffold (three molecules), naphthalene keeps its own; scaffold chains, empty
  scaffolds and parameter errors covered.
- `sequence_repeat_finder`: `ATATAT` (period 2, three copies), `ACGTACGTACGT` (period 4,
  three copies), `AAAA` under `min_period=1`; protein alphabets rejected.
- Runner round trips for all four operators, including export JSON and undeclared
  parameter rejection.

## Tests

`tests/test_extension220.py` through `tests/test_extension224.py` add 25 tests. The
focused suite (new tests, protocol v2 and reference docs) passes; the packaging
suite passes unchanged.

## Notes

- `structure_ss_bridge_network` was planned for this batch but deferred: a reliable
  strand/bridge segmentation needs an independent secondary-structure oracle, which
  is still on the backlog (`structure_dssp`).
- The cavity scan uses a closed padding boundary so solvent channels are not
  reported as cavities; `min_volume` filters grid noise.
- `structure_ligand_residue_map` labels residues as `CHAIN:RESNAME[NUMBER]`, which is
  compact for heatmaps and unique within a structure.
