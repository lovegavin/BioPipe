# Operon 1.79.0

Twentieth real-computation batch: **PoseBusters protein-ligand pose
validation**. The library grows to **668 operators and 101 Readers**.

## Added

- `structure_ligand_pose_qc` (`StructureLigandPoseQcStep`, category Structure,
  arity 1, output `[check, statistic]`):
  - splits a complex into protein and ligand by residue name, drops waters,
    and prefers an RDKit SDF round trip for the ligand so bond perception does
    not depend on the PDB block alone;
  - runs the published PoseBusters suite (`dock` or `mol` config) and returns
    one row per check with the pass/fail value;
  - info reports `n_checks`, `n_failed`, the failing check names and the
    generated file paths.

## Evidence (authority: PoseBusters 0.6.5 itself)

- Synthetic aspirin complex, 22 checks per run:
  - far pose (12 A away): passes bond lengths and volume overlap, fails
    `minimum_distance_to_protein` and `non-aromatic_ring_non-flatness`;
  - superimposed pose: additionally fails `volume_overlap_with_protein`;
  - stretched atom: fails `all_atoms_connected` and `internal_steric_clash`.
- `pytest tests/test_extension308.py`: 4 passed.

## Boundaries

- The operator is a wrapper: scientific authority stays with PoseBusters.
- Bond-level checks depend on a chemically parseable ligand; distorted
  geometries can disconnect the molecule, in which case length checks are
  skipped rather than failed.
- Only single-ligand complexes with a distinct residue name are supported;
  waters are removed, covalent ligands are not special-cased.
