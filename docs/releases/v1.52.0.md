# Operon 1.52.0

Operon 1.52.0 adds five capabilities that close the antibody-numbering and
side-chain design gaps and extend the glycosylation and biased-design surface.

## Operators

| Operator | What it does |
| --- | --- |
| `antibody_numbering_imgt` | Numbers a VH/VHH sequence with the IMGT scheme by aligning it to the reference template, and reports the IMGT region of each residue (FR1-CDR1-FR2-CDR2-FR3-CDR3-FR4). |
| `structure_glycosylation_sites` | Finds N-linked (N-X-S/T, X != P) and O-linked sequons in a PDB complex and reports the per-residue SASA so buried sequons can be filtered. |
| `ligandmpnn_side_chain_packing` | Runs the official LigandMPNN side-chain packing mode (`--pack_side_chains 1` with the side-chain checkpoint) on a backbone and returns the packed structure. |
| `proteinmpnn_bias_matrix` | Builds a ProteinMPNN `--bias_by_res_jsonl` matrix from favored and avoided amino acids at chosen positions, runs the designer and returns the biased designs. |
| `vhh_humanization_mutations` | Compares the Kabat frameworks of a VHH with the human IGHV3-23/IGHJ4 reference and proposes a minimal framework mutation set that yields a fully human framework. |

## Verification

- Hand cases in `tests/test_extension261.py`-`265.py`: IMGT codes cover all 133
  template residues and end at `128`; the sequon scan returns `NAT`, skips
  `NPT` and reports `S`/`T` for O-linked sites; the bias matrix places `+strength`
  on the favored residue and `-strength` on the avoided one; the humanization
  proposal reduces the framework mismatch count to zero.
- Oracle: the IMGT numbering is compared residue-by-residue with
  `abnumber`/ANARCI (`scheme="imgt"`) when the HMMER databases are available.
- 22 focused tests pass; the registry reports 625 operators, 101 Readers, seven
  packages and 24 routes with no errors.
- Windows: the suite, the route checks and the smoke script run on the Windows
  Python environment under `<Operon-directory>`.

## Boundaries

- Side-chain packing requires the official
  `model_params/ligandmpnn_sc_v_32_002_16.pt` checkpoint, which is not bundled;
  the operator reports the missing file instead of guessing.
- IMGT numbering without ANARCI installed uses the static 133-code table derived
  from ANARCI at authoring time; the oracle test skips when ANARCI is absent.
