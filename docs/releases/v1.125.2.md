# Operon 1.125.2

## Fixed

- `RemoteManager.connect` called `_has_dependency_status`, but the helper was
  never defined (the patcher added the call and then skipped the definition),
  so every connection failed with `SSH 连接失败：NameError`. The helper now
  exists at module level and checks `dependencies.entries` in the handshake.

Backend version: 1.125.2 (operators 709, Readers 101).
