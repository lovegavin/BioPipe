# Operon 1.81.0

Twenty-second real-computation batch: **RNA secondary structure folding**. The
library grows to **670 operators and 101 Readers**.

## Added

- `sequence_rna_fold` (`SequenceRnaFoldStep`, category Sequence, arity 1,
  output `[sequence, statistic]`):
  - normalises RNA input (T to U) and rejects non-nucleotide characters;
  - runs the official ViennaRNA `RNAfold` binary (`--noPS`, temperature,
    dangles, optional `--noLP`);
  - reports per sequence the MFE structure, `mfe`, ensemble energy,
    `n_pairs`, GC fraction and length, with the dot-bracket structures in info.

  MFE **-22.40 kcal/mol**, 21 base pairs, identical to the direct CLI run.
- Hairpin `GGGAAACCC`: `(((.....)))`-class structure with MFE -1.20 kcal/mol.
- Two sequences fold in 0.01 s; `pytest tests/test_extension310.py`: 5 passed
  (the CLI-dependent tests skip where RNAfold is absent).

## Boundaries

- ViennaRNA is an optional system package; the operator reports a clear error
  when `RNAfold` is missing and does not bundle the binary.
- Only the MFE and ensemble energy are reported; base-pair probabilities,
  MEA structures and local folding are not surfaced yet.
- Sequences are folded one by one with the default Turner 2004 model; no
  constraints (e.g. forced pairing) are exposed.
