# Operon 1.51.0

Release date: 2026-11-02

Expansion batch for antibody and ligand workflows: Kabat numbering, paratope
prediction, hotspot-restricted ProteinMPNN design, multi-ligand docking and a
cavity druggability score.

## New operators

| Operator | What it does |
| --- | --- |
| `antibody_numbering_kabat` | Aligns a VH/VHH sequence to the reference template and returns one row per residue with its Kabat number, insertion suffix and FR/CDR assignment. The 133 code table is the ANARCI (abnumber, `scheme="kabat"`) numbering of the template, embedded so runtime needs no HMMER database. |
| `structure_paratope_predict` | Projects antibody CDR spans onto a complex and reports each binder residue that contacts the antigen: contact count, minimum distance, paratope flag and CDR name. |
| `proteinmpnn_hotspot_masked_design` | Ranks interface hotspot residues and turns them into the only designable positions of the official ProteinMPNN runner, so designs vary at the epitope and stay fixed elsewhere. |
| `vina_dock_batch` | Docks several ligands against one receptor with AutoDock Vina and returns one summary row per ligand (best affinity, RMSD bounds, modes); the ligand centre can be auto-detected. |
| `structure_cavity_druggability` | Scores the largest buried cavity from grid enclosure and lining hydrophobicity (`0.6 * enclosure + 0.4 * hydrophobicity`), with volume and lining residue count. |

`operon/resources.json` gained no new entries in this batch; docking and
numbering run with user-supplied binaries/databases only where required
(`antibody_numbering_kabat` needs nothing beyond Biopython).
