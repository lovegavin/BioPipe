# Operon 1.116.2

Patch release. Backend version 1.116.2; the operator library is unchanged at
707 operators and 101 Readers.

## Changed

- `operon/remote/provision.py`: the micromamba repair gate now also requires
  `bin/x86_64-conda-linux-gnu-c++`. Previously an environment that already had
  `operon-ready.json`, `bwa` and `samtools` skipped the micromamba step
  entirely, so an environment created before 1.116.1 never gained the C++
  toolchain and a pyarrow source build could still fail.

## Verification

- `tests/test_remote_provision.py`, `test_remote_installation.py`,
  `test_remote_handshake.py`: 45 passed.
- With the gate change, the next "install" against an existing environment
  runs `micromamba install ... gxx_linux-64 cmake make` once and then the
  python installer.
