# Operon 1.123.3

## Fixed

- `依赖 804/810` after a fresh install: all six missing entries were the
  `esm3_*` operators because the ESM-3 environment failed while building
  `pandas 3.1` from source. The recipe now pins `pandas==2.2.3` (wheel) and the
  remaining packages to the set that was executed successfully on the server.
- AntiFold environment: conda supplies `numpy=1.26` before pip runs, so the
  meson `c17` compiler error no longer occurs.
- Boltz environment: `ihm`/`modelcif`/`fairscale` come from pypi.org **before**
  the Tsinghua wheel step, so `modelcif` cannot fail on a missing `ihm`.
- The installer no longer invokes pip with an empty requirement list
  (`You must give at least one requirement to install`).

## Verified on licai-srv-node80 (glibc 2.17)

`ESM3_OK`, `ANTIFOLD_OK` and `BOLTZ_OK` were each produced by the exact command
sequences now recorded in `operon/environments.json`.

Backend version: 1.123.3 (operators 709, Readers 101).
