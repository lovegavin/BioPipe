# Operon Studio 0.116.2

This release packages the unified application and protocol-v3 operator library,
with Windows path fixes verified on an independent desktop test machine.
The preceding 0.116.0 and 0.116.1 candidates retain their original tags and assets.

## Windows profiles and caches

Long Windows paths are handled at the filesystem boundaries for operator wheels,
registry snapshots and atomic temporary files, profile locks, and resumable
transfer caches, frozen parameters, job logs, spill files and figure publication.
The desktop and public API read these results through the same native I/O boundary.
Saved paths stay portable and logical. File locks remain
consistent when the same path is passed in normal or extended Windows spelling.

Operator metadata-only refresh, rollback, old generations, upload/download
resumption, checksums, symlink guards and input allowlists are preserved.

## Agent and specialist-tool access

Workflow, task and artifact services work without a desktop window. CLI and MCP
share those services, with separate read, edit and run permissions. Durable
request identities prevent a retried submission from starting a duplicate task.
An existing desktop session additionally exposes its real selection; one batch
of visible graph edits can be undone together.

The optional SDK-v3 IGV example exports real workflow results as standard BED
and bedGraph files through the public artifact API. Its synthetic example archive
opens as an IGV session. IGV remains a separate application; native-file handoff
does not imply an embedded editor or universal integration with every viewer.

## Downloads

- **Full:** Windows x64 desktop with its own Python 3.11 runtime and declared
  Windows-compatible Python dependencies. No system Python setup is needed.
- **Lite:** the same desktop application, using an existing supported Python.
- **Library 1.1.1:** independently installable 405 operators and 88 Readers,
  with 493 Markdown guides and 493 independent parameter JSON sidecars.
  This update requires application 0.116.2 for its shared filesystem support.
- Application wheel/source, library source, IGV synthetic example, checksums and
  acceptance report are supplied separately.

The full runtime covers Python dependencies for 486 Windows-eligible extensions.
Seven other entries remain discoverable for execution on another platform.
Linux-native tools and separately managed R runtimes are not Windows Python
packages. Memory admission, spilling, streaming contracts, remote execution and
independently frozen workflow/job parameter JSON remain in place.

See `VERIFICATION.md` and `SHA256SUMS.txt` on the release page for the final
package checks and observed acceptance scope. Old main is preserved in the
`legacy-main-20261101` archive; upgrading a detached operator library is explicit.
