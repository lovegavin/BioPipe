# Operon 1.40.0

Expansion batch: backbone dihedrals, CA geometry, ring systems, charge profiles
and ligand burial.

## Capabilities

| Operator | Output | Notes |
| --- | --- | --- |
| `structure_phi_psi` | `[residue, statistic]` with `phi`, `psi`, `region` | coarse Ramachandran classes `alpha`, `beta`, `left_alpha`, `other` |
| `structure_ca_distance_matrix` | `[residue, residue_b]` CA–CA distances | symmetric, optional chain filter |
| `rdkit_ring_systems` | `[molecule, statistic]` | SSSR rings, aromatic rings, fused systems, spiro links, ring size |
| `rdkit_charge_profile` | `[molecule, statistic]` | formal charge, charged atoms, Gasteiger summaries |
| `structure_ligand_burial` | `[ligand, statistic]` | SASA alone vs in complex, buried fraction |

## Design notes

`structure_phi_psi` computes dihedrals with the standard `atan2` form and places
the hydrogen-independent sign convention to match Biopython `calc_dihedral`.
Residues at chain breaks and termini carry `NaN`, and the exported phi/psi ranges
are `null` when a structure has no finite angle of that type. The Ramachandran
classes are deliberately coarse: `alpha` (`phi -100..-30`, `psi -70..10`),
`beta` (`phi -170..-60`, `psi >= 100` or `<= -150`), `left_alpha` (`phi 30..100`,
`psi 0..80`) and `other`. This is a labelling aid, not a DSSP-compatible
secondary-structure assignment.

`structure_ca_distance_matrix` keeps one CA per residue in structure order, so a
matrix entry is the distance between the residues at those two positions (it is
not a contact map). Chain filters apply before the residue count check, and a
filter naming an absent chain is an error.

`rdkit_ring_systems` treats fused rings as one system (rings sharing two or more
atoms) and counts spiro links as ring pairs sharing exactly one atom. Acyclic
molecules return zeros rather than an error.

`rdkit_charge_profile` reports the formal charge over heavy atoms and Gasteiger
charges computed on a copy of the molecule; atoms RDKit cannot type contribute
zero so the matrix stays finite.

`structure_ligand_burial` computes SASA of each ligand residue alone and then in
the protein complex with the same probe and point count, and reports
`buried_fraction = 1 - sasa_complex / sasa_alone`. Ligands with an empty
reference SASA keep a zero fraction.

  runner-level contract check (`Context` + `run`).
- Focused suite: 20 tests for the batch; the packaging group stays green.

## Limits

- `structure_phi_psi` needs N, CA and C atoms; CA-only structures are rejected.
- Ramachandran classes are heuristic buckets, not a thermodynamic analysis.
- `structure_ligand_burial` treats every non-ligand residue as protein surface,
  so nucleic acids and other polymers also contribute to burial.

## Compatibility

No operator or Reader IDs were renamed or removed; Registry counts move from 566
to 571 operators with 101 Readers. Existing workflows keep their values and pins.
