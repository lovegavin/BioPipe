# Operon Studio v2.4.1

This release includes the unified Settings page, desktop-first specialist viewers
and domain output conversions described in [v2.4.0](v2.4.0.md), plus a Windows
lifecycle correction found during release acceptance.

External viewers explicitly leave Operon's process job. Closing Studio therefore
does not terminate the viewer or its unsaved editing session. Analysis workers and
dependency installers still belong to Studio and retain crash/exit cleanup.
The v2.4.0 package remains a superseded candidate, not the recommended release.

- **Settings:** Servers, Outputs and viewers, Appearance in one place.
- **Results:** Open uses a persistent per-format default; an adjacent menu offers
  alternative desktop applications and manual web viewers.
- **Library 2026.11.5.2:** independent release and bundled factory seed, adding
  qualified HIC/Cooler, GenBank, track, network and tree exports.
- **Lite / Full:** existing-environment discovery or portable Python 3.11 with
  tested shared CPU dependencies. Full includes the HIC export dependency.

Protocol v3, independent workflow parameter JSON, managed memory, streaming, spill,
SSH and profile-owned libraries are preserved. Third-party GUI applications,
licenses, GPU drivers and model weights are not bundled. Manual-open adapters
start the application and provide the saved file location rather than claiming an
automatic file load. See `VERIFICATION.md` for the exact acceptance scope.
