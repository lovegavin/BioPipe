# Operon 1.47.0

Backend release of 2026-11-02. Adds four operators to the factory library,
bringing the registry to **600 operators and 101 Readers**.

## New capabilities

| Operator | Category | What it does |
| --- | --- | --- |
| `proteinmpnn_tied_design` | Machine Learning | Runs the official ProteinMPNN with a tied-positions payload so several chains (or symmetric sites) are designed with shared identities each decoding step. |
| `structure_domain_boundary` | Structure | Builds the Cα contact graph, splits it into connected components or by the largest normalized-Laplacian eigengap, and reports per-residue domain assignment plus cross-domain contacts. |
| `structure_ligand_pose_rmsd` | Structure | Superposes two ligand poses (pose vs reference) with Kabsch and symmetry-aware matching of equivalent atoms, reporting per-atom deviations. |
| `sequence_kmer_enrichment` | Sequence | Counts k-mers in a query set and a background set and ranks enrichment with Fisher's exact test, optional Benjamini-Hochberg correction, and an add-pseudocount frequency ratio. |

## Verification

- `proteinmpnn_tied_design`: hand payload mapping for `A:1,2|B:1,2`; a fake official
  runner captures the JSONL payload (`{stem: [{A: [1], B: [1]}, {A: [2], B: [2]}]}`),
  the weights directory and the CPU `CUDA_VISIBLE_DEVICES` convention; validation
  covers malformed groups, chain membership and author residue numbers.
- `structure_domain_boundary`: hand 6-residue two-chain fixture (adjacency, components),
  normalized-Laplacian eigenvalues of two disconnected blocks, a connected dumbbell split
  by the spectral gap, boundary flags on a connected graph, and error paths.
- `structure_ligand_pose_rmsd`: Kabsch recovery of a rigid transform, symmetry matching of
  two equivalent carbons (brute-force permutation search for small element groups),
  identity after translation, element-composition mismatch and ligand selection errors.
- `sequence_kmer_enrichment`: k-mer counts, Benjamini-Hochberg hand case, Fisher agreement
  for the top k-mer, runner enrichment on a synthetic FASTA, and parameter validation.
- Focused suite `tests/test_extension237.py`–`tests/test_extension240.py`: **24 passed**;
  with the protocol and reference-doc tests **49 passed**.
- Registry: `600 operators / 101 readers / 7 packages / 24 routes`, `errors []`.
