# Operon 1.117.0

One hard capability (708 operators, 101 Readers):
**`structure_md_interface_occupancy`** — which interface residues stay in
contact across a trajectory.

## Operator

Reads a `[frames, atoms, 3]` coordinate array plus the topology PDB, resolves
binder and target chains (default: first chain versus the rest), and for every
frame queries cross-chain heavy-atom distances with a KD-tree at a contact
cutoff. Output: one row per residue that contacts the other side at least once,
with `occupancy` (contacted frames / total frames), `min_distance` and
`n_frames`; info adds frame count, cutoff, interface size, persistent count
(occupancy >= 0.9) and the chain assignment.

Bugs found and fixed while testing: residues were counted once per contacting
**atom** on the target side (occupancies above 1.0) and every residue was
reported even when it never contacted the partner; both are fixed and covered
by the hand fixture.

## Verification

- `tests/test_extension349.py`: 4 passed — frame-array validation, a
  hand-computed three-frame system (`A:ALA:1` contacts all three frames,
  `A:GLY:2` only the last, a distant residue is filtered out), chain
  resolution defaults/errors, and an operator round trip.
- Rigid-body control on the 1MEL A/L complex (3798 atoms, 20 frames, L chain
  rotated 2 deg and translated 0.15 A per frame): 48 interface residues, all
  48 persistent, contact distances 2.1-2.6 A. This is a synthetic control, not
  an MD trajectory; a real OpenMM run was attempted but exceeded the CPU budget
  on this host and is not reported as evidence.
- Registry: 708 operators / 101 Readers / 7 packages / 24 routes, `errors []`.

## Boundaries

- The operator consumes frames; producing them (MD or otherwise) is the caller's
  job, which also means a rigid-body control can inflate occupancy.
- Heavy atoms only, hard cutoff, no hydrogen bonds or burial: a transient
  contact and a stable salt bridge with the same occupancy are not distinguished.
- Chain selection assumes the topology PDB atom order matches the frame array.
