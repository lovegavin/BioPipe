# Operon 1.119.1

## Artifact tables

- `preview` now returns `columns`, `row_labels`, `total`, `offset` and `limit`
  alongside the value window, read from the artifact metadata labels.
- New `operon_artifact_table(job_id, artifact_id, offset, limit)` calls
  `/api/v1/jobs/{job}/artifacts/{id}/table`; the same backend serves local and
  ssh jobs (the ssh preview RPC forwards the window to the server-side service).
- The Studio preview keeps its 20-row default; tables default to 100 rows and
  can page to any offset.

## Remote execution

- `operon_remote_status()` lists profiles and their connected state.
- `operon_remote_ensure(profile_id)` reconnects idempotently for key/agent
  authentication and returns an actionable message for password profiles
  (passwords are never stored).

## Agent onboarding

- `docs/agent_bootstrap.md` (English) and `docs/agent_bootstrap.zh.md` teach the
  first turn: status, context, operator discovery, canvas transactions,
  execution switching, run confirmation, artifact tables and reporting rules.
- The quickstart now starts a new agent conversation with a single line —
  "请阅读 docs/agent_bootstrap.zh.md，准备后续工作" — and gives separate local and
  server task prompts for the smoke data.
