# Operon 1.123.8

## Fixed

- Dependency readiness reported six environment/tool-backed operators as
  failed even though the environments were ready:
  `antifold_design`, `antifold_score`, `boltz_complex_confidence`,
  `esm3_sequence_generation`, `foldseek_align`, `foldseek_cluster`.
  `operon.environments.resolve` now falls back to sibling managed
  environments (`<managed>/env-*/external/<name>`), so a probe running under a
  different environment still finds the shared external interpreters, and
  `operon.dependencies.probe` validates declared `external_tools` with
  `shutil.which` instead of importing them as modules.

Backend version: 1.123.8 (operators 709, Readers 101).
