# v1.20.1

Patch release. The library is unchanged: 479 operators, 100 Readers, 7 packages
and 24 built-in routes. This release only makes the ProteinMPNN presentation
test portable, so no operator, Reader, route, contract or saved workflow changes
identity.

## Change

`tests/test_extension110.py` now compares the values that
`proteinmpnn_design` passes to the official runner against
`Path.as_posix()` on every platform:

- `--path_to_model_weights` is compared with
  `(repo / "vanilla_model_weights").as_posix()`;
- the `fixed_positions` JSONL is compared with
  `{structure.as_posix(): {...}}`.

v1.19.1 has always sent POSIX-style paths to ProteinMPNN (the operator calls
`as_posix()` on the structure, output directory, weights directory and fixed
positions file), so this is a test-only correction: the previous assertions
hard-coded `str(path)` and therefore failed on Windows, where `str(path)` uses
backslashes while the operator correctly sends forward slashes.
