# BioPipe Studio 0.4.0

## Extract and launch on Windows x64

The desktop ZIP now includes CPython 3.11 and the declared CPU dependencies of
the built-in Readers and operators. Extract the entire archive and double-click
`BioPipe Studio.exe`; Python, Conda and a compiler do not need to be configured.
The host uses the bundled interpreter even when another Python is installed.
It starts in isolated UTF-8 mode and reports an incomplete runtime rather than
silently selecting another environment.

The .NET runtime is included. If Microsoft WebView2 is absent, the included,
signature-verified official bootstrapper prepares it for the current user. This
one-time setup requires internet access. Keep the `runtime` directory beside the
EXE. Existing user graphs and logs remain in the shared Studio profile.

## Dependency maintenance and selective isolation

- Startup, library refresh and extension installation check declared dependencies.
  Successful entries remain passed until the session ends; changed/new entries
  and failed entries are checked again.
- Compatible operators share dependencies. Conflicting versions receive immutable
  private dependency directories and independent subprocesses using the same
  Python executable. Failed installation does not replace a working generation.
- Reader disk staging, bounded streaming, memory planning and emergency spill
  remain available. Subprocess memory and disk transport are accounted for;
  cancelling a run terminates its owned workers and retains diagnostic logs.
- New packages still need a satisfiable dependency set, compatible Windows builds
  and internet access. A Python-version, driver or OS incompatibility is reported,
  not disguised as a successful repair.

See [dependency isolation](../dependency_isolation.md) and
[installation](../installation.md) for the protocol and boundaries.

## Readers, extensions and editor

- Integrates the author's Windows VCF parser, avoiding the native htslib path.
  Plain/gzipped VCF, multi-ALT records, mixed missing-call spellings and metadata
  propagation are covered. Malformed sample counts and invalid allele indices
  produce readable errors.
- PLINK 2 dependencies are compiled during release preparation. The matching
  pgenlib Windows source archive is supplied with the release.
- Authors may supply an icon image through the class-level `icon` field; a category-specific
  default is used otherwise. Category declarations apply to source refresh and
  packaged extensions.
- Canvas fitting is explicit: double-click blank canvas or use the fit control.
  Editing no longer schedules an automatic fit.
- Complete English [Reader](../reader_extensions.md) and
  [Step](../step_extensions.md) extension guides include executable examples.

## Release artifacts

The desktop ZIP is the end-user download. The SDK wheel is for existing Python
environments. The native-source archive supports reproducible rebuilding of the
included pgenlib extension. `SHA256SUMS.txt` covers the downloadable artifacts;
the desktop's `package-manifest.json` and `runtime/python/biopipe-lock.txt` record
its files and resolved dependency versions. See the attached verification report
for the independent Windows desktop acceptance results.
