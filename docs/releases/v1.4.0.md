# Operon backend 1.4.0

Backend application release: **421 operators, 91 Readers, 7 providers, 24 route
templates**. Operator protocol v3, SDK 3.1.0. Frontend package versions remain
maintained separately.

## New capabilities

| Capability | Provider | Purpose | Output |
| --- | --- | --- | --- |
| `iv_2sls` | `operon-core` | Two-stage least squares with endogenous regressors, excluded instruments and exogenous controls | `[term, statistic]` with `coef`, `se`, `z`, `p`, `ci_low`, `ci_high` |
| `iptw_effect` | `operon-core` | Inverse-probability-weighted average treatment effect (ATE) or effect on the treated (ATT) | `[statistic, value]` with `effect`, `se`, `z`, `p`, `ci_low`, `ci_high`, sample and propensity-score summaries |
| `rdd` | `operon-core` | Sharp regression discontinuity with a local linear fit on each side of the cutoff | `[statistic, value]` with `tau`, `se`, `z`, `p`, `ci_low`, `ci_high`, `n_left`, `n_right` |
| `H5muReader` | `operon-readers` | `.h5mu` MuData modality matrix (dense or sparse, optional layer) | `[sample, feature]` |

All three operators read numeric columns from one `[sample, feature]` table and
select columns by label. The reader dispatches a single modality per read.

## External evidence

- **IV:** coefficients and homoskedastic standard errors match
  `linearmodels 7.1` `IV2SLS(...).fit(cov_type="unadjusted")` to `1e-6`. The
  operator normalizes the residual variance by `n` (not `n - k`), matching that
  estimator; the default `linearmodels` fit is heteroskedastic and is not the
  comparison target. Probe values: `beta = [0.97904861, 0.37089485, 1.90768931]`,
  `se = [0.09340002, 0.14412075, 0.20273829]`.
- **IPTW:** weights match R `glm(t ~ c1 + c2, family = binomial)`; standard errors
  use the explicit weighted least squares sandwich with squared weights, checked
  against a hand-written R implementation in the oracle test.
- **RDD:** point estimate and conventional standard error match R
  `rdrobust(y, x, c = 0, h = 0.5, b = 0.5, p = 1, kernel = "triangular",
  vce = "hc0")` on the 400-point probe (`tau = 0.9273805`, `se = 0.1765214`). The
  sandwich uses squared kernel weights, as in the R implementation.
- **MuData:** `.h5mu` files written by `mudata 0.3.10` are read back with matching
  dense and sparse matrices, obs/var names and AnnData layers.

## Limits

- `iv_2sls` supports cross-sectional two-stage least squares only; no GMM,
  heteroskedastic, clustered or kernel covariance, panel data or weak-instrument
  diagnostics. The homoskedastic covariance assumes independent, identically
  distributed errors.
- `iptw_effect` estimates ATE/ATT with a logistic propensity score and does not
  implement doubly robust estimation, overlap weights or a correction for
  first-stage propensity-score uncertainty. Extreme scores are clipped and
  optionally trimmed.
- `rdd` fits local linear polynomials on each side of a sharp cutoff. It does not
  implement bias-corrected or robust confidence intervals, covariate adjustment,
  fuzzy designs or bandwidth selection.
- `H5muReader` reads one modality at a time; it does not materialize embeddings
  (`obsm`), variable metadata (`varm`) or paired feature maps.
