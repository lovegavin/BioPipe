# Operon 1.12.0

**Release date:** 2026-11-01

1.12.0 adds four distribution and trend tests to the backend operator library.
All four are deterministic, take one numeric series, and were validated against
their reference R implementations.

## New capabilities

| Component | Provider | Input | Output |
| --- | --- | --- | --- |
| `lilliefors_test` | `operon-core` | one numeric series (`[sample, feature]`) | Lilliefors statistic, p-value, n |
| `cox_stuart` | `operon-core` | one numeric series (`[sample, feature]`) | increasing pairs, effective pairs, p-value |
| `rank_test` | `operon-core` | one numeric series (`[sample, feature]`) | Mann-Kendall rank statistic, pair count, expectation, variance, p-value, n |
| `pearson_test` | `operon-core` | one numeric series (`[sample, feature]`) | chi-square statistic, df, p-value, class count, n |

## Methods

- **Lilliefors test** sorts the finite observations, computes the
  Kolmogorov-Smirnov distances against the fitted normal CDF, and evaluates the
  Lilliefors p-value with the `nortest::lillie.test` corrections (the
  `n > 100` rescaling and the four polynomial branches used when the first
  approximation exceeds 0.1).
- **Cox-Stuart test** drops the middle observation for odd lengths, compares the
  first and second halves, counts strictly increasing pairs, and uses the exact
  two-sided binomial tail.
- **Rank test** counts later observations larger than each earlier observation
  and applies the Mann-Kendall normal approximation
  (`mu = n(n-1)/4`, `var = n(n-1)(2n+5)/72`), matching
  `randtests::rank.test`.
- **Pearson test** splits the fitted normal into equiprobable classes with
  `ceiling(2 * n^(2/5))` classes by default, compares observed and expected
  counts, and subtracts two degrees of freedom for the estimated mean and
  standard deviation when `adjust` is true.

## Oracle evidence

The R oracle test runs `nortest` and `randtests` on the same fixtures used by
the unit tests.

| Operator | Reference | Reference value |
| --- | --- | --- |
| `lilliefors_test` | `nortest::lillie.test` | D `0.11130902375462534`, p `0.97780253575171683` |
| `cox_stuart` | `randtests::cox.stuart.test` | statistic `6`, pairs `6`, p `0.03125` |
| `rank_test` | `randtests::rank.test` | z `1.7108556417848431`, P `79`, expected `60`, variance `123.33333333333333`, p `0.08710776496743855` |
| `pearson_test` | `nortest::pearson.test` | X2 `5.2000000000000011`, df `4`, p `0.2673848815716019`, classes `7` |

Short-series and tie fixtures for `cox_stuart` (`4/4/0.125`, all-equal series
with p = 1) and the default-class fixture for `pearson_test` are also covered.

## Limits

- `lilliefors_test` requires at least five finite observations and a non-constant
  series; the p-value uses the published Lilliefors approximation, not a Monte
  Carlo estimate.
- `cox_stuart` drops the middle value for odd lengths so that paired halves are
  equal in size; pairs with zero difference are excluded from the binomial
  denominator.
- `rank_test` uses the normal approximation and, like `randtests::rank.test`,
  does not correct for ties.
- `pearson_test` uses equiprobable classes with estimated mean and standard
  deviation; the default class count is `ceiling(2 * n^(2/5))`, and a too-small
  `n_classes` can leave no degrees of freedom.
