# Operon 1.46.1

Patch: the interface-masked ProteinMPNN designer ignored non-protein atoms.

## Fix

`proteinmpnn_masked_interface_design` derived its residue mask from every heavy
atom within the binder/target cutoff. Real PDB entries carry `HETATM` water,
ion and ligand rows, and those labels (for example `A:HOH:150`) are not author
residue numbers of the protein chains, so the run stopped with
`interface residue(s) ... are not author residue numbers of the structure file`.

The interface set is now restricted to the twenty standard amino acids before
the mask is built. If a whole side has no protein residue at the interface the
operator reports `no protein residue was found on the <side> side of the
interface` instead of producing an empty mask.
