# Operon 1.77.0

Eighteenth real-computation batch: **per-residue lDDT**. The library grows to
**666 operators and 101 Readers**.

## Added

- `structure_lddt` (`StructureLddtStep`, category Structure, arity 1, output
  `[residue, statistic]`):
  - extracts matched C-alpha atoms for the model and the reference (chain
    agnostic by resname:number, so independent crystal copies compare);
  - scores every atom against the 15 A inclusion radius with the four
    thresholds 0.5/1/2/4 A and the standard `1/4` averaging;
  - reports per-residue `lddt` and `n_pairs`, with `mean_lddt` and the
    threshold list in info.

## Boundaries

- C-alpha only; all-atom lDDT is not implemented.
- Residues are matched by name and number (no sequence alignment); renumbered
  structures must be harmonized first.
- The score is reported as a fraction in [0, 1]; multiply by 100 for the
  commonly quoted percentage.
