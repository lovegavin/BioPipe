# Operon 1.58.0

Expansion batch adding four operators, reaching **651 operators and 101
Readers**. This closes the small-operator series; from 1.59 onward the library
policy focuses on model wrappers and analytically hard capabilities (see
`docs/design/extension_policy.md`).

## Added

- `proteinmpnn_interface_temperature_scan` — runs the official ProteinMPNN
  runner across a sampling-temperature ladder on a hotspot-masked interface and
  reports yield, score and recovery per temperature.
- `esm_embedding_knn_density` — k-nearest-neighbour density novelty with a
  median/MAD robust threshold.
- `sequence_cysteine_pairing` — cysteine positions and adjacent/outer disulfide
  pairing hypotheses for VHH and scaffold triage.
- `sequence_hydrophobic_moment` — Eisenberg helical hydrophobic moment with a
  closed-form check for poly-leucine.
