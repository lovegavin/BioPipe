# Operon 1.27.0

Expansion batch. The library grows from 508 to **512 operators** (101 Readers
unchanged, 7 packages, 24 routes).

| Capability | Kind | Purpose |
| --- | --- | --- |
| `rdkit_oral_bioavailability` | operator | Lipinski, Veber and Egan oral-bioavailability rule sets with descriptor values, violation counts and a combined pass flag |
| `rdkit_qed` | operator | Bickerton QED drug-likeness score with the descriptors behind its desirability terms |
| `sasa_per_residue` | operator | Shrake-Rupley solvent-accessible surface area for every residue of a full-atom structure |
| `antibody_cdr_motifs` | operator | Kabat CDR scan for N-glycosylation, deamidation, isomerization, oxidation and free-cysteine liabilities with positions |

## Operators

### `rdkit_oral_bioavailability`

Evaluates three rule sets on RDKit descriptors: Lipinski (molecular weight,
cLogP, hydrogen-bond donors and acceptors, at most one violation), Veber
(rotatable bonds <= 10 and TPSA <= 140 A^2) and Egan (TPSA <= 131.6 A^2 and
cLogP <= 5.88). The output form has one row per molecule with the descriptor
values, the number of Lipinski violations, the three pass flags and a combined
`oral_bioavailability_pass`. All thresholds are parameters, so the same
operator can encode stricter internal criteria. The rule provenance is stored
in `info.rule_sets` and `info.thresholds`.

### `rdkit_qed`

Computes the Bickerton quantitative estimate of drug-likeness with RDKit's
`QED.qed`. The form reports the score together with molecular weight, cLogP,
TPSA, donors, acceptors, rotatable bonds and aromatic rings; the published
score is a weighted geometric mean of monotone desirability functions over
those properties.

### `sasa_per_residue`

Samples Shrake-Rupley sphere points with Bondi van der Waals radii and a
1.4 A probe, then aggregates the per-atom areas into per-residue values with a
`chain:RES:number[icode]` label. Water and other excluded residue names are
skipped, hydrogens are ignored, and the output carries `sasa`, `sasa_fraction`
of the total surface and the heavy-atom `n_atoms`.

### `antibody_cdr_motifs`

Reuses the Kabat CDR boundaries of `antibody_cdr_kabat` and scans each selected
CDR for N-glycosylation (N-X-S/T with X not proline), deamidation (NG, NS),
isomerization (DP, DG), oxidation (M, W) and free cysteines. The form reports
counts per region and `info.motif_positions` lists the 1-based sequence
positions of every hit.

## Evidence

- Hand-computed assertions for the rule arithmetic: ethanol, benzene, aspirin
  and a C40 alkane; single-sphere SASA equals `4*pi*(r+probe)^2`; motif hits on
  a synthetic `AANGSVDPWGGC` sequence.
- Authoritative oracles: RDKit `QED.qed` and descriptor functions for
  `rdkit_qed`, Biopython `Bio.PDB.SASA.ShrakeRupley` for `sasa_per_residue`
  (per-residue within 25 %, total within 1 %), `re` lookahead scans for the
  motif positions, and Kabat/ANARCI-verified regions from `antibody_cdr_kabat`.
- 22 new tests in `tests/test_extension145.py` to `test_extension148.py`,
  including runner-level contract checks for all four operators.

## Limits

- The bioavailability rules are descriptor rules, not a pharmacokinetic model.
- QED is the RDKit implementation; no alternative property set is exposed.
- SASA uses Bondi radii, so values differ slightly from tools using ProtOr or
  atom-name radii dictionaries.
- Motif scanning is sequence-only; it does not know about disulfides, so every
  cysteine is reported as a free-cysteine candidate.

## Deferred

- `structure_dssp`: exact secondary-structure assignment needs the full
  Kabat-Sander hydrogen-bond pattern algorithm; shipping mkdssp as both engine
  and oracle would make the check circular, so the operator waits for an
  independent implementation plus a DSSP oracle.
- `ligandmpnn_ligand_design`: ligand-aware design needs a dedicated ligand
  fixture and flag mapping before it can be released.

## Compatibility

Additive only. All four IDs are new; `inputs_arity` and existing contracts are
unchanged, so saved workflows do not need re-pinning.
