# BioPipe Studio 0.7.0

2026-10-27 source release. 主题：严格契约、Agent/SOP 文档、Studio 导入修复。当前
78 个算子、16 个 Reader、6 个包、14 条路线；本版本不新增分析算子/Reader。

## 严格契约

- 16/16 Reader、78/78 算子使用 `additionalProperties: false`。
- 30 个 legacy 算子迁移到源码 schema；`operator_ui.json` 仅保留展示元数据。
- 参数补齐 title、basic/advanced 分组、order/unit；基类强制严格校验。
- Reader/算子输出继续由 Form/labels/axis_info/contracts 约束。

## Agent 与 SOP

- [任务 SOP](../route_sop.md)、[LLM 手册](../llm_guide.md)、[用户手册](../user_guide.md)。
- 78 个算子页、16 个 Reader 页、`operator_index.json`/`reader_index.json`。
- `biopipe inspect`、`scripts/run.py --check`、`tasks/sop_demo/`。
- `docs/reference/` 自动生成；新增/修改后运行 `scripts/build_reference_docs.py`。

## Studio 修复

- 导入任务从 `code_root` 搜索输入，而非只看 Studio workspace。
- 支持项目内绝对路径；跨盘 job 保留绝对路径；导出尽量相对化。
- 重新选择输入文件保留 dims/labels/Reader args；Reader 选项尊重 `args.reader`。
- `_input_names` 在 runner/graph/import 边界剥离。

## 安全与资源

- heatmap `max_cells`（默认 4,000,000）/`max_pixels`（默认 40,000,000）阻止超大矩阵渲染。
- 严格参数校验、数值字符串归一化、坐标/计数精度保持。

## 验证

- 全量 pytest：**440 passed, 12 skipped, 0 failed**。
- 14/14 verify、49/49 demo、29 个独立 SOP。
- registry check、ruff `--select F`、compileall、portability 通过。
- Studio workspace 导入与 C 盘 workspace + D 盘数据跨盘 job 实测通过。

## 兼容性/限制

- 相对路径仍是共享任务推荐形式；绝对路径适合单机。
- 9 条 route 模板仍缺合成 pytest fixture；真实数据 demo 已覆盖。
- 前端视觉测试由用户执行；生产 bundle 已重建。
- Windows 环境快照：[conda](../environment/windows-biopipe-conda.yml) / [pip](../environment/windows-biopipe-pip-freeze.txt)。
