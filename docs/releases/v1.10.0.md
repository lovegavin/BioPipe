# Operon 1.10.0

Backend/application release. Adds four statistics operators and no new Readers:
exact Poisson tests, binomial interval estimates, chi-square goodness of fit and
redundancy analysis. Registry: **443 operators / 93 Readers / 7 providers / 24
route templates**.

## New operators

| Operator | Provider | Purpose |
| --- | --- | --- |
| `proportion_ci` | `operon-core` | Wilson, Clopper-Pearson, Agresti-Coull, Jeffreys and Wald intervals for one proportion |
| `poisson_test` | `operon-core` | Exact Poisson rate test (two-sided, greater, less) with gamma exact confidence intervals |
| `chisq_gof` | `operon-core` | Chi-square goodness of fit against uniform or user-supplied probabilities |
| `rda` | `operon-core` | Redundancy analysis of a response matrix on centred predictors |

All four take a numeric `[sample, feature]` table (RDA takes response and
predictor tables that must share sample labels), return a declared numeric Form
and keep method metadata in `info`.

## Authoritative comparisons

| Operator | Reference | Checked values |
| --- | --- | --- |
| `proportion_ci` | R `binom.test`, `prop.test(correct = FALSE)` | 30/100 Clopper-Pearson 0.2124064–0.3998147; 0/5 upper 0.5218239; Wilson interval matches at 1e-6 |
| `poisson_test` | R `poisson.test` | 5 events / 1 exposure against rate 2: p = 0.05265302, CI 1.623486–11.66833; 0 / 2 exposure CI upper 1.84444 |
| `chisq_gof` | R `chisq.test` | counts 10/20/30 against 0.2/0.3/0.5: chi2 = 0.555556, df = 2, p = 0.757465 |
| `rda` | R `vegan::rda` | constrained eigenvalues 1.36595192 and 1.03587421 |

The Poisson two-sided p-value follows R's equal-density rule (the smaller tail
plus every outcome whose density is no larger than the observed one), not the
common `2 * min(tail, tail)` approximation; the approximation differs by up to a
factor of two on the smallest counts.

## Bounds and limits

- `proportion_ci` covers a single proportion per row. It does not implement
  stratified or matched intervals, and the Wald interval is reported as-is
  (including its known poor coverage at extreme proportions).
- `poisson_test` compares one observed count against a null rate. It does not
  implement two-sample rate ratios; for those use `fisher_alpha`, `chisq_gof` or
  a route-level comparison.
- `chisq_gof` does not apply a continuity correction and does not warn
  automatically about expected counts below five; inspect `expected` in the
  output before drawing conclusions.
- `rda` fits unconstrained linear predictors, returns constrained eigenvalues
  only, and performs no permutation test. Use `cca` for correspondence analysis
  or `pcoa` for unconstrained ordination.
- Intervals and tests are frequentist and assume independent observations;
  repeated measures need an explicit mixed model (`glmm_logistic`,
  `linear_mixed_model`).
