# Operon 1.59.4

Patch alignment for the hard-capability queue. `boltz_predict` now builds the
actual Boltz CLI invocation and declares the parameters it passes, and
`docs/design/hard_capability_status.md` records which capabilities are verified,
which are wrapper-aligned but weight-blocked, and which cannot be verified in
this environment. Counts stay at **653 operators and 101 Readers**.

## Fixed

- `boltz_predict`: `--accelerator cpu|gpu` instead of the non-existent
  `--device`; `--output_format`, `--sampling_steps`, `--diffusion_samples`,
  `--num_workers`, `--no_kernels` added; affinity is expressed through the YAML
  `properties.affinity` block rather than a CLI flag. The five new parameters
  are declared in the parameter JSON (the registry rejected undeclared reads).

## Documented

- `docs/design/hard_capability_status.md`: Foldseek is verified end to end;
  Boltz, AntiFold, OpenFold/AF2 and Pfam/HMMER are blocked on network or
  GB-scale downloads, with the concrete failure observed for each.

  with local assets, Boltz fake official-layout runner).
