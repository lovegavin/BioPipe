# Operon 1.50.2

Release date: 2026-11-02

Patch release for the operator icon registry.

## Fix

`vina_pose_cluster` declared the `SquaresFour` phosphor icon, which is also the
generic placeholder used by the Studio canvas whenever a name is not
registered. The operator presentation test therefore could not tell the two
apart and failed with "vina_pose_cluster: expected ... not to be ...". The
operator now declares `CirclesThree`, a registered glyph that matches its
clustering semantics.

## Verification

- `frontend/src/operatorPresentation.test.tsx`: the catalog-wide placeholder
  check passes again (23 tests in that file).
- Full frontend suite on Windows: 117 tests, build succeeds.
