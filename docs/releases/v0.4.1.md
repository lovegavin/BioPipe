# BioPipe Studio 0.4.1

Saved workflows now run after a bundled-source update without repeatedly asking
users to repin. Compressed input declarations, import selection and execution
follow the same Reader capabilities. Both Windows desktop variants include these
fixes and the author's latest upstream engine changes.

## Saved workflows and bundled pins

- New runs resolve recognized historical bundled pins to the installed source
  and record the replacement in the new job's lock and diagnostics.
- Old job files, logs and registry snapshots remain unchanged. This migration
  does not recreate an unavailable historical implementation.
- Source fingerprints are refreshed after source changes instead of retaining
  a stale process-wide value. A worker still rejects code changed after its job
  was created. Unknown pins and installed-wheel pins remain strict.
- `scripts/diagnose_pins.py` provides read-only diagnosis. The legacy
  `scripts/repin_all.py` entry point now diagnoses instead of rewriting history;
  running it is not an upgrade prerequisite.

## Compressed Readers

- GAF declares its native gzip support so the desktop accepts `.gaf.gz`.
- H5AD, Parquet and BGEN distinguish their internal compression from outer
  `.gz`, `.bz2` and `.xz` wrappers, which are decoded to temporary disk using
  bounded copy buffers before parsing.
- GAF and VCF accept uppercase `.GZ`. Import filters and runtime selection share
  declared suffix rules, including explicit errors for unsupported combinations.
- Compressed-path sibling checks avoid confusing binary PLINK BED with interval
  BED. Temporary decoding preserves the basename and cleans parser sidecars.
- Custom metadata probes receive the same prepared input as reads. The default
  file-size probe still uses metadata only. Existing disk preparation, streaming,
  memory planning and emergency spill remain available.
- Decompression failures retain their specific error and traceback in job logs.

See [input formats](../input_formats.md) for the supported wrapper matrix.
ZIP/tar archives and arbitrary `.zst` inputs are not implicitly supported.

## Upstream integration

Includes upstream engine v4 and its patch through `82e232a`: CRLF/blank-line
parsing fixes, FASTA sequence encoding metadata, and eleven new operators for
sequence, annotation, interval and peak-to-gene analysis. The generated catalog
contains 64 operators, 15 Readers, six provider packages and five registered
route templates. Additional upstream workflows are available as YAML examples.
See [upstream changes](../changelog/upstream/v4.md).

## Downloads

- **BioPipe-Studio-v0.4.1-Windows-x64.zip**: recommended for end users. Includes
  CPython 3.11, built-in CPU dependencies, .NET and the official WebView2
  bootstrapper. Extract the entire archive and double-click the EXE. Missing
  WebView2 installation and newly added dependencies require internet access.
- **BioPipe-Studio-v0.4.1-Windows-x64-Lite.zip**: desktop host and application
  source for users with an existing compatible Python environment and WebView2.
- **biopipe_studio-0.4.1-py3-none-any.whl**: Python/SDK distribution.
- **pgenlib-0.95.1-biopipe-windows-source.tar.gz**: matching source for the bundled
  Windows PLINK 2 extension.

Both desktop variants use the existing shared Studio profile. Keep all extracted
files together; no developer-machine path or profile is shipped. File hashes,
resolved dependency versions and validation results accompany the release.
