# Operon 1.57.0

Expansion batch adding four operators, reaching **647 operators and 101
Readers**; no existing contract changes.

## Added

- `structure_protonation_sites` — per-residue pKa estimates shifted by nearby
  opposite charges, with charged fractions at a user pH and a net-charge
  summary. This is the first step toward pH-dependent interface scoring.
- `sequence_isoelectric_point` — EMBOSS-style pKa set, bisection pI and net
  charge at a reference pH.
- `sequence_beta_propensity` — Chou-Fasman beta-propensity hot-spot windows for
  aggregation and developability triage.
- `esm_embedding_isolation_forest` — scikit-learn isolation forest over an
  embedding matrix with decision scores and outlier flags.

## Boundaries

- The protonation model is a local-charge heuristic, not PROPKA or a
  constant-pH simulation; pKa shifts ignore hydrogen bonds and desolvation.
- Beta propensity is the Chou-Fasman table, not a trained amyloid predictor.
