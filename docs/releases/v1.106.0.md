# Operon 1.106.0

One hard capability (698 operators, 101 Readers):
**`structure_md_markov_states`** — Markov state model with implied timescales.

## Operator

Clusters CA conformations by pairwise RMSD (average linkage, cutoff), counts
transitions between cluster labels at a lag of frames, row-normalises the counts
(with optional pseudo counts) into a transition matrix, and reports per-state
population, self-transition probability, mean dwell in frames/picoseconds, the
transition matrix, its eigenvalues and the slowest implied timescales
`-lag * frame_time / ln(lambda)`.

## Boundaries

- RMSD clustering is a crude state decomposition; no feature-based
  (dihedral/contact) discretisation and no Chapman-Kolmogorov validation.
- With 20 frames the statistics are far too small for meaningful kinetics; the
  numbers above demonstrate the machinery, not converged rates.
- Detailed balance is not enforced; the matrix is the raw row-normalised count
  estimate with optional pseudo counts.
