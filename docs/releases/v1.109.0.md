# Operon 1.109.0

One hard capability (701 operators, 101 Readers):
**`structure_md_rotamer_states`** — chi1 rotamer populations, entropy and
transitions along a trajectory.

## Operator

Parses the topology for complete chi1 atom sets (N-CA-CB-XG, XG selected per
residue by the existing `CHI1` table), evaluates the chi1 dihedral for every
residue and frame with the shared `structure_chi_angles.dihedral`, classifies
the angle into the nearest staggered rotamer (g+ 60°, t 180°, g- -60°) and
reports populations, rotamer entropy (nats), transition counts and the mean
angle.

## Boundaries

- Only chi1 is classified; chi2/chi3 rotamers and backbone-dependent rotamer
  libraries are not modelled.
- Entropy is the discrete three-state Shannon entropy of the sampled frames; a
  20-frame run cannot resolve rare rotamers.
- Rotamer boundaries are the ideal staggered angles, not a library like
  Dunbrack.
