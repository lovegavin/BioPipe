# Operon 1.123.5

## Fixed

- The ESM-3 and AntiFold environments fell back to source builds of
  `scipy`/`scikit-learn` on this host, so the environments stayed incomplete
  and six `esm3_*` dependency entries failed. Both recipes now pin versions
  with wheels for their interpreters (`numpy==2.1.3`/`scipy==1.14.1` for
  ESM-3; conda `numpy=1.26` + `scikit-learn=1.6` and `scipy==1.13.1` for
  AntiFold), and environment requirements are installed with
  `--prefer-binary`.

Backend version: 1.123.5 (operators 709, Readers 101).
