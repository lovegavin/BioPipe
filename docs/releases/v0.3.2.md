# BioPipe Studio 0.3.2

This patch fixes Windows desktop startup when a valid analysis environment exists
but is not on Explorer's PATH. The previous relocation check added Python to PATH,
so it missed the ordinary double-click failure.

## Changes since 0.3.1

- Remember a successfully used interpreter in a machine-local bootstrap file,
  shared by development startup and all desktop release folders. Every startup
  revalidates the interpreter; stale or corrupt hints allow other candidates.
- Discover Conda's registered environments and standard Windows Python
  registrations without requiring terminal activation.
- Offer an interpreter picker when automatic discovery fails. Validate version
  and core dependencies before saving; `--select-runtime` reopens the picker.
  Explicit environment/config overrides retain priority.
- Keep packaged configuration relative and automatic. Add active-source and
  package path audits, and omit developer source/PDB paths from release binaries.
- Include all required core schema packages in the portable Conda environment.

## Install or upgrade

Extract `BioPipe-Studio-v0.3.2-Windows-x64.zip` completely and double-click
`BioPipe Studio.exe`. If requested, choose the `python.exe` inside your existing
Python 3.11+ environment. For new environments, follow `START_HERE.txt`.
WebView2 is required; .NET and the frontend are bundled. Python remains separate.

The runtime hint `~/.biopipe/runtime.json` is created on the destination computer,
is independent of canvas profiles, and is never shipped in the ZIP. The shared
canvas/profile remains `~/.biopipe/studio`. No route or data migration is required.
The engine, operators, Readers, SDK protocol and memory manager are unchanged.

## Validation

- Reproduced the failure in the 0.3.1 release executable; explicitly selecting the
  already-installed environment passed, confirming discovery was the cause.
- Regression checks cover empty PATH, no activated venv, relocated/non-ASCII
  folders, Python-to-desktop registration, stale/corrupt hints, explicit invalid
  overrides and Conda registrations.
- Real WebView2 startup, draft persistence and shutdown pass without PATH changes.
- Profile, desktop/backend and engine portability regression tests pass.
- Active source and the final package pass the developer-path audit.

Previous releases and the historical source in `legacy/` remain available.
Attachment digests are listed in `SHA256SUMS.txt`; the ZIP includes a file manifest.
