# Operon 1.53.2

Patch release publishing two design documents and the corrected fixtures for the
pending v1.54.0 test batch. v1.53.1 contained only the version bump because the
document paths were staged outside the repository; this release corrects that.
The library stays at **635 operators and 101 Readers**.

## Added

- `docs/design/minibinder_vhh_design_route.md` — the shipped minibinder/VHH
  design loop, the operator/Reader inventory behind it, binder-class semantics
  (neutral/antagonist/agonist) and an explicit statement that pH-dependent
  binding is not implemented.
- `docs/design/competitive_landscape.md` — comparison with RFdiffusion,
  BindCraft, ColabDesign, ProteinMPNN, LigandMPNN, IgFold, AntiFold, Boltz,
  Chai, AlphaFold3 and with workflow projects (Nextflow, Snakemake, Galaxy,
  CWL), plus the moat assessment and roadmap.
- `docs/README.md` links both notes under "Design notes".

## Fixed

- `tests/test_extension271.py`–`275.py` now match the shipped operators:
  dict label maps, real `Context` objects, single-sequence transmembrane spans,
  sequon-based liability positions, and the epoxide ring-opening reaction
  template for pairwise enumeration.

## Verification

- `python -m operon registry check`: 635 operators / 101 Readers / 7 packages
  / 24 routes, `errors []`.
- `pytest tests/test_extension271.py`–`275.py`: 25 passed.
- Focused release gate plus the six packaging modules.
- Windows verification on `<Operon-directory>` (version, counts, tests, routes, frontend).

## Boundaries

- Documentation and fixtures only; no operator contract or execution
  behaviour changes. The roadmap items named in the landscape note (packaged
  binder route, state-specific agonism, pH scoring, affinity estimation) remain
  unimplemented.
