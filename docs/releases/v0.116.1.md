# Operon Studio 0.116.1

This is the stable Windows release of the unified application and protocol-v3
operator library. It includes the features described in [0.116.0](v0.116.0.md)
and fixes Windows path-length failures found during candidate acceptance.

## Windows cache compatibility

Operator installation, metadata-only refresh, restore and rollback now handle
cache paths beyond the traditional Windows path limit. The installer adapts
filesystem and pip arguments at their I/O boundaries. Saved registry paths,
generation locks and independently frozen parameter JSON remain portable.

The same handling covers resumable transfer objects, receipts and filename
aliases, including the bounded-copy fallback when hard links are unavailable.
Symlink/junction rejection, input allowlists and content verification remain.

## Unified application and agent access

- CLI and MCP use the shared workflow, task and artifact services without
  needing an open desktop window.
- Read, edit and run permissions are separate; scientific execution requires
  run permission and durable request identities prevent duplicate submissions.
- A real desktop selection can be read through MCP. One batch of visible
  graph edits can be undone in one operation. Headless services do not create
  a fictitious selection or canvas session.
- Memory admission, cache spilling, streaming contracts, remote execution and
  independent workflow/job parameter files are preserved.

The release acceptance helper also handles FastMCP's single-item and multi-item
session-list representations without requiring a manually supplied session ID.

## Packages and specialist-tool example

- **Full:** Windows x64 desktop with its own Python 3.11 runtime and declared
  Windows-compatible Python dependencies; no system Python setup is needed.
- **Lite:** the same desktop application using an existing supported Python.
- **Library 1.1.0:** separately installable catalog with 405 operators,
  88 Readers, 493 Markdown guides and independent parameter JSON sidecars.
  Existing detached libraries are upgraded explicitly, preserving user edits.
- **IGV example:** a v3 SDK operator exports computed intervals into standard
  BED/bedGraph files through the public artifact API. The accompanying synthetic
  result archive can be opened as an IGV session. IGV remains a separate app.

The runtime manifest lists Python dependencies included for 486 Windows-eligible
extensions and seven entries needing another execution environment. Linux-native
tools and separately managed R runtimes are not bundled as Windows Python packages.

`VERIFICATION.md` and `SHA256SUMS.txt` on the release page record final acceptance
and archive checksums. The 0.116.0 candidate remains a prerelease; its tag is not
moved. The old main source remains under `legacy-main-20261101`.
