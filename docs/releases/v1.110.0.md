# Operon 1.110.0

One hard capability (702 operators, 101 Readers):
**`structure_md_dssp_transitions`** — DSSP secondary-structure state kinetics.

## Operator

Runs mkdssp on every trajectory frame, maps the eight DSSP codes onto
helix/strand/coil, and reports per-residue populations, transition counts and
mean dwell (frames and picoseconds), plus the global 3x3 coarse transition
matrix.

The DSSP 4.x text layout was verified against a real frame: the residue token is
the one-letter code, so the operator maps it back to the three-letter name
before matching topology labels (`chain:RESNAME:number`). The shared
`structure_dssp_segments.run_dssp` call is unchanged.

## Boundaries

- Coarse three-state reduction loses turns/bends (both folded into coil) and
  the 3_10/pi-helix distinction.
- DSSP is run per frame, so cost scales with the number of frames; 20 frames
  give only illustrative kinetics.
- The operator requires mkdssp on PATH and reports a clear error otherwise.
