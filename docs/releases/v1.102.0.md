# Operon 1.102.0

One hard capability (694 operators, 101 Readers):
**`structure_md_communication_path`** — allosteric communication path from a
dynamic cross-correlation matrix.

## Operator

Trajectory frames (`.npy`, nanometres) plus a topology PDB are superposed on CA
atoms, a covariance matrix is built, normalised into a dynamic cross-correlation
matrix `C_ij / sqrt(C_ii C_jj)`, and converted into positive edge weights
`w_ij = -ln |C_ij|` (edges below `min_correlation` are removed). A Dijkstra
search then reports the shortest allosteric path between a source and a target
residue with per-step residue numbers, edge weights and cumulative weights.

## Boundaries

- The cross-correlation matrix is a linear, harmonic approximation from a short
  trajectory; with N frames at most N-1 modes are resolvable.
- Paths are graph artefacts of the chosen correlation threshold; they rank
  coupling, not causality, and the operator states this in its description.
- CA atoms only.
