# Operon 1.90.0

One hard capability: **`structure_md_salt_bridge_occupancy`** (679 operators,
101 Readers). It tracks acidic (ASP/GLU) and basic (LYS/ARG/HIS) side-chain
atom pairs across MD frames and reports how often each pair stays inside the
salt-bridge cutoff.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB), optional `chains` filter,
  `cutoff`, `min_occupancy`, `stride`, `bond_dim`, `output`.
- Output `[salt_bridge, statistic]`: `occupancy`, `mean_distance`,
  `min_distance`; labels `A:10:ASP-B:20:LYS`; info `n_frames`, `n_acidic`,
  `n_basic`, `n_salt_bridges`, `cutoff`, `min_occupancy`, `stride`.
- Acidic atoms: ASP OD1/OD2, GLU OE1/OE2. Basic atoms: LYS NZ, ARG NH1/NH2/NE,
  HIS ND1/NE2. Distances are the minimum over the atom pairs of each residue
  pair per frame.

## Boundaries

- Histidine is treated as always basic; no protonation-state dependence.
- Only side-chain terminal atoms are considered, so backbone-mediated contacts
  and bridging waters are out of scope.
