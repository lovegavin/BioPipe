# Operon 1.122.1

## Fixed

- The managed installer crashed with `NameError: name 'prefix' is not defined`:
  the isolated-environment step is invoked from `ensure_requirements`, which has
  no `prefix` argument. It now derives the deployment prefix from
  `sys.prefix`, so a fresh install can create dedicated operator environments
  (AntiFold, ESM-3) after the shared environment is ready.

Backend version: 1.122.1 (operators 709, Readers 101).
