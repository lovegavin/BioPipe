This batch adds three statistical operators and one community-ecology
estimator, each with a deterministic external oracle.

## Capabilities

| Operator | Provider | Description |
| --- | --- | --- |
| `weighted_kappa` | `operon-core` | Weighted Cohen's kappa for two numeric raters, with linear or quadratic disagreement weights, standard error from the `irr::kappa2` variance formula, z statistic and two-sided p value. |
| `turning_point` | `operon-core` | Wald-Wolfowitz turning point test of serial randomness. Consecutive ties are removed the way `randtests::turning.point.test` removes them before counting turning points. |
| `periodogram` | `operon-core` | Raw periodogram of one numeric series: no taper, no smoothing kernel, optional mean removal or least-squares detrending. |
| `specpool` | `operon-microbiome` | Chao, first- and second-order jackknife and bootstrap species-pool richness estimators with the standard errors reported by `vegan::specpool`. |

## Limits

- `weighted_kappa` requires exactly two raters and numeric ratings. Category
  levels are the sorted distinct ratings; the operator does not rescale ratings
  or check that both raters used the same scale.
- `turning_point` uses the normal approximation of the turning-point statistic;
  no exact or permutation p value is reported. The test assumes independent
  identically distributed observations.
- `periodogram` returns the raw periodogram only, with `df = 2` per bin. It has
  no taper, no smoothing, no confidence bands and no zero padding; for odd
  series length the last observation's Nyquist contribution is not used.
- `specpool` follows the `vegan::specpool` variance formulas, including the
  small-sample correction and the bootstrap pair-absence covariance. It reports
  the estimators, not the observed accumulation curve; use `specaccum` for
  species accumulation.
- All four outputs use the shared float32 `Form` representation, so tests assert
  with tolerances between `1e-5` and `1e-6` rather than exact equality.
