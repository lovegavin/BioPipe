# Operon 1.82.0

Twenty-third real-computation batch: **RNA ensemble statistics**. The library
grows to **671 operators and 101 Readers**.

## Added

- `sequence_rna_ensemble` (`SequenceRnaEnsembleStep`, category Sequence, arity
  1, output `[sequence, statistic]`):
  - runs the ViennaRNA partition function (`RNAfold -p --noPS`, temperature and
    dangles configurable);
  - reports `mfe`, `ensemble`, `mea_energy`, `mea_diversity`,
    `mfe_frequency`, `ensemble_diversity` and `n_pairs`;
  - info carries the MFE and MEA dot-bracket structures.

## Evidence (authority: ViennaRNA 2.5.1 `RNAfold -p`)

- Yeast tRNA-Phe (76 nt): MFE **-22.40** kcal/mol, ensemble free energy
  **-24.13**, MEA **-3.01** with diversity 16.21, MFE frequency **0.0607**,
  ensemble diversity **23.38** - the frequency and diversity values match the
  CLI line exactly.
- Hairpin `GCGCUUCGCCGCAAAAAA`: MFE -2.80, ensemble -3.07, MEA -2.80
  (d=0.99), MFE frequency 0.64388.
- `pytest tests/test_extension311.py`: 5 passed (CLI tests skip where RNAfold
  is absent).

## Boundaries

- Only the summary statistics and two structures are exposed; per-pair
  probabilities (`_dp.ps` matrix) are not parsed.
- The ensemble model is ViennaRNA's Turner 2004 parameter set; no constraints
  or modified nucleotides are supported.
