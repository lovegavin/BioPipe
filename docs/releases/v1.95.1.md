# Operon 1.95.1

Patch release: `prodigal_genes` is now verified against a real Prodigal run
instead of only resource-gated fake-runner tests. The library stays at
**684 operators and 101 Readers**.

## Verified

- Prodigal 2.6.3 installed from the distribution packages
  (`apt-get install prodigal`), no database required.
- Real run on the phage lambda genome (48 502 bp, committed as
  `tests/fixtures/lambda_genome.fa`): 61 CDS, first CDS 191-736 (+), exactly
  matching the CLI GFF output. The real test runs only with
  `OPERON_PRODIGAL_REAL=1` and is skipped otherwise.
- `docs/large_resources.md` gained an installation section;
  `docs/design/hard_capability_status.md` records prodigal as verified.

## Verification

- `pytest tests/test_extension252.py` with `OPERON_PRODIGAL_REAL=1`: 4 passed.
- Registry check: 684 operators / 101 Readers / 7 packages / 24 routes,
  `errors []`.
- Packaging gate passes; Windows keeps skipping the real test because Prodigal
  is not installed there.

## Boundaries

- The verification covers one genome; gene predictions for other organisms
  depend on Prodigal's own model, not on this wrapper.
