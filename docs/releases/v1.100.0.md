# Operon 1.100.0

Two trajectory-level hard capabilities (691 operators, 101 Readers):
**`structure_md_pca`** (essential dynamics) and
**`structure_md_quasiharmonic_entropy`** (Schlitter configurational entropy).

## Operators

### structure_md_pca

Loads a `.npy` frame stack (frames, atoms, 3; nanometres) and a topology PDB,
selects CA atoms, superposes every frame onto the first with Kabsch, builds the
3N x 3N coordinate covariance matrix and reports the slowest eigenmodes:
`eigenvalue`, `variance_fraction`, `cumulative_fraction`. Info carries frame and
atom counts, the variance sum and the number of retained modes.

### structure_md_quasiharmonic_entropy

Uses the same covariance matrix and evaluates
`S = 0.5 k_B sum ln(2 pi e lambda_i)` over non-zero eigenvalues. Rows are the top
modes by contribution (eigenvalue, `entropy_kb`, fraction) plus a `total` row;
info carries `total_entropy_kb`, `entropy_kj_mol_k` and `entropy_per_dof_kb`.

## Verification

- `tests/test_extension330.py`: 3 passed — Kabsch invariance under rotation, run
  round trip, error paths, and an independent **ProDy PCA** oracle on the same
  aligned DCD (variance fractions agree to 2e-3).
- `tests/test_extension331.py`: 2 passed — closed-form analytic entropy for a
  diagonal covariance (`6 * 0.5 * (1 + ln(2 pi sigma^2))` to 1e-12), rotation
  invariance, unit conversion to kJ/mol/K, error path.
- Real OpenMM run (1MEL chain A, 1881 particles, 20 frames × 100 steps sample):
  PCA top mode **32.6%** of variance, top-10 cumulative **89.9%**; quasiharmonic
  entropy **27.83 k_B** (0.23 kJ/mol/K) over the 19 non-zero modes (frames - 1,
  as expected for a rank-limited covariance).
- Registry: 691 operators / 101 Readers / 7 packages / 24 routes, `errors []`.

## Boundaries

- The entropy estimate is a harmonic approximation of a finite sample; with
  N frames at most N-1 modes are resolvable, so longer trajectories are needed
  for converged values.
- Only CA atoms are analysed; side-chain entropy is not included.
- `prody` is an optional test dependency; the operators only need NumPy.
