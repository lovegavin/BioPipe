# Operon 1.86.0

One hard capability: **`structure_md_ss_occupancy`** (675 operators, 101 Readers).
It runs DSSP on sampled MD frames and reports per-residue helix, strand and coil
occupancies plus the dominant secondary-structure state.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB), `stride`, `dssp_path`,
  `timeout_seconds`, `residue_dim`, `output`.
- Output `[residue, statistic]`: `helix`, `strand`, `coil`, `dominant`
  (0 = coil, 1 = strand, 2 = helix); info `n_frames`, `n_residues`,
  `mean_helix`, `mean_strand`, `stride`.
- Frames are written by substituting coordinates into the topology lines and
  read by mkdssp 4.2.2; DSSP codes map to helix (`H/G/I`), strand (`E/B`) and
  coil.

## Boundaries

- Frames start with `HEADER    OPERON MD FRAME` because mkdssp 4.x assumes
  mmCIF for header-less input.
- Occupancy describes DSSP assignment, not experimental structure; residues
  missing from a frame count as coil.
