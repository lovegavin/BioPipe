# Operon v1.9.0

Backend application release. One batch of four statistical and machine
learning operators; the Python package version moves to 1.9.0 while the SDK
(3.1.0) and frontend package version are unchanged.

## New capabilities

| Operator | Provider | Inputs | Output |
| --- | --- | --- | --- |
| `manova` | operon-core | response table and group metadata | Pillai, Wilks, Hotelling-Lawley or Roy statistic with F approximation and p value |
| `glmm_logistic` | operon-core | outcome/predictor table and group metadata | fixed-effect estimates, standard errors, z, p, confidence intervals, random-intercept SD and Laplace log-likelihood |
| `qda` | operon-core | feature table and label table | held-out predictions with accuracy and confusion matrix |
| `knn` | operon-core | feature table and label table | held-out predictions with accuracy and confusion matrix |

`manova` follows `stats::summary.manova`: the same eigenvalue
parameterisations and F approximations are used for all four statistics.
`glmm_logistic` fits a random-intercept logistic model with the Laplace
approximation evaluated by Newton iterations for the random effects, matching
`lme4::glmer(nAGQ = 1)`. `qda` estimates per-class covariance matrices and
applies the quadratic log-posterior; `knn` supports uniform and distance
weights with deterministic tie-breaking.

## Authoritative comparisons

| Operator | Oracle | Result |
| --- | --- | --- |
| `manova` | R `stats::summary.manova` | Pillai 1.0179526 / F 6.2193694 / df 4,24 / p 0.00139624; Wilks, Hotelling-Lawley and Roy also matched |
| `glmm_logistic` | R `lme4::glmer(nAGQ = 1)` | coefficients 0.644988 / 0.802245, sigma 0.313439 and log-likelihood -95.1091933 agree to about 1e-5 |
| `qda` | R `MASS::qda` | class means, posteriors and predicted classes matched on a fixed split |
| `knn` | R `class::knn` | predicted classes matched on a fixed split |

The R oracle test regenerates the same data from Python, writes it to CSV and
compares values computed by R.

## Limits

- `manova` requires finite responses, at least two groups with two samples each
  and a non-singular residual covariance; the F approximations are the ones R
  uses, not exact tests.
- `glmm_logistic` supports one random intercept, binary outcomes and a single
  numeric predictor; it is the Laplace approximation (nAGQ = 1), so log-likelihoods
  are not directly comparable with adaptive Gauss-Hermite fits.
- `qda` assumes per-class multivariate normal data; a singular class covariance
  raises an error unless `reg_param` is set. Splits are stratified with a fixed
  seed but are not a substitute for external validation.
- `knn` breaks vote ties by the lowest class index; accuracy on a single split
  is descriptive, not a generalisation estimate.
