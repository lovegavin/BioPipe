# Operon 1.24.0

Released 2026-11-02. This expansion batch adds five capabilities for structural
interfaces, substructure chemistry and ligand-aware sequence design. The
registry now contains **498 operators, 101 Readers, seven providers and 24
route templates**.

## New capabilities

| Operator | Category | What it adds |
| --- | --- | --- |
| `structure_contacts` | Machine Learning | Inter-chain heavy-atom contact network with per-residue contact counts and the nearest approach distance. |
| `structure_hbonds` | Machine Learning | Backbone N-H...O=C hydrogen bonds with the Kabsch-Sander electrostatic model, donor/acceptor counts and the strongest interaction per residue. |
| `rdkit_mcs` | Machine Learning | Maximum common substructure (SMARTS) across a molecule set with per-molecule matched atom counts. |
| `ligandmpnn_design` | Machine Learning | Ligand-aware sequence design through the official LigandMPNN `run.py`, with fixed/redesigned residues, amino-acid bias and omit lists. |
| `ligandmpnn_score` | Machine Learning | Per-residue native-sequence log-probabilities from the official LigandMPNN `score.py`, aggregated over scoring batches. |

## Operator notes

### `structure_contacts`

`contact_count` counts distinct residues of the other chain within `cutoff`
(default 4.0 A); `min_distance` is the closest heavy-atom pair distance. Waters
and other `exclude_resnames` entries are excluded by default, hydrogens are
never considered, and `include_intra` can switch on intra-chain contacts.
Residues without any contact are kept when `min_contacts` is 0, which makes the
output a complete per-residue profile.

### `structure_hbonds`

The operator reimplements the DSSP energy model (Kabsch & Sander, 1983):
`E = 0.084 * 332 * (1/r_ON + 1/r_CH - 1/r_OH - 1/r_CN)` with the amide hydrogen
placed antiparallel to the preceding carbonyl. Proline never donates, bonds
require `E < energy_threshold` (-0.5 kcal/mol) and `r_ON <= max_distance`
(5.2 A), and inter-chain bonds are opt-in. Validation against `mkdssp` 4.2.2 on
a 16-residue helix fixture reproduces DSSP's per-residue donor and acceptor
counts exactly (at the -0.55 threshold that compensates DSSP's one-decimal
energy printing).

### `rdkit_mcs`

Wraps `rdFMCS.FindMCS` and reports the SMARTS pattern, its atom and bond counts
and, per molecule, how many atoms are covered. Atom comparison (`any` or
`elements`), bond comparison (`any` or `strict`), ring matching and the search
timeout are exposed. A timed-out or empty search raises instead of silently
returning nothing.

### `ligandmpnn_design`

Runs the official LigandMPNN `run.py` in the repository directory, parses the
generated FASTA and exposes `overall_confidence` (= exp(-mean NLL)),
`ligand_confidence` and `seq_recovery` per design. `chains_to_design`,
`fixed_positions`, `redesigned_residues`, `omit_AA`, `bias_AA`,
`temperature`, `number_of_batches` and `batch_size` map directly to the official
flags; `device="cpu"` clears `CUDA_VISIBLE_DEVICES` so the same weights run on a
CPU-only host. Native and generated sequences are reported in `info.sequences`.

### `ligandmpnn_score`

Runs the official `score.py` with teacher forcing on the native sequence and
reads the `torch.save` payload it writes. `mean_log_prob` is the mean native
log-probability over scoring batches, `std_log_prob` its spread; residues are
sorted by chain and residue number. The payload keys (`log_probs`,
`native_sequence`, `mask`, `residue_names`) are validated before use.

## Limits

- `structure_contacts` and `structure_hbonds` need a PDB Form with named columns
  on the field dimension; CA-only structures cannot place amide hydrogens.
- `structure_hbonds` reproduces DSSP's electrostatic model, not DSSP's
  secondary-structure assignment.
- `rdkit_mcs` uses the RDKit default timeout; very large molecule sets may need
  a larger `timeout`.
- `ligandmpnn_design` and `ligandmpnn_score` require a local LigandMPNN
  checkout (or `OPERON_LIGANDMPNN_PATH`), a matching weight file and a Python
  environment able to import the official dependencies (`torch`, `prody`,
  `ml_collections`, `dm-tree`). LigandMPNN itself expects NumPy 1.x aliases;
  with NumPy 2 a `sitecustomize` shim providing `np.int`/`np.float`/`np.bool`
  is enough. The reference weight files are 6.7 MB (protein MPNN) and 10.5 MB
  (LigandMPNN).
- Scores are model estimates, not experimental affinities.

## Compatibility

No existing operator ID, port, parameter or output schema changed. Existing
workflows keep their frozen values and pins.
