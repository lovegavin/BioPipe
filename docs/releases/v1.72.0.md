# Operon 1.72.0

Thirteenth real-computation batch: **Boltz-2 binding-affinity predictions**.
The library grows to **661 operators and 101 Readers**.

## Added

- `boltz_affinity_summary` (`BoltzAffinitySummaryStep`, category Machine
  Learning, arity 0, output `[complex, statistic]`):
  - reads one `affinity_*.json` file or every such file under a predictions
    directory;
  - emits `affinity_pred_value`, `affinity_probability_binary` and a
    `has_variants` flag, with `best_name`/`best_value`/`best_probability` and
    the raw summaries in info;
  - validates JSON shape and reports missing keys by name.

## Evidence

- Boltz-2 weights (conf 2.29 GB, affinity 2.06 GB, mols 1.86 GB) fetched from
  the `hf-mirror.com` mirror into `~/.boltz`; `ccd.pkl` and `boltz1_conf.ckpt`
  were already cached.
- A 14-residue peptide plus aspirin ran structure and affinity prediction in
  **40 s on CPU** with an empty MSA.
- Output `affinity_aff.json`: `affinity_pred_value 1.59375`,
  `affinity_probability_binary 0.359375`, plus variant heads
  `1.7266/0.2041` and `1.4609/0.5156`.
- `boltz_affinity_summary` reproduces the values exactly (one row labelled
  `aff`, `has_variants = 1.0`).
- `pytest tests/test_extension301.py`: 4 passed.

## Boundaries

- The affinity value is a model-internal score, not a calibrated IC50; the toy
  peptide complex is used to prove the wiring, not to claim accuracy.
- Boltz-2 needs its three extra weights; without them the config fails at load
  time and the operator is not involved.
- One affinity binder per YAML property block; multi-binder competition is not
  modelled beyond Boltz-2's own variant heads.
