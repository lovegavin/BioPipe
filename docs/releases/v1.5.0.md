# Operon backend 1.5.0

Backend-only release. Application version **1.5.0**; SDK **3.1.0**; protocol
**v3**. 425 operators, 91 Readers, seven provider packages and 24 route
templates.

## Added capabilities

| Operator | Provider | Input | Output |
| --- | --- | --- | --- |
| `neighbor_joining` | `operon-core` | distance matrix `[taxon, taxon_b]` | tree `[node, field]` |
| `upgma` | `operon-core` | distance matrix `[taxon, taxon_b]` | tree `[node, field]` |
| `robinson_foulds` | `operon-core` | two trees `[node, field]` | `[statistic, value]` |
| `gsva_plage` | `operon-expression` | expression `[gene, sample]` + membership `[gene, gene_set]` | `[sample, gene_set]` |

`neighbor_joining` uses the Saitou–Nei criterion with the standard limb-length
formula. `upgma` builds a rooted ultrametric tree from size-weighted cluster
distances. Both emit the same tree table as `NewickReader`
(`parent`, `branch_length`, `depth`, `is_leaf`) so they compose with
`patristic_distance`, `robinson_foulds` and the plotting steps.

`robinson_foulds` compares unrooted bipartitions, excludes trivial splits and
reports `rf`, `max_rf`, `normalized_rf`, false positives and false negatives.
`gsva_plage` applies the PLAGE decomposition: gene-wise z-scores, first right
singular vector per gene set, sign anchored on the largest absolute loading.

## Oracle evidence

| Check | Reference | Result |
| --- | --- | --- |
| NJ pairwise distances | Biopython 1.88 `DistanceTreeConstructor.nj` | additive matrix restored exactly |
| UPGMA branch lengths | Biopython 1.88 `DistanceTreeConstructor.upgma` | pendant lengths and heights match |
| Robinson–Foulds | DendroPy 5.1.3 `unweighted_robinson_foulds_distance` | `rf = 2`, `max_rf = 2`, `normalized_rf = 1.0` |
| PLAGE scores | R `GSVA 1.50.5` `gsva(method = "plage")` | absolute scores within `1e-5`, absolute correlation within `1e-4` |
| PLAGE unit path | first right singular vector of gene-set z-scores | matches direct SVD to `1e-9` |

## Limits

- Tree construction applies to a square, symmetric, finite, non-negative
  distance matrix with zero diagonal; NJ negative branches are clipped to `0`
  and counted in `negative_branches_clipped`.
- `upgma` assumes ultrametric input; the root carries no branch length.
- `robinson_foulds` requires both trees to contain exactly the same tip labels
  and uses unrooted splits only.
- PLAGE scores are sign-ambiguous by construction; the implementation anchors
  each score so the largest absolute loading is positive, which may differ from
  another implementation's sign convention.
- Gene-set membership must use genes present in the expression matrix;
  `min_size` filters smaller sets.
