# Operon Studio 2.0.2

This integrated release includes the author's backend 2.0.0 and the layered
MCP/CLI/API interfaces documented in [the integration notes](v2.0.1.md): 709
operators, 101 Readers, seven providers and 24 routes, with protocol v3 and
SDK 3.1.0 retained. Independent parameter JSON, managed memory, streaming,
emergency spill, SSH transfers and per-host admission remain unchanged.

The 2.0.1 candidate exposed a shutdown problem during real Windows EXE acceptance.
A missing named interpreter such as AntiFold incorrectly entered shared Python
dependency repair, and the repair loop continued to the next operator after
receiving cancellation. This release keeps dedicated environments outside shared
repair, signals cancellation before waiting for execution shutdown, and avoids
refreshing the library after shutdown begins. Missing dedicated environments
remain explicitly unavailable; they are not silently marked ready.

The real-desktop QA harness also now treats an omitted empty undo history as
zero. Windows test fixtures read Unicode explicitly. The old candidate and its
diagnostics remain available for traceability; its assets are not replaced.

Lite uses an existing compatible Python. Full bundles portable Python and shared
CPU dependencies. Model weights, Linux tools, GPU drivers and dedicated model
environments are managed separately. See `VERIFICATION.md` on the release page
for actual checks, desktop acceptance and remaining limitations.
