# Operon 1.45.0

Expansion batch: sequence design and structure-analysis capabilities.

## New operators

- `sequence_codon_adaptation` — codon adaptation index (Sharp & Li 1987) of
  coding DNA sequences against a reference coding set. Codons absent from the
  reference receive the paper's 0.5 pseudo-count, ATG/TGG are excluded from the
  geometric mean by default (configurable), and stop codons are counted when the
  reference defines them. Output: one row per target sequence with `cai`,
  `n_codons`, `n_excluded` and `frac_optimal`.
- `structure_cavity_lining` — rasterises a PDB atom table, selects the largest
  buried cavity (free grid cells unreachable from the box boundary) and reports
  every residue with a heavy atom within `lining_cutoff` of a cavity cell.
  Output: `min_distance` and `n_atoms` per lining residue plus cavity volume in
  the open information.
- `antibody_cdr_graft` — grafts Kabat CDR-H1/H2/H3 loops from a donor VH/VHH onto
  an acceptor framework using the conserved-anchor Kabat assignment of
  `antibody_cdr_kabat`; any subset of CDRs can be grafted. Output: one row per
  graft with acceptor length, grafted length, length delta and graft count; the
  grafted sequence and per-region spans are stored in the open information.
- `proteinmpnn_masked_interface_design` — derives the interface mask from
  heavy-atom contacts between a binder and a target chain group, then redesigns
  only the masked-side interface residues with the official ProteinMPNN runner
  (fixed positions are the complement of the mask on every chain). `mask_side`
  selects binder, target or both; the PDB file must be supplied as
  `structure_path` because the atom table has no atom-name column.

## Verification

- Hand-computed cases: codon weights and CAI of `CTGCTGCTGCTA`/`CTGCTA`
  (`sqrt(1/3)`), the 27 Å³ hollow-cube cavity with its lining residues, CDR
  replacement spans and the interface contact matrix of a two-chain complex.
- Authoritative oracles: Biopython `CodonAdaptationIndex.calculate` for the CAI
  (rel 1e-12 on five targets), residue CDR spans cross-checked against the
  ANARCI-labelled fixtures, and cavity volumes cross-checked with
  `structure_cavity_scan`.
- The interface designer is exercised through a fake `protein_mpnn_run.py` that
  records the forwarded `--fixed_positions_jsonl` payload, verifying the
  fixed-position complement without weights.
- Focused suite `tests/test_extension229.py`–`232.py` passes (18 tests);
  protocol and reference-doc suites pass (33 tests in total).
- Registry: 592 operators, 101 Readers, 7 packages, 24 routes, no errors.

## Compatibility

All four operators are new IDs with their own parameter schemas; no existing
operator, Reader, contract or saved workflow changes.
