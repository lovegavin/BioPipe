# Operon 1.84.0

Twenty-fifth real-computation batch: **flexible-ligand PDBQT preparation**. The
library grows to **673 operators and 101 Readers**.

## Added

- `ligand_pdbqt_flexible` (`LigandPdbqtFlexibleStep`, category Docking, arity
  0, output `[ligand, statistic]`):
  - embeds the SMILES with RDKit (ETKDGv3 + MMFF/UFF) and Gasteiger charges;
  - detects AutoDock torsions (acyclic single bonds with heavy degree >= 2 on
    both atoms, amide bonds excluded) and emits a `ROOT ... ENDROOT` block plus
    nested `BRANCH`/`ENDBRANCH` trees and `TORSDOF`;
  - returns torsion counts, heavy-atom count, the PDBQT lines in info and can
    write the file to `output_path`.

## Evidence (authority: AutoDock Vina 1.2.7 engine + RDKit)

- Aspirin: 3 torsions, 3 balanced BRANCH/ENDBRANCH blocks; Vina parses the file
  and docks it into 1MEL (exhaustiveness 8, 5 modes): best **-2.43 kcal/mol**
  with torsion penalty 0.43 and internal strain -0.37, versus -3.00 for the
  rigid ligand of v1.83.0.
- Ethanol: no rotatable heavy-heavy bond, `TORSDOF 0`, no BRANCH lines.
- Butane: one torsion, Vina accepts the tree.
- `pytest tests/test_extension313.py`: 6 passed, including the real-engine
  docking test.

## Boundaries

- Polar hydrogens are not written, so hydrogen-bond directionality relies on
  Vina's united-atom treatment; receptors remain rigid and uncharged.
- Torsion detection follows the AutoDock 4 rule set; RDKit's strict
  `CalcNumRotatableBonds` can differ (aspirin: 3 vs 2), and the operator reports
  both numbers for comparison.
- Ester and sulfonamide handling is not special-cased beyond amides.
