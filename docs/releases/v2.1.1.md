# Operon 2.1.1

Patch release. No capability changes; the registry stays at **713 operators /
101 Readers / 7 packages / 24 routes**.

## Fixes

- `tests/test_extension350.py` now imports Biopython lazily, after the real-run
  gate and the fixture checks. Windows checkouts without Biopython collect and
  skip the real antiSMASH test instead of failing at import time. The
  `antismash_bgc` operator itself does not depend on Biopython.

## Verification

- Focused suite (operators 350-353, dependency contract, protocol and reference
  documents) passes on Linux; the real runs remain gated by `OPERON_*_REAL=1`.
- Packaging and release-metadata tests pass with the 2.1.1 version strings.
- Windows: registry check 713 / 101 / 7 / 24, `errors []`; both reference routes
  `CHECK OK`; operator tests pass with the real-run tests skipped.
