# Operon 1.125.1

## Fixed

- The service-side dependency snapshot dropped `resources.environment` and
  `resources.external_tools` when building its entries, so the probe fell back
  to the shared interpreter and reported every environment/tool-backed
  operator as failed (`依赖 0/6`). The snapshot now carries both fields and the
  fingerprint covers them, so a scope of six shows six passes.

Backend version: 1.125.1 (operators 709, Readers 101).
