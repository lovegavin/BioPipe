# Operon 1.104.0

One hard capability (696 operators, 101 Readers):
**`sequence_rna_accessibility`** — Boltzmann-ensemble unpaired probabilities and
accessible single-stranded segments.

## Operator

Uses the ViennaRNA Python bindings (installed with `pip install ViennaRNA`,
2.7.2 here) to compute the partition function at a given temperature, converts
the upper-triangular pair-probability matrix into a symmetric one, and reports
per-base `unpaired_probability` / `paired_probability` plus every contiguous
run with `unpaired_probability >= threshold` and length `>= min_length`. Info
carries the MFE energy and structure, the mean/max unpaired probability, the
segment list and the pair-probability sum.

## Boundaries

- Single-sequence partition function only: no constraints, no SHAPE data, no
  coaxial stacking refinements from the CLI.
- Accessibility is a thermodynamic ensemble property; it is not a structure
  prediction and carries no pseudoknot support.
- The bindings are optional; the operator raises an install hint when missing.
