# Operon backend 1.6.0

Backend-only release. Application version **1.6.0**; SDK **3.1.0**; protocol
**v3**. 429 operators, 91 Readers, seven provider packages and 24 route
templates.

## Added capabilities

| Operator | Provider | Input | Output |
| --- | --- | --- | --- |
| `simper` | `operon-microbiome` | abundance `[sample, taxon]` + metadata `[sample, feature]` | `[taxon, statistic]` |
| `mrpp` | `operon-microbiome` | abundance `[sample, taxon]` + metadata `[sample, feature]` | `[statistic, value]` |
| `specaccum` | `operon-microbiome` | abundance `[sample, taxon]` | `[sites, statistic]` |
| `cophenetic_correlation` | `operon-core` | tree `[node, field]` + distance `[sample, sample_b]` | `[statistic, value]` |

`simper` decomposes the Bray-Curtis dissimilarity between two groups into
per-taxon contributions `|x_ik - x_jk| / (sum_k x_ik + sum_k x_jk)`, averaged
over all cross-group sample pairs. It reports `average`, `ava`, `avb`, `sd`,
`ratio` and the cumulative contribution after sorting by decreasing average.

`mrpp` computes the chance-corrected within-group agreement
`A = 1 - delta / E.delta` with group-size weights, and a permutation p-value
using the same add-one correction as `vegan::mrpp`.

`specaccum` computes the exact expected species richness for every number of
sampling units and the conditioned standard deviation, treating a taxon as
present when its abundance is greater than zero.

`cophenetic_correlation` compares tree patristic distances with an observed
sample distance matrix and reports the Pearson correlation, its square and the
number of tips and pairs.

## Oracle evidence

| Check | Reference | Result |
| --- | --- | --- |
| SIMPER contributions | R `vegan` `simper(permutations = 0)` | average, ava, avb and overall match to `1e-10` |
| MRPP delta | R `vegan::mrpp` | `delta = 2.9913224123`, `E.delta = 8.7587793955`, `A = 0.658477` |
| Species accumulation | R `vegan::specaccum(method = "exact", conditioned = TRUE)` | richness matches to `1e-6` |
| Cophenetic correlation | R `ape::cophenetic.phylo` followed by Pearson correlation | `r` matches to `1e-12` |

## Limits

- `simper` supports exactly two groups and the Bray-Curtis decomposition; it
  reports the `permutations = 0` output and does not compute permutation
  p-values.
- `mrpp` supports `euclidean`, `bray` (Bray-Curtis) and `manhattan` distances;
  weights are group sizes (`weight.type = 1`). The p-value is seeded and
  reproducible in Operon but is not identical to any particular R RNG stream.
- `specaccum` implements the exact (rarefaction) method with the conditioned
  standard deviation, and requires at least two sampling units. A taxon counts
  as present when its abundance is greater than zero.
- `cophenetic_correlation` requires identical tip and matrix labels, at least
  three tips and non-constant distances; it uses the Pearson correlation only.
- When a sample point has exactly zero variance, `vegan` can return `NaN` from
  floating-point round-off while this operator reports `0`.
