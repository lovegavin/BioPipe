# BioPipe Studio 0.3.1

This patch makes the operator library consistent and easier to scan. The Windows
desktop package includes the same updated presentation as the development UI.

## Changes since 0.3.0

- Merge equivalent English and Chinese category names and group built-in
  operators by function. Each operator appears in one category, including the
  recently added axis-analysis and microbiome operators.
- Use compact monochrome functional icons for non-visual operators throughout the
  library, canvas and inspector. Bin uses an interval-column icon; computation
  operators no longer display large illustrative charts or chart frames.
- Add distinct Dot plot, Violin plot and Composition barplot illustrations while
  retaining the existing chart families. Plot operators keep their chart previews.
- Apply presentation to existing catalog descriptors without rewriting operator
  contracts, package fingerprints or saved workflows. Custom category names and
  explicit provider previews remain available.
- Display the full package version in Studio's status bar.

## Install or upgrade

Download `BioPipe-Studio-v0.3.1-Windows-x64.zip`, extract the entire folder and follow
`START_HERE.txt`. Python 3.11+ with the required dependencies and Microsoft WebView2
Runtime are required. The desktop host bundles .NET and the compiled UI; Python
and analysis environments remain independent. The Python wheel contains the
engine, SDK and CLI/MCP.

The shared profile remains `~/.biopipe/studio`. Existing saved routes, registries
and data remain available when switching to the new desktop folder. All analysis,
reader, streaming and memory-management capabilities from [0.3.0](v0.3.0.md) are
retained. The SDK protocol and bundled provider versions are unchanged.

Previous releases and the original source archive in `legacy/` remain available.
`SHA256SUMS.txt` lists attachment checksums; the desktop ZIP also contains a
per-file manifest with the source commit.

## Validation

- 46 frontend tests passed, with TypeScript and the production build passing.
- Frontend dependency audit reported zero vulnerabilities.
- The Python regression run passed 195 tests; all five plugin-installation checks
  affected by an older installed runtime then passed in an isolated environment
  containing the release wheel. The full plugin/Agent rerun passed 22 tests.
- Real Windows/WebView2 lifecycle checks passed, including frontend bootstrap,
  Agent context, duplicate launch, occupied-port fallback, worker cleanup, draft
  recovery and graceful shutdown.
- Registry validation found 46 operators, 13 readers, six packages and five routes,
  with no errors or drift. Analysis source and provider manifests are unchanged.
