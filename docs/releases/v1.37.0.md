# Operon 1.37.0

Release date: 2026-11-02

Expansion batch adding five operators for design uncertainty, scaffold
diversity, embedding outliers, nucleotide composition and helix geometry.
Backend application version 1.37.0; protocol 3; registry counts 556 operators
and 101 Readers.

## Capabilities

| Operator | Contract | Summary |
| --- | --- | --- |
| `proteinmpnn_perplexity` | inputs 0, output `[position, statistic]` | Runs the official ProteinMPNN conditional-probability pass and reports per-position perplexity, entropy and the most likely probability. |
| `rdkit_scaffold_diversity` | inputs 0, output `[scaffold, statistic]` | Groups a molecule collection by Murcko scaffold and reports occurrence counts, fractions and mean scaffold size. |
| `esm_embedding_outlier_scan` | input `[sample, embedding]`, output `[sample, statistic]` | Ranks embeddings by Mahalanobis distance to the centroid or by mean distance to the k nearest neighbours. |
| `sequence_gc_profile` | input `[sequence, position]`, output `[sequence, statistic]` | Nucleotide composition summary: GC content, third-codon GC, CpG observed/expected, AT skew and sliding-window GC spread. |
| `structure_helix_geometry` | input `[atom, field]`, output `[helix, statistic]` | Detects CA helices and reports axial rise, radius, twist and residues per turn. |

## Design notes

- `proteinmpnn_perplexity` reconstructs the native sequence from the `S` token
  array in `conditional_probs_only/<stem>.npz`; the official runner does not
  write a FASTA in that mode. Probabilities are renormalised over the twenty
  standard amino acids, and perplexity is the effective number of choices
  `exp(H)` in nats.
- `rdkit_scaffold_diversity` reports an `acyclic` bucket for molecules without
  a ring system, so the scaffold ratio includes them.
- `esm_embedding_outlier_scan` uses a ridge-regularised pseudo-inverse of the
  covariance; a degenerate spread yields zero z-scores instead of dividing by
  zero.
- `sequence_gc_profile` accepts DNA or RNA input; `U` is counted as `T`. The
  third-codon statistic is reported for complete codons only and is NaN
  otherwise.
- `structure_helix_geometry` classifies a residue window as helical when both
  the CA(i)-CA(i+1) step and the CA(i)-CA(i+3) span are short enough, then
  measures each run with an SVD axis. Short helices give a slightly biased
  axis, which is documented in the operator description.

## Evidence

- `tests/test_extension190.py` (proteinmpnn_perplexity): token-decoded native
  sequence, normalised probability matrix, hand-computed perplexity/entropy
  (uniform 20 choices gives perplexity 20 and 4.3219 bits; a one-hot position
  gives 1 and 0), fake-runner command assertions, parameter and failure paths,
  and an official ProteinMPNN run on the two-chain fixture (16 positions,
  native `SRALRYYYVKNIIKKV`).
- `tests/test_extension191.py` (rdkit_scaffold_diversity): Murcko stripping,
  hand-grouped scaffolds (benzene/toluene collapse to `c1ccccc1`, ethanol is
  `acyclic`), RDKit recomputation oracle.
- `tests/test_extension192.py` (esm_embedding_outlier_scan): Mahalanobis
  distances against a manual covariance inverse, k-NN hand values, z-score and
  rank semantics, parameter and shape failures.
- `tests/test_extension193.py` (sequence_gc_profile): hand GC/GC3/CpG/AT-skew
  values on `ACGTACGT`, window arithmetic, step output and error paths.
- `tests/test_extension194.py` (structure_helix_geometry): ideal helix
  (rise 1.5 A, radius 2.3 A, 100 degrees per residue), detection of helices
  versus a linear chain, end-to-end PDB run and empty-result behaviour.
- `tests/test_extension195.py`: runner-level contract checks for three of the
  new operators (export files under `output/steps`).

Focused suite (`190`-`195` plus `extension8`, `protocol_v2`,
`reference_docs`): 29 passed with the official ProteinMPNN checkout and
weights. Packaging group remains green.

## Known limits

- `proteinmpnn_perplexity` requires a local ProteinMPNN checkout and uses CPU
  by default; a full GPU run needs `device="cuda"`.
- `rdkit_scaffold_diversity` treats acyclic molecules as one shared scaffold.
- `esm_embedding_outlier_scan` assumes at least three embeddings; it is a
  descriptive outlier score, not a hypothesis test.
- `structure_helix_geometry` detects helices from CA geometry only; it does
  not assign the remaining secondary structure.
