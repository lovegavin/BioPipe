# Operon 1.80.0

Twenty-first real-computation batch: **fpocket pocket detection**. The library
grows to **669 operators and 101 Readers**.

## Added

- `structure_pocket_detect` (`StructurePocketDetectStep`, category Structure,
  arity 1, output `[pocket, statistic]`):
  - writes the heavy-atom structure, runs fpocket, and parses the
    `<stem>_info.txt` summary;
  - reports per pocket: `score`, `druggability`, `volume`, `n_spheres`,
    `mean_radius`, `n_residues`, and the lining-residue centroid;
  - filters by `min_score`, `min_druggability`, `max_pockets`; info carries
    `n_detected`, `best_score`, `best_druggability` and the fpocket output path;
  - launches `.py` runners through `sys.executable` so the test double works
    on Windows.

## Evidence (authority: fpocket 4.0 built from source)

- Real run on 1MEL heavy atoms: **21 pockets detected**, top 5 kept; best score
  **0.317** (druggability 0.005, volume 517 A^3, 52 alpha spheres, 17 lining
  residues), and a second cavity reaches druggability **0.405** (volume
  634 A^3). Runtime 0.7 s.
- `pytest tests/test_extension309.py`: 4 passed (fake-runner contract test plus
  the real-binary test, which skips where fpocket is absent).

## Boundaries

- fpocket is an optional external binary; the operator reports a clear error
  when it is missing. The binary is not bundled with Operon.
- Waters and hetero atoms are stripped before detection; only heavy atoms are
  passed to fpocket.
- Pocket ranking and classification are fpocket's, not re-derived here.
