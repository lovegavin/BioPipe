# Operon 1.36.1

Released 2026-11-02. Patch release (no library expansion).

Backend application version **1.36.1**, protocol version 3, SDK 3.1.0.
Generated indexes stay at **551 operators**, **101 Readers**, seven packages and
24 built-in routes.

## Fix

`proteinmpnn_design_diversity` now falls back to the repository's
`vanilla_model_weights` directory when `weights_path` is empty. Previously the
operator only forwarded `--path_to_model_weights` when the parameter was set,
relying on the upstream default, which the Windows runner resolved to a path
next to `protein_mpnn_run.py` (`.../protein_mpnn_run.p/vanilla_model_weights/…`)
and failed with `FileNotFoundError`. The default now matches the checkout
layout used by every other ProteinMPNN operator in this library.

## Evidence

- `tests/test_extension189.py` — 22 passed for 187-189 after the change.
- Windows smoke: `structure_secondary_structure`, `structure_contact_order`,
  `rdkit_fragment_overlap` and `proteinmpnn_design_diversity` all run through
  the shared `Context` + `run()` path.
- Packaging group unchanged at 65 passed.

## Limits

No behaviour change when `weights_path` is supplied. A checkout without a
`vanilla_model_weights` directory still requires the explicit parameter.

## Compatibility

Patch only; operator ids, ports and saved parameter values are unchanged.
