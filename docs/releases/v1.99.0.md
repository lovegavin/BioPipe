# Operon 1.99.0

Two hard structural-dynamics capabilities (689 operators, 101 Readers):
**`structure_gnm_flexibility`** and **`structure_anm_modes`**. Both build the
model from CA atoms in-process with NumPy and are verified against the
independent ProDy implementation.

## Operators

### structure_gnm_flexibility

Gaussian network model (Kirchhoff matrix, distance cutoff, spring constant).
Reports per residue `msf`, `norm_msf` (mean 1) and `mode1_weight`; info carries
`n_residues`, `zero_modes`, `msf_min/max`, `collectivity`, `cutoff`, `gamma`.

### structure_anm_modes

Anisotropic network model (3N x 3N Hessian of outer-product blocks with
`r_hat r_hat^T`). Reports per-residue `msf` and `norm_msf` restricted to the
slowest `n_modes`; info carries `slowest_eigenvalues`, `zero_modes` (6 for a
rigid body), `collectivity` and the same model parameters.

## Verification

- `tests/test_extension328.py`: 3 passed — CA selection (132 on 1MEL chain A),
  rotation invariance, run round trip, error paths, and an independent
  **ProDy GNM** oracle built from the same cutoff (`msf` agreement 1e-5
  relative).
- `tests/test_extension329.py`: 3 passed — Hessian rank (3 for a triangle, 6
  zero modes are excluded), rotation invariance, run round trip, and an
  independent **ProDy ANM** oracle (20 modes, `msf` agreement 1e-4).
- Evidence on 1MEL chain A (132 CA): GNM `msf` 0.034-0.211, collectivity 0.565,
  slowest-mode hot spot `A:ALA:104`; ANM slowest eigenvalues 1.186/1.323/1.561,
  collectivity 0.059, most flexible residue `A:GLY:42` (the CDR-H2 loop).
- Registry: 689 operators / 101 Readers / 7 packages / 24 routes, `errors []`.

## Boundaries

- Elastic network models are coarse-grained CA models; they rank flexibility but
  do not produce actual motion trajectories or energetics.
- The ANM result depends on `n_modes` (20 by default) and the cutoff (15 Å);
  both are exposed as parameters.
- `prody` is an optional test dependency; the operator itself only needs NumPy.
