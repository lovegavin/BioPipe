# Operon 2.2.0

Released: 2026-11-04

Minor batch: **genome assembly I**. The registry grows from 713 to **716
operators** (101 Readers, 7 packages, 24 routes); no Reader or route changes.

## New capabilities

| Operator | Purpose | Evidence |
| --- | --- | --- |
| `flye_assemble` | De novo assembly of long reads with the official Flye 2.9.6 binary; returns per-contig length, coverage and circularity plus N50/L50. | 242 simulated 6 kb reads (30x, 2% substitution error) from the 48,502 bp lambda genome assembled to one 47,913 bp contig (98.8% of the reference) at 32x coverage, N50 47,913. |
| `assembly_stats` | Runs the official QUAST 5.3 report on contigs and returns every numeric metric; optional reference enables genome fraction, NGA50 and misassembly metrics. | Hand-checked N50/L50 on contigs 10/20/30/40 (N50 30, L50 2, total 100) and a QUAST run on the same set; reference-based run on the Flye assembly. |
| `crispr_array_detect` | Detects CRISPR arrays with the official minced 0.4.2 tool; returns start/end, repeat count, repeat and spacer lengths and the consensus repeat. | Real E. coli K-12 CRISPR1 locus (562 bp fixture): one array 201-534, six repeats, 29 bp repeat / 32 bp spacer, consensus `CGGTTTATCCCCGCTGGCGCGGGGAACTC`. |

All three declare the tool through `resources.external_tools` (`flye`, `quast`,
`minced`), so the dependency probe resolves them with `find_tool` rather than
importing a Python module; isolated environments are not required. The
operators prepend the tool's own directory to `PATH`, which lets Flye find
`minimap2` and minced find its Java runtime.

## Packaging and tests

- New tests `tests/test_extension354.py` (Flye), `355.py` (QUAST) and `356.py`
  (minced): 16 passed with the real tools enabled, including the real assembly,
  the reference QUAST run and the real E. coli array.
- Real runs are gated by `OPERON_FLYE`, `OPERON_QUAST`, `OPERON_MINCED` and
  the `OPERON_REAL_ASSEMBLY` / `OPERON_REAL_CRISPR` switches; without the
  tools the tests skip instead of pretending to pass.
- `registry build` / `registry check`: 716 operators, 101 Readers, 7 packages,
  24 routes, errors `[]`.

## Resource notes

`docs/large_resources.md` gained a "Genome assembly tools" section with the
conda command that installs Flye, QUAST, minced, minimap2 and OpenJDK. No
database download is required for these three operators.

## Limits

- `flye_assemble` consumes sequence-only reads (FASTQ qualities are not used),
  so `--nano-raw`-style modes are the intended ones; assembly quality is
  bounded by the reads supplied.
- `assembly_stats` reports whatever QUAST emits; metrics that depend on a
  reference are absent when `reference_path` is empty.
- `crispr_array_detect` reports arrays from minced, including the terminal
  repeat that carries no spacer; it does not annotate Cas genes.
