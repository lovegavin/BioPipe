# Operon 1.89.0

One hard capability: **`structure_md_contact_occupancy`** (678 operators,
101 Readers). It measures how often each residue pair stays in contact across
MD frames using heavy-atom minimum distances, and reports mean and minimum
distances per surviving pair.

## Operator

- Parameters: `trajectory_path` (`.npy`, nanometres, shape
  `(frames, atoms, 3)`), `topology_path` (PDB), optional `chains` filter,
  `cutoff`, `min_occupancy`, `stride`, `contact_dim`, `output`.
- Output `[contact, statistic]`: `occupancy`, `mean_distance`, `min_distance`;
  labels `A:12-B:34`; info `n_frames`, `n_pairs`, `n_contacts`, `cutoff`,
  `min_occupancy`, `stride`.
- Hydrogens are excluded by element and atom-name heuristics; pairs are ordered
  by topology residue order and sorted by decreasing occupancy.

## Boundaries

- Contacts use minimum heavy-atom distance only (no hydrogen-bond or salt-bridge
  semantics); see `structure_md_ss_occupancy` and `interface_hbond_network`
  for chemistry-aware views.
- Frames must share one topology atom order.
