# Operon 1.125.0

## Added

- Temporary dependency scope. `OPERON_DEPENDENCY_SCOPE` (comma separated ids)
  or `~/.config/operon/dependency_scope.json` (JSON list) restricts dependency
  checks, readiness display and the installer's verification gate to the named
  operators. The rest of the library stays installed and usable; only the check
  is scoped. Deleting the file (or unsetting the variable) restores the full
  check, which is the intended end state once the scoped entries are verified.

Backend version: 1.125.0 (operators 709, Readers 101).
