# Operon 1.59.1

Patch release for the v1.59.0 wrappers. Windows cannot `CreateProcess` a Python
script, so `boltz_predict` and `foldseek_search` now launch a `.py` runner
through `sys.executable` (the same guard used by `vina_dock` and `colabfold_predict`).
Counts stay at **653 operators and 101 Readers**.
