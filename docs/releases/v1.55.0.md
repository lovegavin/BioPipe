# Operon 1.55.0

Expansion batch adding four operators for binder design and embedding
analysis, reaching **639 operators and 101 Readers**; no existing contract
changes.

## Added

- `structure_ligand_interaction_fingerprint` — per-ligand-atom interaction
  counts (hydrophobic, polar, charged, aromatic) and nearest protein distance
  from a PDB atom table; usable as a docking triage feature.
- `sequence_disorder_predictor` — charge/composition disorder propensity with a
  sliding window and merged disordered segments.
- `proteinmpnn_interface_scan` — sweeps interface cutoffs, rebuilds hotspot
  masks at each cutoff, runs the official ProteinMPNN runner and reports design
  yield and scores per cutoff.
- `esm_embedding_autoencoder` — small torch autoencoder over an embedding
  matrix, producing per-sample reconstruction MSE for novelty and outlier
  screening.

## Boundaries

- The interface scan needs a local ProteinMPNN checkout and weights; the
  autoencoder needs torch. Disorder propensity is a sequence heuristic, not a
  trained predictor, and the fingerprint is geometric, not energetic.
