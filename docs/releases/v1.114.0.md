# Operon 1.114.0

One hard capability (706 operators, 101 Readers): **`foldseek_align`** —
pairwise structural alignment through the real Foldseek binary.

## Operator

Runs `foldseek easy-search` on two structure files with
`--format-output query,target,alntmscore,rmsd,lddt,fident,qcov,tcov,alnlen`
and returns the first hit as a one-row table, with the raw fields also in
`info`. `foldseek structurealign` was rejected during implementation because it
requires four databases (query, target, prefilter, result) rather than two
files; `easy-search` builds the databases internally.

## Boundaries

- Foldseek's TM-score is its own normalisation and can exceed 1.008-style values
  (self-pair 1.008 here), so it is not interchangeable with the TM-score
  operator added in v1.75 (0.9865 for the same pair); use one metric per study.
- `easy-search` reports the best hit only; multi-hit ranking remains the job of
  `foldseek_search` against a prebuilt database.
- A malformed test double earlier overwrote the 1MEL fixture with a TSV row;
  the fixture was restored from git and the test now writes only to the
  designated result path.
