# Operon 1.53.0

Release date: 2026-11-02

This expansion adds five capabilities around constrained sequence design, secretion
signal typing, docking-pose comparison and learned feature probes. The registry
grows from 625 to **630 operators** and keeps **101 Readers, 7 packages and 24
route templates**.

## New operators

| Operator | Category | What it does |
| --- | --- | --- |
| `proteinmpnn_omit_design` | Machine Learning | Runs the official ProteinMPNN runner with `--omit_AAs`, verifies that no returned design leaks an omitted residue, and exports the score columns. |
| `sequence_signal_peptide_v2` | Sequence | SignalP-style scan that reports cleavage site, hydrophobic core, Tat/SPI/SPII type code and the n/h/c regions. |
| `vina_pose_rmsd` | Structure | Compares docking poses with an official AutoDock pose file, using symmetry-aware RMSD per pose. |
| `structure_ligand_strain` | Structure | Computes bound-versus-minimized energy of an RDKit-parsed ligand pose with MMFF94 or UFF. |
| `esm_embedding_ridge_probe` | Machine Learning | Ridge regression cross-validation (R², RMSE, MAE, baseline RMSE) over an ESM embedding matrix with continuous targets. |

## Verification

- `proteinmpnn_omit_design`: option parsing and command construction are checked
  against a fake official runner; designs are parsed from the standard
  `seqs/<stem>.fa` file, and the leak guard is exercised with a stub returning an
  omitted residue.
- `sequence_signal_peptide_v2`: hand-computed hydrophobic windows, Tat motif and
  type-code paths plus a real VHH and a cytosolic control.
- `vina_pose_rmsd`: rigid-transform, symmetry-permutation and element-mismatch
  cases, with the reference parsed by the same PDBQT reader the docking operator
  uses.
- `structure_ligand_strain`: ligand block construction from an encoded PDB form
  and bound/minimized/strain energy on a small rigid molecule.
- `esm_embedding_ridge_probe`: ridge solution compared with scikit-learn's
  `Ridge` and `KFold`-free exact arithmetic, plus target parsing and validation
  errors.

Focused tests 266–270 pass locally (33 tests). The packaging group
(`test_builtin_pins`, `test_dependencies`, `test_library_bundle`,
`test_operator_images`, `test_release_build`, `test_release_agent_harness`) passes
in the release environment.

## Boundaries

- `proteinmpnn_omit_design` requires a local ProteinMPNN checkout and weights; the
  operator reports the missing path instead of downloading anything.
- `vina_pose_rmsd` compares PDBQT poses and does not re-dock; docking stays in
  `vina_dock` and `vina_dock_batch`.
- `structure_ligand_strain` needs force-field parameters for every ligand atom and
  reports the RDKit error when they are missing.
- `esm_embedding_ridge_probe` needs an embedding matrix from `esm_embedding`; no
  weights are fetched.
