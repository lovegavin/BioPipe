# Operon 1.123.6

## Fixed

- `antifold_score` now declares `resources.environment = "antifold"`, so its
  dependency probe runs inside the AntiFold interpreter instead of the shared
  one (`antifold: ModuleNotFoundError` was the last optional failure).
- ESM-3 installs `esm` with `--no-build-isolation --no-deps` after its build
  backends and runtime extras (`tenacity`, `torchvision`) are present; the
  isolated pip build could not resolve torch at build time and left the
  environment without `esm`.
- AntiFold installs `biotite==0.38`, `torch-geometric==2.4.0` and
  `biopython==1.83` (its own pins) after the base wheels.
- Verified directly on the server: the live probe now reports
  `810 entries; required 0 optional 1` before this patch, and the remaining
  optional entry was exactly `antifold_score` (now routed to its environment).

Backend version: 1.123.6 (operators 709, Readers 101).
