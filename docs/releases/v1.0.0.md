# Operon Studio 1.0.0 backend

This is a backend/application version milestone, not a feature change from
0.116.2. The unified application source, CLI, HTTP API and headless worker share
the same tested implementation; the preceding 0.116.2 release remains the
functional baseline.

## Version boundaries

- Backend/application: **1.0.0** (`pyproject.toml`, `operon.__version__`).
- SDK: **3.1.0** (operator protocol 3).
- Operator library: **1.1.1** (405 operators, 88 Readers).
- Generated operator and Reader plugins now declare
  `operon-studio>=1.0.0,<2`; the previous `<1` cap would reject the 1.x
  application.

The frontend package version is independent of the backend version and keeps
its existing 0.116.2 package metadata.

## Compatibility

The 1.0.0 backend retains the 0.116.2 filesystem, registry, library and remote
execution contracts. Workflows and plugins written for 0.116.x continue to
load; plugin manifests that pinned the application below 1.0 must update their
upper bound to `<2`.

The operator library minimum application remains 0.116.2 because its shared
filesystem support is available from that release forward.

## Validation

Targeted release, protocol, library, SDK-agent and plugin-refresh tests pass
against 1.0.0. No new installation archive or desktop executable is produced by
this version promotion.
