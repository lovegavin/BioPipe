# Operon 1.46.2

Patch: operator artwork and an optional dependency guard.

## Fixes

- The frontend icon registry only knew 32 component names. Operators that
  declared other phosphor names (`Cube`, `Atom`, `Brain`, `Waves`, `Flask`,
  `MagicWand`, `Scissors`, `ShareNetwork`) fell back to the generic placeholder
  whenever their category had no default glyph, which made the shipped catalog
  render several structure and sequence operators as identical placeholders.
  Those components are now imported and registered.
- Five operators named components that the pinned phosphor release does not
  export (`TreePine`, `Scale`, `ChartColumn`, `Wand2`, `Protein`); they now use
  the shipped equivalents `TreeStructure`, `Scales`, `ChartBar`, `MagicWand`
  and `Intersect`.
- `esm_embedding_linear_probe` imported scikit-learn lazily and leaked a raw
  `ModuleNotFoundError`; it now raises a `StepError` naming the optional
  dependency and the install command, and `tests/test_extension234.py` skips
  when scikit-learn is absent.

## Verification

- Registry unchanged: 596 operators / 101 Readers / 7 packages / 24 routes,
  errors [].
- Frontend test suite and production build on the Windows checkout.
