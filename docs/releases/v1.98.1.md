# Operon 1.98.1

Patch release: the ESM-3 contract tests no longer require the `esm` package.

## Fixed

- `tests/test_extension326.py` (inverse folding) and
  `tests/test_extension327.py` (structure prediction) inject stub `esm`,
  `esm.sdk` and `esm.sdk.api` modules, so the fake-model contract tests run on
  Windows and in any environment without ESM-3 installed. Previously they
  failed with `StepError: esm3_fold: esm.sdk.api is unavailable in the
  installed ESM package` because a full submodule cannot be registered without
  its parent packages.

## Verification

- `pytest tests/test_extension326.py tests/test_extension327.py -q`: 7 passed,
  2 skipped (real-model tests gated by `OPERON_ESM3_REAL`).
- Registry unchanged: 687 operators / 101 Readers / 7 packages / 24 routes,
  `errors []`; no operator, contract or execution change.
- Windows verification: version 1.98.1, counts match, new tests pass or skip
  cleanly, route CHECK OK, frontend build passes.

## Boundaries

- Test-only patch. ESM-3 model behaviour, parameters and outputs are unchanged
  from 1.98.0.
