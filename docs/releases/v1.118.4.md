# BioPipe 1.118.4

Documentation-only patch for the MCP quickstart.

## Change

`docs/quickstart_full_flow.md` section 4 now states the three settings an
operator needs to choose when connecting DeepSeek Harness:

- **Workspace**: the BioPipe checkout (for code and examples) or a dedicated
  data directory; never `C:\Windows`, `C:\Program Files`, a drive root or the
  whole user profile.
- **Permissions**: default `workspace-write`; keep `mcp --allow-run` for
  submission, drop it for read-only triage, add `--read-only` to forbid edits,
  and only add `--allow-plugins` when installing a trusted wheel.
- **Minimal example prompt**: a copy-paste prompt that exercises
  `biopipe_operator_search` → `biopipe_workflow_prepare` → `biopipe_submit`
  (`request_id` fixed) → `biopipe_job` / `biopipe_artifacts`, plus the canvas
  variant that starts from `biopipe_context`.
