# Operon 1.34.0 - CDR-fixed antibody design, consensus and interface redesign

This expansion batch adds four sequence-design capabilities with authoritative
oracles derived from the official ProteinMPNN and ESM-IF implementations.

## Capabilities

| Operator | What it does | Authoritative evidence |
| --- | --- | --- |
| `antibody_cdr_redesign` | Fixes every Kabat CDR of an antibody chain and re-designs only the framework with ProteinMPNN. The operator parses the chain sequence from the PDB, locates CDR1/2/3 with the shared Kabat annotation, builds the fixed-position JSONL (other chains fully fixed) and rejects any design that perturbs a CDR residue. | The official `protein_mpnn_run.py` run on the 1MEL VHH (chain A) keeps every CDR residue across all designs. |
| `proteinmpnn_multi_model_consensus` | Samples the same backbone with several checkpoints, aggregates per-position amino-acid frequencies across all designs and reports the consensus sequence and per-position agreement. | Each model's designs match an independent `proteinmpnn_design` run with the same seed, and the frequency matrix is checked by hand. |
| `esm_if_interface_redesign` | Finds the binder-side interface residues of a complex (heavy-atom contact within a cutoff), masks only those positions in the `partial_seq` and samples with ESM-IF. | The official `model.sample(partial_seq=...)` with the same mask and seed produces the same sequences; non-interface positions are asserted unchanged. |
| `proteinmpnn_temperature_ladder` | Runs one official sampling pass per temperature and reports mean score, mean sequence recovery, sequence diversity (one minus mean pairwise identity) and the design count. | Independent per-temperature originals are compared position by position; diversity is checked against a hand-computed identity. |

## Design notes

- `antibody_cdr_redesign` treats the chain numbering as sequential positions, matching
  ProteinMPNN's `fixed_positions_jsonl` semantics (1-based indices within each chain),
  not the author numbering of the PDB. Non-antibody chains are fixed completely so the
  parsed design stays aligned with the selected chain.
- `proteinmpnn_multi_model_consensus` runs checkpoints one after another to keep peak
  memory bounded; all runs share the seed, temperature and chain selection.
- `esm_if_interface_redesign` supports exactly one binder chain because ESM-IF scores a
  single chain; the target chains only define the interface geometry.
- `proteinmpnn_temperature_ladder` requires at least two designs per temperature so the
  diversity column is defined; duplicate temperatures collapse.

## Evidence

- 28 new tests (`tests/test_extension179.py` - `182.py`) cover command construction,
  FASTA parsing, CDR invariance enforcement, consensus maths, interface masking,
  diversity and the error paths of every parameter.
- Runner-level and official-runner tests use the local ProteinMPNN checkout and the
  ESM-IF1 checkpoint; both are gated on the local files and skip cleanly when absent.
- Registry: 543 operators, 101 Readers, 7 packages, 24 routes, no errors.

## Limits

- ProteinMPNN and ESM-IF weights are user-supplied local files; nothing is downloaded at
  run time.
- The Kabat CDR boundaries are the shared heuristic implementation, not a full ANARCI
  numbering; unusual frameworks may need manual `design_ranges`.
- ESM-IF is CPU-only in the installed fair-esm build.
- Temperature ladders cost one designer run per temperature.

## Compatibility

New operators only; no existing operator or Reader contract changes.
