# Operon Studio v2.4.0

This release brings a unified Settings page and desktop-first handoff to specialist
viewers. The application and operator library retain independent versions and
release channels. Protocol v3, saved parameter JSON, memory admission, streaming,
emergency spill and SSH execution remain in place.

## Settings and result viewing

- The toolbar gear opens Servers, Outputs and viewers, and Appearance. Server
  installation, maintenance and connection controls are together; the toolbar
  retains the current execution-location selector.
- Configure application paths and default desktop viewers by file extension.
  Defaults survive restart and stay outside workflow JSON. A missing explicit
  default produces an error rather than silently switching applications.
- Results provide Open and a compact alternatives menu. The catalog contains 21
  desktop and eight web adapters across Hi-C, genomic tracks, plasmids, molecular
  structures, networks, microscopy, trees, single-cell and mass-spectrometry data.
- Remote handoff uses retained-output transfer/cache and associated indexes. It
  does not upload data to web viewers automatically. Viewer launch is separate
  from scientific execution and requires run scope through CLI/MCP/API.
- CLI and API share the same defaults. MCP discovery reports compatible viewers
  and the default without launching; explicit launch remains a separate request.

## Independent library

The bundled factory seed is **2026.11.5.2**, also published independently under
`library-v2026.11.5.2`. The unified output operator adds HIC/Cooler, GenBank,
BED/bedGraph, GraphML and Newick conversion when required data and metadata are
present. Existing native files are reused, and other branches continue computing.
User-installed provider generations are not overwritten by an application update.

## Downloads and limits

- **Full:** portable Python 3.11 and the tested shared CPU dependencies, including
  HIC export support. Extract the whole archive and double-click the EXE.
- **Lite:** requires a compatible existing Python environment; automatic discovery
  and declared-dependency checks remain enabled.
- The application wheel and source archive are for server/headless installations;
  the reference seed has a separate wheel and native library bundles.

Third-party GUI applications, licenses, GPU drivers, model weights and dedicated
analysis environments are not bundled. Some viewers require manual File/Open or
additional reference/index files. A launch acknowledgement does not certify that
every third-party viewer has rendered the file. See `VERIFICATION.md` for the
actual release checks and [the viewer guide](../result_viewers.md) for contracts.
