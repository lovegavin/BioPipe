# Operon 1.121.0

## Multi-environment operator support

AntiFold pins NumPy 1.26, Torch 2.3.1, Biotite 0.38 and Biopython 1.83, which
cannot coexist with the shared NumPy 2 / Torch 2.6 scientific runtime. Instead of
downgrading the shared stack or relaxing the pins, Operon now manages a
dedicated interpreter per conflicting operator:

- `operon/environments.json` declares environments (`python`, `imports`,
  `requirements`); `operon/environments.py` resolves them from
  `OPERON_ENV_<NAME>` or `<prefix>/external/<name>`, probes their imports in
  their own interpreter, and is exposed as `python -m operon.environments`.
- `antifold_design` declares `resources.environment = "antifold"` and runs the
  official runner through that interpreter unless `python_executable` overrides it.
- The managed Linux installer creates declared environments (micromamba + pip with
  the mirror) after the shared environment is ready.
- The dependency probe routes declared-environment operators to their own
  interpreter and keeps every version pin strict; transitive dependency
  warnings are removed, so an incompatible shared environment still fails.
