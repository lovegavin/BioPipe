# Operon 1.105.0

One hard capability (697 operators, 101 Readers):
**`structure_interface_residue_energy`** — per-residue decomposition of the
vacuum Coulomb + Lennard-Jones protein-protein interaction energy.

## Operator

The structure is repaired with PDBFixer (waters and heterogens removed, missing
atoms and hydrogens added), an Amber14 `NoCutoff` system is built, and the
non-bonded parameters (charge, sigma, epsilon) are read back from the
`NonbondedForce`. Cross-side atom pairs are evaluated with the OpenMM
conventions (`sigma_ij = (sigma_i + sigma_j) / 2`,
`epsilon_ij = sqrt(epsilon_i epsilon_j)`, Coulomb constant 138.935456 kJ nm /
mol e^2), bonded exceptions are masked out, and every pair is split evenly
between its two residues. Output rows are residues with Coulomb, LJ, total and
contact counts; info carries the side totals and the decomposed sum.

## Verification

- `tests/test_extension337.py`: 3 passed — analytic pair checks
  (`q=+1, -1` at 0.5 nm equals `-C/0.5`; LJ minimum equals `-epsilon`), a real
  1MEL decomposition (16.6 M cross-side atom pairs, finite energies), and a
  full operator round trip asserting `decomposed_total_kj == total_interaction_kj`
  (exact identity, the decomposition is not an approximation).
- Real evidence: 1MEL A/B vs L/M, 554 interface residues,
  Coulomb **-5221.4 kJ/mol**, LJ **-710.4 kJ/mol**, total **-5931.7 kJ/mol**
  (decomposed sum identical); the strongest residues are `A:GLU:108` and
  `A:ASP:99`, as expected for electrostatics-dominated interfaces.
- Registry: 697 operators / 101 Readers / 7 packages / 24 routes, `errors []`.

## Boundaries

- Vacuum electrostatics only: no implicit solvent, no entropy, no explicit
  bridging waters; this is a ranking tool, not a binding free energy.
- Repaired hydrogens change absolute numbers slightly between runs (PDBFixer
  placement is not seeded); rankings are stable.
- Cost grows with the square of the interface atom count (~75 s for 1MEL in
  tests), so very large complexes need care.
