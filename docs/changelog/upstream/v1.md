# Upstream v1

Initial version of the BioPipe engine.

## Scope

- Four protocols: Manifest, Reader, Step, Form.
- 12 built-in Readers.
- 18 built-in Steps.
- Context and Runner runtime.
- GWAS pipeline demo.

## Protocols

**Manifest** — `task.yaml` with `sources` and `steps` blocks. Optional top-level `params`. Each source declares `path`, `dims`, `labels`, `args`. Each step declares `name`, `inputs`, `params`.

**Reader** — subclasses declare `extensions`, `requires_siblings`, `excludes_siblings`, `handles_compression`, and implement `read(path, dims, labels, **args) -> Form`. Auto-discovered from `src/reader/readers/`.

**Step** — subclasses declare `name`, `inputs_arity`, `outputs`, and implement `run(ctx, inputs)` and optionally `export(ctx)`. Auto-discovered from `src/task/step/steps/`.

**Form** — `data` (N-d tensor), `dims`, `labels`, `info`, `axis_info`. `validate()` enforces label coverage, `subset_axis()` trims data, labels, and axis-parallel info in sync.

## Readers (12)

| Reader | Extensions | Layout | Notes |
|---|---|---|---|
| FastaReader | `.fasta` `.fa` `.fna` `.faa` | sequence × position | Nucleotide/protein sequences, NaN-padded |
| H5adReader | `.h5ad` | obs × var | AnnData, layer support |
| Gff3Reader | `.gff` `.gff3` | row × 9 columns | GFF3 annotation |
| GtfReader | `.gtf` | row × 9 columns | GTF annotation |
| VcfReader | `.vcf` `.vcf.gz` | variant × sample | GT to ALT count |
| BedReader | `.bed` | row × column | UCSC BED, 3–12 columns |
| CsvReader | `.csv` | row × column | Header supported |
| ParquetReader | `.parquet` | row × column | Column names from metadata |
| MtxReader | `.mtx` | gene × cell | 10x MEX |
| Plink1Reader | `.bed` + `.bim` + `.fam` | variant × sample | PLINK 1.x |
| Plink2Reader | `.pgen` + `.pvar` + `.psam` | variant × sample | PLINK 2.x |
| BgenReader | `.bgen` | variant × sample | Expected ALT dosage |

## Steps (18)

| Step | Category | Notes |
|---|---|---|
| `describe` | Data inspection | Print and export a summary of one input Form |
| `transpose` | Dimension / label | Reorder the axes of a Form |
| `rename_dim` | Dimension / label | Rename a single dimension |
| `select` | Dimension / label | Keep only the listed labels along a dimension |
| `drop` | Dimension / label | Remove named labels from a dimension |
| `concat` | Dimension / label | Concatenate several forms along a dimension |
| `attach_info` | Dimension / label | Attach axis-parallel info arrays by label |
| `missing` | QC filtering | Filter positions by missing rate |
| `maf` | QC filtering | Filter positions by minor allele frequency |
| `hwe` | QC filtering | Filter positions by Hardy–Weinberg exact test |
| `ld_prune` | QC filtering | Prune positions by pairwise LD |
| `pca` | Statistical modeling | PCA of a 2D Form |
| `regress` | Statistical modeling | Multiple regression over one dimension |
| `correction` | Statistical modeling | Multiple-testing correction (Bonferroni, FDR) |
| `histogram` | Plotting | Histogram of one labeled column |
| `scatter` | Plotting | Scatter plot of two labeled columns |
| `line` | Plotting | Line plot of one column against another |
| `manhattan` | Plotting | Genome-wide Manhattan plot |

## End-to-End Pipelines

- `tasks/gwas_demo` — GWAS: `missing` → `maf` → `hwe` → `ld_prune` → `pca` → `regress` → `correction` → `manhattan`.
- `tasks/csv_demo` — Minimal CSV read and `describe`.

## Known Limitations

- Matrix Readers (`MtxReader`, `FastaReader`) declared whole-dimension encoders under `info["encoders"][dim_name]`, which violated the column-encoder contract enforced by `Form.validate`. Fixed in v2.
- `CsvReader` had no `sep` parameter, so tab-separated files could not be read without pre-processing. Fixed in v2.
- Only two-group comparison was supported, via an internal operator not exposed as a public Step. Extended in v2.
