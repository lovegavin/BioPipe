# Upstream v2

Second version of the BioPipe engine. Expands the operator set from a GWAS-focused collection into a general-purpose pipeline framework serving five classical analysis paths: bulk RNA-seq DE, proteomics DE, survival analysis, single-cell, and microbiome.

This changelog records every Reader and Step change introduced in this version.

## Scope

- 28 new built-in Steps.
- 1 new Reader (`TxtReader`).
- 1 Reader change (`CsvReader` gains `sep`).
- 2 Reader fixes (`MtxReader`, `FastaReader`).
- 1 Step contract change (`compare_groups` gains multi-group modes).
- 5 end-to-end pipelines added.
- 1 demo task per operator.

## Reader changes

### New: TxtReader

Handles `.txt`, `.tsv`, `.tab`. Delegates parsing to another registered Reader, selected by the `reader` argument (default `"csv"`). When the delegate is `CsvReader` and no `sep` is given, a tab separator is assumed for `.txt`, `.tsv`, and `.tab` files.

```yaml
sources:
  table:
    path: input/table.txt
    dims: [sample, feature]
    labels:
      sample: {feature: 0}
      feature: builtin
    args:
      reader: csv
      sep: "\t"
```

### Changed: CsvReader

Accepts a new `sep` argument (default `","`). Tab-separated and other delimited files can now be read directly, without pre-processing into CSV.

### Fixed: MtxReader

Removed the whole-dimension encoder that was written under `info["encoders"]["gene"]["gene"]` (and the equivalent for cell). This encoder violated the column-encoder contract enforced by `Form.validate`, which requires every encoder key to match a column label present in `form.labels[dim]`. The Reader now uses `unique_labels` only, and no encoder is stored.

### Fixed: FastaReader

Same class of fix as `MtxReader`. The whole-dimension encoder for the sequence axis was removed. Labels come from `unique_labels` only.

## Step changes

### New: filtering and transformation

| Step | Purpose | Methods / Notes |
|---|---|---|
| `filter_min` | Drop positions whose value does not reach a threshold in enough samples | Any ndim ≥ 1. Replaces the internal `filter_low_count` used by the RNA-seq path. |
| `filter_by` | Drop positions using rules defined on a second form | Rules support `{field, min, max}`. |
| `normalize` | Scale along one axis | `cpm`, `total`, `median_of_ratios`, `quantile`, `zscore` |
| `log_transform` | `log_base(x + pseudocount)` elementwise | Preserves NaN. `base` accepts int, float, or `"e"`. |
| `impute` | Fill missing cells | `min`, `median`, `mean`. Works on N-dimensional input. |
| `bin` | Discretize a continuous axis | `quantile`, `uniform`. Supports `value_label` to read a named column from a statistics axis. |

### New: dimensionality and ranking

| Step | Purpose | Methods / Notes |
|---|---|---|
| `reduce_axis` | Collapse one axis into a summary statistic per position | `sum`, `mean`, `std`, `var`, `min`, `max`, `median`, `nonzero`, `count`. Any ndim ≥ 1. |
| `rank_axis` | Rank positions along an axis and keep the top N | Rank by `variance`, `std`, `mean`, `sum`, `nonzero`, `abs_mean`, `max`. Supports `min_value`, `keep_ties`, `descending`. |
| `reduce` | General dimensionality reduction | `pca`, `umap`, `tsne`, `pcoa`. Supersedes the standalone `pca` Step, which is retained for compatibility. |
| `cluster_axis` | Cluster positions along an axis | `kmeans`, `hierarchical` (Ward), `louvain` (KNN graph community detection). |

### Changed: compare_groups

Extended from two-group to multi-group comparison. Three modes:

| Mode | Output | Notes |
|---|---|---|
| `two_groups` (default) | `[dim, "statistic"]` | Backward compatible with v1 behaviour. Requires `group_a` and `group_b`. |
| `one_vs_rest` | `[dim, "comparison", "statistic"]` | One comparison per group: that group vs the union of the others. |
| `pairwise` | `[dim, "comparison", "statistic"]` | Every unordered pair of groups. |

Methods: `ttest`, `welch`, `mannwhitney` (alias `wilcoxon`), `deseq2`. The `min_per_group` parameter controls which comparisons are skipped. The `groups` parameter selects and orders groups explicitly.

### New: diversity, distance, and correlation

| Step | Purpose | Methods / Notes |
|---|---|---|
| `diversity` | Per-position diversity metrics | `shannon`, `simpson`, `richness`, `evenness`, `gini`. |
| `distance_matrix` | Pairwise distances along one axis | `euclidean`, `manhattan`, `cosine`, `correlation`, `braycurtis`, `jaccard`, `hamming`. Output `[dim, dim_b]`. |
| `correlation` | Pairwise correlations along one axis | `pearson`, `spearman`, `kendall`, `cosine`, `jaccard`, `overlap`. Handles missing values pairwise via `min_valid`. |
| `permanova` | Permutation-based MANOVA on a distance matrix | Anderson (2001) formulation. Supports overall and pairwise tests. `n_permutations` controls the permutation count. |

### New: relational operations

| Step | Purpose | Methods / Notes |
|---|---|---|
| `join` | Attach selected columns from a second form, aligned by label | `inner` and `left` join modes. Supports a prefix to disambiguate column names. |
| `aggregate` | Collapse rows into groups using a group column | `sum`, `mean`, `median`, `min`, `max`, `count`. Group order follows first appearance in the input. |

### New: survival analysis

| Step | Purpose | Methods / Notes |
|---|---|---|
| `kaplan_meier` | Kaplan–Meier survival curves grouped by a label column | Supports `group_map` for collapsing substages. Censor marks and optional confidence bands. |
| `logrank_test` | Log-rank test across groups | Overall test plus optional pairwise tests. |
| `cox_regression` | Cox proportional hazards model | Accepts numeric and categorical covariates. Categorical covariates are expanded to one dummy per level, dropping the first as reference. The output label uses `{col}_{level}`. |
| `forest_plot` | Forest plot of hazard ratios | Confidence intervals and significance highlighting. Supports `sort_by` (`input`, `hr`, `p`). |

### New: visualization

| Step | Purpose | Methods / Notes |
|---|---|---|
| `volcano` | Volcano plot of log2FC vs −log10(P) | Threshold lines, up / down / ns colouring, optional top-N annotation. |
| `ma_plot` | MA plot of log2FC vs mean expression | Significance colouring. |
| `heatmap` | Matrix heatmap | Row selection by variance or explicit label. Standardization: `row`, `col`, `none`. Optional row and column hierarchical clustering. |
| `boxplot` | Box plot of a value column split by groups | Two inputs: data Form and metadata Form. Per-group summary in the export. |
| `violin` | Violin plot of a value column split by groups | Inner marks: `box`, `quartile`, `point`, `none`. |
| `dotplot` | Dot plot of features × groups | Colour = mean value; size = proportion of non-zero (or threshold) samples. |
| `barplot` | Stacked bar plot of a composition matrix | Top-N feature selection with optional Other aggregation. |

## Operator Demos

Each operator in `src/task/step/steps/` has a demo under `tasks/<operator>_demo/`, containing a `task.yaml`, a `test_<operator>.py` standalone unit test, and (where relevant) an `input/` directory with real data.

## Breaking changes from v1

- `MtxReader` and `FastaReader` no longer write `info["encoders"]`. Workflows that read encoders written by these two Readers must derive the mapping from `form.labels` instead.
- `compare_groups` output shape is unchanged in the default `two_groups` mode. The `one_vs_rest` and `pairwise` modes produce a 3D output `[dim, "comparison", "statistic"]`, which downstream Steps must consume via `select` on the comparison axis.
- `Form.validate` encoder check now enforces the column-encoder contract strictly. Any Reader that wrote `info["encoders"][dim][dim]` will now raise `ValidationError: orphan encoder {dim}.{dim}`.

## Non-breaking additions

- `pca` is retained and continues to work. New pipelines should prefer `reduce`.
- All existing `task.yaml` files in `tasks/` continue to run without modification.
