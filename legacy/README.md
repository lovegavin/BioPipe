# Legacy BioPipe source

This directory preserves the source, task definitions, documentation and dependency
configuration from upstream commit `9a80642d1ce5168e4f12847764387954fbdfff83`, immediately before Studio 0.2.0.
Files listed in `snapshot.json` are unchanged snapshots with SHA-256 checksums.
See [the original README](README.upstream.md) for historical behavior.

The current application lives at the repository root. This archive is not imported,
packaged or tested as part of the current application. Its old dependency configuration
is retained for reference; do not apply it to a current Studio environment.

Generated analysis outputs, the old compiled frontend, the desktop executable and IDE
settings are excluded from this source archive. The complete original tree, including
those artifacts, remains available at the commit above in Git history. Original demo
outputs also remain under the root `tasks/` directories.
